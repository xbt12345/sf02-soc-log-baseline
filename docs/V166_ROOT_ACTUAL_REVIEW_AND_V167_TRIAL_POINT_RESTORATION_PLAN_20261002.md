## 3. 成熟方法依据与本项目改造

[Wächter/Biegler 原始研究第4.1节](https://optimization-online.org/wp-content/uploads/2001/08/367.pdf)允许在起点或实际试探点采用约束 Jacobian，并讨论连续的有限修正。[Ipopt](https://github.com/coin-or/Ipopt)的[修正次数/违约量减小机制](https://coin-or.github.io/Ipopt/OPTIONS.html#OPT_max_soc)提供有界执行的参考。这里借鉴“在当前实际试探点重新建模并重新验收”，不移植整个求解器，也不借用其局部收敛结论宣称模型必然有效。

下一候选流程统一由**实际 V166 门槛**决定，不按折ID选择算法：通过者精确重放原候选；失败且所有阻挡都已覆盖者进入最多两次试探点修正。当前事实使角色0/2保持，角色1需要修正。

### 固定输入、来源与目标

- 三角色实际起点仍为各自 V164 最后真实接受参数 theta0；先完整重放并匹配全部原行。
- 控制为 V166 已保存真实位移和完整候选。角色0/2位移、参数、预测及356/8条候选修复保持，不能重新优化它们后挑更好的结果；这些仍是候选收益，不是永久训练收益。
- 原始 CSR、16个有序意见、头分块/query、原标签、完整原类别分母、固定错误目标、原频次、全部混合行、原纯正确及累计8条修复与全部旧技能保护均不变。
- 不删除25函数中的任何函数，不只测五个失败函数；修正可能移动其他边界，角色1每个修正点都重测原25函数。

### 实际失败点 Jacobian 的有界修正

1. 临时赋值 theta_j=theta0+u_j，第一次 u_j 为角色1 V166 被拒绝位移。保存全参数真实身份，禁止当作接受更新。
2. 在这个实际 theta_j 对全部25函数测完整参数间隔导数，各测两次。q/logq/间隔与该点已保存完整预测一致；每项元数据同时写 theta0 身份、实际线性化点身份和完整输入身份。不得用 theta0 导数冒充 theta_j 导数。
3. 以 c_j 为该点真实间隔，求最小修正 e：A(theta_j)e >= -c_j。保持原 gM(theta0)·(u_j+e)<=0、gS(theta0)·(u_j+e)<=0 和原单位数值检查；类别梯度的起点角色与保护Jacobian的试探点角色明确区分。
4. 恢复 theta0 后按 u_j+e 做完整实际候选；仍从 theta0 的固定目标风险执行原16eps/Armijo和完整原行类别/正确保护/旧技能。数学通过不能提交参数。
5. 候选全部通过则停止修正。若仍仅有已覆盖函数翻错、有限目标的双类下降仍合格，且已测函数最大负间隔严格降至前一点的0.99倍以下，才允许第二次同样修正。该0.99是前瞻性继续诊断规则，不是分类豁免，也不是按本轮结果调阈值。
6. 出现未覆盖阻挡、数值/身份/重复失败、方向不合格、双类实际目标下降失败、残差没有足够减小，或第二次仍不安全，即停止。保留全部结果，不增加第三次修正，不扩大25上限、不换种子或步长。
7. 所有分支 finally 恢复 theta0，保存完整恢复模型与全原行q/logq。正式拟合和永久更新为0。

零地板只用于局部数学目标；真实argmax和原正确保护始终决定是否安全，包括竞争类索引较小时的平手。算术容限不得成为允许错判的余量。
