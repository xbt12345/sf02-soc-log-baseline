# v3.3.1 标签影响审查与下一轮修订

日期：2026-09-12。对象是已完成的 v3.2 云端训练与尚未实施的 v3.3 方案；本次优化后的方案为 v3.3.1。**执行源仍为 [TRAINING_PLAN.md](TRAINING_PLAN.md)，本文记录审查理由与状态，不是第二份执行入口。**

结论：应先削弱日志里的上游判断、身份、采集包装和缺失模式捷径，不能先削弱全部官方标签。已有实际证据支持输入修复；目前没有独立证据支持大规模自动纠错。下一轮保留完整监督基线，加入标签证据复核和一个有条件的少数类权重候选，不立即改用更大模型。

## 本次新执行的检查

在本地核对准备文件、分组、划分与三折外层预测摘要，按行复算全部 2,056,871 条分数的筛选影响；未重训、未修改权重或标签、未上传或启动平台任务。[完整结果](../evidence/2026-09-12/v33_label_influence_audit.json)。

### 1. “模型不赞同原标签就降权”会影响谁

| 官方类别/来源 | 被该规则选中的记录 | 影响 |
|---|---:|---|
| 正常，全体 | 0 / 1,899,723 | 正常类监督完全不受影响 |
| 恶意，全体 | 1,366 / 111,728 | 影响 1.22% |
| 可疑，全体 | 2,992 / 45,420 | 影响 6.59% |
| Duo 可疑 | 12 / 12 | 全部可疑监督受影响 |
| WAF 可疑 | 2 / 2 | 全部可疑监督受影响，且只有一个组 |
| AD 可疑 | 210 / 473 | 影响 44.40% |
| Falcon 可疑 | 26 / 35 | 影响 74.29% |

改成“只相信最高分≥0.9 的模型纠错”也不能解决：Duo 12 条、WAF 2 条仍全部被选中。另一个示例规则“原标签对应分数低于 0.9 就降权”将影响 5,981 条可疑、7,046 条恶意，却不影响任何正常；AD 的 473 条可疑会全部被选中。

这些只是对已见分数的筛选反例。没有实测降权后会掉多少分，也没有证明被选中的官方标签都正确；它证明这种规则会对当前弱类产生极不对称影响。不能把这个试算扩展成对所有噪声学习算法的否定。

### 2. “同文异标签”不自动意味着官方错标

| 可观察表示 | 相同表示中的标签冲突 | 涉及行 | 固定表示、每种表示只给一个类别的经验最少错误 |
|---|---:|---:|---:|
| 官方原始 message 的冻结摘要 | 0 组 | 0 | 0 |
| v3.2 完整清洗文本 | 49 组 | 2,423 | 692 |
| ASA 去采集头后的正文诊断 | 75 组 | 4,075 | 1,116 |

前两项本次全量重算；第三项来自此前实际去头部计数，见[证据](../evidence/2026-09-12/v32_asa_header_regroup_impact.json)。原始摘要构建代码只哈希 message_sanitized 字符串，不包含 label_binary；它是主办方已经脱敏的原文，不是原始生产日志。未见原始同文冲突也不能证明所有标签可信。

冲突发生在合并表示后，需要回查原文差异。如果丢的是动作、结果、端口角色等合法事实，应修复表示；如果差异仅是时间/IP/采集包装，不能为追分恢复捷径；如果关键上下文未提供，就承认当前输入无法区分。多数投票改标签只是抹掉矛盾，不能增加可识别信息。

| 轮次与严重度 | 被质疑的原方案/具体位置 | 反例与影响 | 最小修订与验收 |
|---|---|---|---|
| 第一轮，P1，已有实测 | v3.3 §3/§10：“已加入字段边界修复”容易被读成已修好；§5 高分基线仍有包装依赖 | v3.2 保持 ASA 正文不变、统一成一种已观察头部时，2,616 条原本正确记录变错；说明高分并不等于头部不敏感 | 规范化与事实保护并行，可信变换下文本/向量/分数不变；在修复后新分组上重训并全量重测。现在未通过 |
| 第二轮，P1，本次实算 | v3.3 §3/§5 没有明确标签不可信时的处理方法 | 模型不一致降权影响所有 Duo/WAF 可疑；高分模型意见也不能避免 | 新 §3.4 禁止按旧模型分数自动删改，保留困难样本；独立事实复核先于可靠性权重。规则已补，未训练验证 |
| 第三轮，P1，本次实算加既有诊断 | v3.3 §4：“标签和每行权重保持原样”，但未清楚区分冲突来源 | 原始摘要无冲突、清洗有 49 组、去头部有 75 组；更强清洗可能同时去捷径和去信息 | 新 §3.4 要求逐组核对合法事实/捷径/缺上下文；不以冲突归零为修复目标，不改测试标签。定位证据已得，逐组修复尚未完成 |
| 第四轮，P1，已有实测与协议推演 | v3.3 §7 低误报策略与 §6 来源留出，以及新增标签复核可能互相污染 | Duo 分来源阈值少报正常，也把可疑检出从 10/12 降到 5/12；用目标域标签纠错后再“留出”会泄漏；只审错例会夸大错标比例 | 分类与报警双报，复核加入正确对照并记录抽样；目标域不参与学习纠错/权重/阈值；所有行继续计分，复核与拒识同时报告覆盖。新规则已补，迁移效果未验证 |

第一轮记录中的头部变换实测见 [ASA 头部敏感性](../evidence/2026-09-12/v32_asa_header_sensitivity.json)；第四轮阈值计数见 [可行性实算](../evidence/2026-09-12/v33_plan_feasibility.json)。

进一步反驳新方案：一致性约束本身允许模型总判正常，因此不单独构成通过条件；按类别加权可能增加正常误报，因此仅作受控候选；无原标签的审核依旧可能缺少事件真相，因此不把审阅意见伪装为新金标准。这三项边界已经写入当前执行源。

## 最少且有效的执行顺序

1. 修 ASA/Duo 输入，并检查标签字段不进入表示；对同文冲突回查真实信息损失。
2. 对修复后的全体数据重新分组，保留所有官方标签与自然行分布。
3. 先运行未加权的修复词模型 R。继承域内、ASA 模板、AD/Duo/WAF 来源留出，基础预算仍是 27 次拟合；支持预检不合格则报告缺口，不强跑。
4. 有区分事实但弱类仍被压制时，再比较一个受限类别权重候选；事实缺失时优先改表示或报告不可识别，不能让权重掩盖原因。候选选择只用对应开发职责，完整候选会增加验证成本。
5. 返回一个完整结果包，按上表逐项填入实测结果。没有训练结果就保留“未验证”，不能用方案条款代替解决状态。

规范化能够强制做到的行为不变性，不默认换成额外一致性训练；旧模型分数只作为调查线索。暂不引入外部数据，暂不增加标签平滑、自动软标签或大模型纠错。这样的选择减少无根据的实验，保留必要的效果验证。

对方法的边界参考：[标签平滑原论文](https://arxiv.org/abs/1906.02629)讨论软目标和校准；[Confident Learning 原论文](https://arxiv.org/abs/1911.00068)说明噪声假设与标签估计方法。它们都不是本项目已经通过迁移验收的证据。
