# V160 固定终点的有限诊断计划

本计划先登记诊断边界，尚未授予或执行任何官方模型调用。V159 完整质量失败；三个目标继续 active。唯一待检机制是将实际保护分类间隔的法向加入两类共同下降方向求解。模型、初始化、完整输入、原频损失、当前数值政策和全部硬保护保持 V159 已执行契约。

## 对象与输出

固定使用 `artifacts/v159_class_boundary_numeric_trial_20261002` 的三个 B 终点，角色 0/1/2。入口须在调用前绑定终点参数、合法 FIT/OOF/部署原行、完整输入与有序 16 成员概率、训练源、保护清单和源码。不得用 outer 标签生成梯度或法向。

每角色输出：原单位完整 gM/gS、真实控制探针阻挡原行及 q/logq、合法 truth 与实际竞争类、完整参数间隔法向的两次测量、QP 对偶量/残差/方向数组、全部候选有限步人口分类和两类风险检查、恢复后参数哈希。QP 成功只允许尝试有限步；有限步通过只证明该探针，不能宣称已拟合或分类掌握。

控制探针固定重放该终点最后登记的失败步长，使用未增加保护法向的原 MGDA 方向。实际阻挡需由重放 q/logq 与原行验证，不能把此前近间隔行直接当阻挡。

第一轮加入控制探针的全部实际违反保护间隔约束。后续仅从上一轮最后一个已执行失败有限探针加入全部新约束；不按收益选择探针，不丢弃难约束。每角色最多 24 个唯一法向；超过上限直接停止。去重仅允许完整实际输入、角色/作用域、合法 truth、竞争类及批上下文完全相同的约束；不同范围或不同竞争类不能因 local ID 相同合并。全部原行仍参与原频损失和质量评分。

## 有限步检查与停止分类

所有探针保留 V159 两类风险的实际下降、Armijo 与分辨率检查，以及初始正确纯 OOF、完整部署 225558 行和联合技能保护；保护逐行 argmax 必须精确通过。每个候选先保存真实输出，再判定。其余角色部署输出使用已封存终点，当前角色候选与之组成联合保护检查。

停止分别记录：绑定/合法来源失败、控制阻挡未复现、非有限输入或测量不重复、数值消去无法分辨、QP 证书失败或迭代上限、固定切空间无可分辨共同下降、法向数量上限、有限步两类风险失败、有限步保护翻转、补约束无新增、三轮或调用预算耗尽、有限探针通过、恢复哈希失败。不得将这些统称收敛、全局不可行或分类完成。

每个探针结束恢复固定终点；所有退出路径恢复并验证参数哈希。不保存探针为新部署模型。三个角色都通过有限机制后，才能另行登记有界训练契约；本诊断不包含该后续训练预算。
