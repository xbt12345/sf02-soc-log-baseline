## 当前权重下的必要条件

当前完整分类器是 `z = log(max(mean_p, 1e-12)) + mean(tanh(h) @ Wout)`。因为每个tanh输出和成员平均都在[-1,1]，对任意真类t及竞争类r，有：

`|delta_t - delta_r| <= sum_j |Wout[j,t] - Wout[j,r]|`。

若固定先验的 `log(mean_p[r]) - log(mean_p[t])` 在原单位算术余量之外大于这个上限，则在**这组固定Wout**下，即使任意改变编码器隐藏表示也不能把该原行判为真类。这里只是当前读出必要条件；Wout可以继续训练，上限不是永久容量限制，也不是输入不可辨、标签错误或全局无解的证明。未被上限阻挡同样不证明现有编码器或全部保护约束能完成分类。
