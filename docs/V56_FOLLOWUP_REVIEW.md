# v5.6 后续审查：先修正空值证据，再检验缺失条件下的学习

2026-09-14。本次复核已有模型、48组校准/评价分项和四个重点错误条件，做了逐项及联合参数撤除、训练支持追溯、受约束可区分性对照。**没有新增训练，没有产生可晋升模型。** v5.6冻结的183份文件复核前后相同，关键分数重建最大差4.44e-16；仅官方拟合侧开发资料，原压力评价未运行。

结论：大方向仍应是保留可靠事实、学习未见组合、逐类验证，但上一轮“先做样本外残差学习”的优先级需要下调。现已找到更直接的结构问题：不适用的ICMP空值重复进入修正，来自正常ACL的源角色空值参数被应用到缺角色ASA；缺失条件的收益又被平均指标掩盖。先处理这些可定位问题，再判断是否需要交叉拟合或联合训练，避免同时改动多个机制。

## 1. P1：不存在的事实被当成多个证据累加

位置：[共享字段与修正设计](../training/v56_shared_control.py)，`SHARED`包含四个ICMP字段，`keys`把每个字段的`__MISSING__`也当作普通可学习类别；`predict`无条件累加对应参数。

behavior_1的拟合数据中，四个ICMP空值指示列完全相同：各覆盖44,832行、10,380个正文组；每个参数给M相对S的分数增加0.09546，合计0.38185。这里的TCP/UDP本来就没有ICMP类型/代码，这些空值不构成四份不同的威胁事实。

同协议中，源角色空值参数只有8条正常ACL、4个正文组支持，**没有任何缺源角色的ASA拟合记录**。该参数却在ASA角色屏蔽评价中启用，给M相对S增加0.28784。它不是从“缺源角色ASA该怎样分型”的训练证据学来的。不能把这个差值解释成安全规律。

实际新增的995条可疑误判全部属于UDP、原方向dmz→outside、两端端口可见。推理撤除对照如下；每一行始终使用同一批31,833条ASA，其中M=15,568、S=16,265：

| behavior_1缺源角色 | M错误 | S错误 | 总错误 |
|---|---:|---:|---:|
| 原基础模型 | 80 | 914 | 994 |
| v5.6共享修正 | 8 | 1,909 | 1,917 |
| 撤除四个ICMP空值修正 | 48 | 1,457 | 1,505 |
| 再撤除源角色空值修正 | 80 | 892 | 972 |

最后一项撤回995条新增S误判，另修复22条原S错误。这是有真实预测支持的机制定位，**不是重训收益或可直接发布的补丁**。例如在BODY缺目的角色上撤除同一组ICMP修正，会使总错误3,610→5,038。单独撤一个参数也不能充分说明联合影响：本例单项撤除均未撤回995条错误，联合撤除才显现。

从惩罚函数也可解释一个风险：四个完全相同的设计列，如果惩罚精度相同，合计效果δ平均分给四个参数，平方惩罚仅为单参数承载δ的四分之一。此处是可推导的表示与正则化耦合，不能仅凭此断言所有相关字段有害。

最小调整：保留原13个观察值和原文来源；在新修正分支中明确字段适用范围，TCP/UDP不激活ICMP值或四个ICMP空值效应；ICMP真实type/code仍完整保留。角色未知只表示当前不知道该事实，不复用由8条正常记录学出的威胁分型偏移。缺失标记可以帮助选择经过训练的信息条件，但不能仅凭缺失就指定标签。

验收：拟合前逐列输出适用范围、实际支持和重复列；重新拟合一次同配置修正，检查所有协议、视图、类别，包括正常ACL。不能将本次撤参的评价答案用于硬编码端口、方向或分数阈值。

## 2. P1：验证在检查缺字段，当前修正却没有学习这些条件

位置：[共享修正训练](../training/v56_shared_control.py)的`run`，训练矩阵由`x.loc[tr]`构成，六种视图只用于校准/评价。所有四协议的拟合ASA均没有缺源角色记录，也没有缺目的角色记录。这个事实可以证明训练与这些压力条件不匹配，不能单独证明全部退化都由它造成。

需要纠正上一轮的笼统建议：**“加入缺失增强”不是尚未尝试的新方向。** v5.5的E1V已经使用完整/缺源角色/缺目的角色共同训练，正文错误与E1相同，但行为留出错误从2,075增至3,011；不能换个名称重复这项实验。[历史实际结果](V55_RISK_VALIDATION.md)。

下一项应与旧试验有明确差异：冻结完整输入的基础模型；在字段确实不可见时，才启用独立的缺失条件修正。辅助损失不更新完整输入分支，也不让不同缺失条件共享未经检验的全局类别偏移。保留原记录、原标签与每行总损失质量；同输入混标按实际类计数学习分布，不能强迫零损失或复制完整模型的高置信度硬标签。

先只做一项结构对照：原共享结构与“适用范围修正”的共享结构使用相同拟合/校准/评价；其后才增加缺失条件分支。每项均加入零修正作为真实候选。若仍无法通过逐类条件，停止扩训该结构，而非继续扫描λ。

## 3. P1：最差组需要单独处理覆盖问题，不能笼统归因于ICMP或网络容量

behavior_2的全部2,308条S，都位于“TCP、outside→dmz、源端口不可见、目的端口可见”这个行为组。该组共17,058行，M=14,750；原模型与共享修正同为M错48、S错2,243，可疑召回65/2,308=2.82%。这是本轮拟合侧的TCP问题，不能与早期原压力ICMP code13问题混淆。

该组有1,625种完整保留输入，162种同时出现M/S标签。给每个相同输入一个固定答案，即使事先知道本组全部标签，总错误最小也为1,248；这个最小总错误方案的分解是M错328、S错920，会增加M错误。因此只报“距离总错误底线还有多少”会高估符合当前保护约束的空间。

本次增加了按相同输入分组的精确整数优化，并回查所选组合的计数：

| 对该组允许的M错误上限 | 在本批评价标签上理论最少S错误 |
|---|---:|
| 0 | 1,537 |
| 48（不超过本组原模型） | 1,387 |
| 216 | 1,060 |
| 328 | 920 |

其中M≤48的解实际使用46条M错误，正确识别921条S。说明当前2,243条S错误中至少存在有限样本层面的改善空间，也说明在这个输入表示和保护条件下，本批S召回至多约39.9%。**这个上限利用评价标签求得，不是训练可达到的保证，不是未来环境上限，也不提供可部署规则。** 表中的216只是假设预算，不把其他行为组的M错误预算挪用到此处。

再查现有拟合侧的目的端口证据：

| 在同类TCP方向的拟合记录中 | 对应评价S条数 |
|---|---:|
| 目的端口从未出现 | 683 |
| 目的端口出现过，但未伴随S | 1,268 |
| 目的端口有S记录 | 357 |

即使放宽到全部ASA，仍有623条S的目的端口未见，1,076条S的目的端口只伴随其他标签出现。纯端口查表显然不足，原样增加训练轮数也不会补出这些目标条件的监督证据。

拟合侧存在23,325条同方向、两端端口可见的TCP（M=23,004、S=321），屏蔽源端口后可构造相同的粗可见模式，但S占比只有1.38%；自然缺源端口评价组S占比13.53%。因此随机屏蔽只补“看起来像”的输入，不能保证补出真实缺失机制的条件分布。不得用评价比例给这些行重加权。

最小下一项：在拟合侧自然存在的单端口缺失组与按预定规则屏蔽得到的组之间做迁移对照，单独报告未知端口、已见端口无同类支持、已见有同类支持三层；保留实际端口但不把查表正确当作行为掌握。若训练侧找不到支持可迁移区分的剩余事实，将这部分明确列为监督覆盖/不可区分限制。v5.3已做过106,953条ASA原文核对，未找到已审行为字段的新遗漏；本次没有新迹象需要重复全量原文扫描，更不能恢复身份、区域编号和绝对时间来追分。[原文审查边界](V53_ASA_EXECUTION.md)。

## 4. P1：逐类保护必须进入校准选型，并与部署难点匹配

位置：[当前选型函数](../training/run_v56.py)的`rank`使用`max(rates)`；一个极差条件可以遮住其他条件的退化。当前外层行为组隔离，而内层校准主要按正文组分开，未同样要求行为组合未见，校准表现可能不代表外层迁移困难。

不需要先看评价答案才能发现风险：本次用**已经保存的校准输出**重算逐协议×六视图×M/S不退化条件，12个共享候选全部至少有一个分项失败。behavior_1已选配置在缺源角色校准上S错误225→321，已经出现+96；评价上对应退化放大为+995。因此这轮并非只有评价后才有预警。

behavior_0完整校准表现是M错196→350、S错1,042→770，评价却是M错1,192→876、S错867→1,061，取舍方向反转。新增194条S误判全部来自UDP、outside→dmz、源端口缺失/目的端口可见。需要跨条件学习和验证，单一全局偏移不能稳定解决这两个方向不同的问题。

下一项规则：先在校准侧逐项比较相对同协议基础模型的M/S错误变化、威胁→正常和正常错误；不符合则使用零修正或停止，不从全都失败的候选中强行挑一个。选型记录不只保存一个最大值，而是保存完整风险变化向量。内层增加预定的行为组合留出；同一正文及其所有增强副本始终属于同侧。增强后投影重合须另行报告，不能继续声称这些可见组合完全未见。

这项后验审查没有修改v5.6的预定门槛和失败结论。未来若严格逐类保护没有可行方案，应如实报告取舍；不能反复调规则直到历史开发集通过。正常评价仍是同4条记录，不能以它们通过来证明实际低误报。

## 6. 执行顺序及停止点

1. **先修复新共享分支的字段适用范围和空值重复计分，再做一次同配置重训对照。** 这是当前有直接撤参证据、成本最低的对象。撤参诊断本身不作为新模型。
2. **若仍有明显缺失条件能力缺口，再做独立缺失条件修正。** 冻结完整分支，加入零修正对照，辅助梯度不改变完整输入行为；不重复v5.5所有视图共用网络的做法。以逐类校准条件决定是否评价/扩大，失败不继续扫描。
3. **TCP自然缺端口作为单独的覆盖验收。** 使用拟合侧自然缺失与人工缺失对照，不靠复制行或重设类别比例制造支持；同时报告同输入冲突和M保护下的可区分空间。没有训练支持则不承诺解决。
4. **最后才测样本外残差学习。** 前三项仍显示两阶段学习有必要时，以相同结构、分组划分与预算对照；不同时加深网络、调阈值和改损失。

当前完成的是机制审查与下一轮方案细化，不是以上训练。没有证明需要新增算力；这些限定对照可继续在本地CPU做，无需上传平台执行包。继续仅用官方数据，正式入口不变。
