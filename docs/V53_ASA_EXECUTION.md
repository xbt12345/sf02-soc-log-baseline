# v5.3 ASA 专项：信息、组合能力与关系变化的分离实测

2026-09-14。**已完成原文全量审查、16 个 EBM 模型对照、4 个拟合侧完整组合计数模型及独立回放。确实修复了部分模型能力缺口，但没有候选通过全部预设条件，ASA 尚未解决。** v5.1 仍是保留的局部开发起点，公共 B 和正式提交入口没有替换。

本次仅处理允许开发的 **106,953 条 ASA**，另纳入现有 **16 条正常 ACL 拒绝连接**作为相关反例。仅用官方数据，本地 CPU 完成；未使用平台、未补外部训练数据、未修改官方标签，也没有重新启用产品名、绝对时间、IP 身份或脱敏编号。

## 1. 先回答：信息丢失，还是模型能力？

三者同时存在，不能用一个结论概括所有错误。

### 1.1 当前没有找到新的明确行为字段漏提取

独立解析器逐条完整匹配 106,953 条 ASA 原文，将其拆为报头、动作、协议、源/目的端点、ICMP type/code、ACL 名及哈希。对动作、阻断结果、协议、可识别方向角色、严格可读端口、ICMP 类型/代码的比较，**未匹配 0 条、已审查字段差异 0 条**。

完整真实端口值保留；不从 `CRED-数字` 等脱敏标记猜回原端口，不把缺失哨兵当真实端口。这个结论只覆盖已审查的可读行为字段，并非证明所有上下文都已保留。

发现 **215 个相同保留事实但标签混合的组，涉及 23,220 行**。每个组都只有一种独立提取的安全行为观察。在“每折、相同观察必须同答”的条件下，本批开发记录至少产生 **1,970 条错误**。这是有限数据中的冲突下界，不是官方错标数量、真实 Bayes 错误或可保证达到的成绩。

原始字符串并非完全相同。只做诊断时，恢复目的区域后缀可将该下界从 1,970 降至 1,002；恢复源 IP 字符串或原始报头可降至 0。这说明它们可以区分记录，**不能说明它们能区分攻击**。区域编号可能关联未提供的资产上下文；脱敏端口的真实值也可能已经不可恢复。没有可信含义和跨环境证据时，不把这些字符串重新送入分类器。

Cisco 将 106023 解释为 ACL 拒绝了一个报文，并指出持续同源事件可能涉及扫描；这不提供本题 malicious/suspicious 的划分规则。当前也没有可信的会话关联或标签定义，不能自行把单条 deny 等同攻击、把同源日志拼成已证实的攻击链。[Cisco 原始文档](https://www.cisco.com/c/en/us/td/docs/security/asa/syslog/asa-syslog/syslog-messages-101001-to-199021.html)

### 1.2 组合表达不足已有直接反证

这里的“同标签/相反标签”是**事后诊断子集**，不是给模型提供评价答案。

| 拟合侧相同观察的支持情况 | 评价行数 | v5.1 错误 | N_PAIR 错误 | 完整组合＋v5.1 错误 |
|---|---:|---:|---:|---:|
| 只见过与该评价行相同的标签 | 12,901 | **1,532** | **364** | **0** |
| 只见过与该评价行相反的标签 | 1,311 | 921 | 1,171 | **1,311** |
| 两类标签都见过 | 21,233 | 2,423 | 2,376 | 2,410 |
| 单个事实值见过，完整组合未见 | 20,232 | 442 | 300 | 442 |
| 至少一个事实值在 ASA 拟合侧未见 | 51,276 | 654 | 618 | 654 |

N_PAIR 在第一行修复 **1,168 条，新增错误 0 条**，覆盖 579 个正文组；因而不能继续把这些错误都归为“数据没信息”。其剩余 364 条来自 177 个正文组，对应拟合侧只有 2–8 条同输入原始记录；记录次数也不等于独立事件次数。

完整组合对照将第一行全部修正，却让第二行全部判错。它在本批上展示了足够的记忆能力，同时展示了依赖历史同输入标签的代价。**从“能记住已见组合”到“能判断新环境”，中间仍有实质缺口。**

## 2. 实际执行的对照设计

新方法采用 [InterpretML 开源项目](https://github.com/interpretml/interpret) 的 EBM，利用可检查的单字段作用和组合项区分表达能力。官方 API 支持名义类别及交互项；本轮验证每个拟合侧可见值独占类别，没有合并不同真实端口。[官方 API](https://interpret.ml/docs/python/api/ExplainableBoostingClassifier.html)

固定两项因素，四个候选分别在原三折和旧宽模板压力划分训练，共 16 个模型：

| 名称 | 表达 | 训练输入 |
|---|---|---|
| N_MAIN | 各事实单独作用 | 原始可见事实 |
| N_PAIR | 单字段＋10 个预先列出的事实组合 | 原始可见事实 |
| A_MAIN | 各事实单独作用 | 完整事实＋5 种部分信息视图 |
| A_PAIR | 单字段＋相同的10个组合 | 完整事实＋5种部分信息视图 |

组合包括协议与方向、协议与端口、源/目的端口、ICMP 类型与代码以及协议＋源角色＋目的角色。A 使用完整输入权重 0.5，其余五视图各 0.1，每条原记录总权重仍为 1；不去重、不重复降权、不改标签。视图删掉相应端口/角色后，重新构造组合，防止组合项偷偷保留已删信息。

均固定 1,200 轮，关闭早停，不按评价成绩选迭代轮数、阈值或类别权重。三折隔离正文组；旧压力同时隔离正文组与旧 union 组。**原三折不声称隔离旧 union 组。** 这些数据此前已查看，全部结果属于开发与压力诊断，不是新盲测。

v5.2 曾提出先做拟合侧选择。本轮改为四个固定候选在全部四个既有协议上的有限因素对照，没有实现或声称完成内层选择；因此不据此自动选出可部署模型。

最初原生端口交互分配过大的类别乘积，单个工作进程内存超过 8 GB。停止两个未完成训练后，改为只存储实际出现的组合类别，不枚举所有端口组合。两个已完成 N_MAIN 对照原样复用并核对概率；其余 **14 次新拟合**在修订配置下完成。合计 **16 个完成的 EBM**，不把两个中断尝试算作完成，原失败目录保留供追溯。

追加容量对照：四个协议各构造一个完整事实组合的三类计数表，保留原记录次数和混合标签。对见过的输入使用 `(拟合侧类别计数＋原模型概率)/(计数总和＋1)`，未见输入严格回退原模型。分别搭配 v5.1 与 A_PAIR，形成 JOINT_V51/JOINT_A_PAIR；**这是固定平滑的能力对照，不是概率校准保证**。未按评价结果调平滑量，未按“纯标签组”筛选训练。

## 3. 分类结果：总分改善，但必须保留失败结论

以下都只统计同一批 ASA；M=malicious，S=suspicious。压力 S 共 733 条。每类错误包含被误判为正常的情况。

| 模型 | 三折总错误 | 三折 M 错误 | 三折 S 错误 | 压力总错误 | 压力 S 正确数 |
|---|---:|---:|---:|---:|---:|
| v5.1 | 5,972 | **554** | 5,418 | 827 | **48** |
| N_MAIN | 5,563 | 746 | 4,817 | 827 | 48 |
| N_PAIR | **4,829** | 796 | 4,033 | 759 | 10 |
| A_MAIN | 5,755 | 686 | 5,069 | 835 | 48 |
| A_PAIR | 4,901 | 560 | 4,341 | **739** | **0** |
| JOINT_V51 | 4,817 | **1,256** | 3,561 | 827 | 48 |
| JOINT_A_PAIR | **4,637** | **1,090** | 3,547 | 739 | 0 |

N_PAIR 相对基线修复 1,629 条，新增 486 条错误，净少 1,143 条，错误率相对降低 **19.14%**。其三折 ASA 两类 Macro-F1 从 0.923684 提升到 0.939573；收益并非全部集中于一个模板，修复涉及 716 个正文组，但最大单组贡献仍为 148 条，须保留这种集中度信息。

以下问题导致不替换当前模型：

- N_PAIR 的三折 M 错误增加 242 条，压力还出现 **18 条恶意→正常**，不能用总分抵消。
- A_PAIR 的三折 M 仅多错 6 条，但压力 **733 条 S 全部错误**。压力总错误变少主要来自偏向 M，不能称为迁移成功。
- JOINT_V51 的完整组合记忆让 M 错误从 554 变为 1,256；其压力 **7,571 条全部是未见完整组合**，输出逐条等于基线，没有新增迁移收益。
- JOINT_A_PAIR 虽然总错误最低，M 错误接近基线两倍，且继承压力 S 召回为零的问题，停止作为当前替换候选。

单独使用完整组合频率、对未见键回退类别先验的负对照，在压力上会全部判 M，错误只有 733，却没有任何 S 召回。它直接说明为什么不能按最小错误数或总体准确率选方案。

四个 EBM 均正确识别三折中的 16 条正常 ACL 反例，基线原来全部误判；这是一个局部改善。但这些正常记录仅 8 个正文组，旧压力没有正常评价记录，**不能据此声称正常网络误报率已经可靠**。完整计数回退 v5.1 的候选没有修复这16条。

## 4. 缺失信息处理：有明确收益，也有适用边界

比较 N_PAIR 与 A_PAIR，以下只统计原来具有被移除字段的同一批记录，不能横向把不同分母当成同一测试。

| 输入条件 | 受影响行数 | N_PAIR 错误 | A_PAIR 错误 |
|---|---:|---:|---:|
| 完整观察 | 106,953 | 4,829 | 4,901 |
| 移除源端口及范围 | 70,766 | 2,051 | 1,477 |
| 移除目的端口及范围 | 87,528 | 3,971 | 3,971 |
| 移除双端口及范围 | 99,334 | 4,165 | 4,171 |
| 移除源方向角色 | 106,451 | 28,417 | **4,815** |
| 移除目的方向角色 | 106,953 | 28,375 | **5,191** |

部分信息训练能大幅缓解“一个方向字段不见了就几乎全部判某类”，因此**保留这一机制的研究价值**。但它不能恢复已丢失的实际信息，去目的端口没有分类收益，去双端口还多错 6 条；去源端口时虽然总错误下降，S 错误仍从 639 增至 679。完整输入概率损失也从 0.180425 升到 0.189789。

这轮没有确认它对所有缺失来源有效，也没有确认真实平台的缺失机制。不能把“适应了本轮人工移除”写成“所有真实缺失数据都解决”。

## 5. 对抗性审查及完成边界

| 反证问题 | 本轮实际证据 | 结论 |
|---|---|---|
| 会不会仍漏掉明确可读信息？ | 全部106,953条完整语法核对，所审字段0差异 | 暂无新的已证实解析遗漏；不继续无依据重写输入 |
| 会不会仍偷偷依赖时间/产品/身份？ | 706条真实记录外层字段替换；其中690条改报头、端点身份、区域后缀、ACL及哈希 | 指定变化下路由、事实及预测保持一致；真实角色和端口未改 |
| 会不会只是学不会完整组合？ | 1,532→364→0 的表达容量对照 | 部分确实是模型能力；修复这部分不等于整体通过 |
| 会不会靠记忆制造高分？ | 完整组合使相反标签子集921→1,311错误，未见压力输入全部回退 | 纯记忆路线不通过 |
| 会不会把缺失字段藏在交互项中？ | 删除后重新构造组合，5项边界测试通过 | 指定视图没有残留被删值 |
| 会不会用多数类掩盖崩溃？ | 压力逐类统计暴露 A_PAIR 的 S=0/733 | 该候选不替换 |
| 会不会报告和模型不是同一份？ | 原始训练文件重新哈希；拟合侧类别逐项重建；从保存的分箱表/线性系数独立计算概率 | 数值和来源核验通过，不等于质量通过 |

独立核验覆盖 EBM 的 **2,748,960 行三类概率**，以及完整组合与 v5.1 回退的 **2,061,720 行三类概率**；最大差在浮点精度内（EBM 为 2.22×10⁻¹⁶），类别决策一致。另有 2,888 行保存 EBM 的原文关联预测复核。706条原文选择覆盖全部215个混合观察组，并包含额外错误正文与全部16条正常反例。

本轮安装 `interpret-core 0.7.8`，其他已有依赖未升级。模型、配置、划分、逐行预测、错误子集及源文件均已保存。没有把审查通过、单个子集零错误或分数上涨当成部署通过。

## 6. 调整后的后续方向

**停止三项已被本轮反证的做法：直接替换为当前 EBM 候选、把完整事实查表作为主判定器、用同一比例的字段移除训练宣称所有缺失问题解决。** 保留原始数据及失败证据，不重复跑原配置。

后续只沿 ASA 的两条尚有证据的轴推进：

1. **组合能力与稀疏支持一起处理。** 保留单字段与组合表达，但组合修正要按拟合侧独立正文组支持进行部分共享、收缩；将“有相同输入”“只有较低阶证据”“完全无支持”分开报告。不能按评价标签是否一致分流，不能将同一正文的重复次数当作独立可信度，也不恢复失败的简单重复降权。下一次比较必须同时给出已见同标签、相反标签、未见组合和两类错误，未见组不能只回退后冒充新收益。
2. **完整输入和部分信息目标分开选择。** 本轮缺角色训练有效，但固定六视图混合伤害部分完整输入和压力 S 类。下一项若实施，应在每个外层拟合侧内部按正文组划分，比较完整视图与部分视图的共享/独立参数，选择只用内层结果；配置选择完成后再固定到外层。每个内层拟合侧必须重建词典、组合和计数，不能直接拿训练过内层评价行的 v5.1 输出当无泄漏选择依据。

这两项是**下一项待执行实验**，本轮没有声称已实现分层收缩或内层选型。它们仍不能解决相同可靠观察对应不同真实意图的问题。对215个混合组，当前已完成可读字段核对和冲突清单；能继续争取的是资产角色含义、可靠行为关联或标签判定规则，而不是再换一种编码。用户目前只使用官方数据，因此保留这项不可识别边界，不自行补标签或抓取其他训练集。

下次候选继续要求：三折总错误严格下降、M/S各自不退化、至少两折改善、不增加恶意/可疑→正常、正常ACL不变坏、压力总错误与两类错误均不变坏。进一步声称泛化，必须在未见组合子集有实际改善；已反复查看的开发折即使重新划分也不称为新盲测。当前尚无证据保证这些条件可以仅靠模型同时满足。
