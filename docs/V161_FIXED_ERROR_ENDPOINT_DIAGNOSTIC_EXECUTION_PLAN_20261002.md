# V161 固定旧错误目标：三终点有限诊断执行登记

V160 的实际角色 2 安全方向降低完整 CE，却提高旧错误 CE。V161 本轮只改变学习目标：固定 B 终点合法 OOF 的非冲突旧 M/S 错误，目标 stable CE 保留原频数，除以该角色完整原类质量。全输入、模型、参数起点、意见成员及原数值阈值不变。固定目标共 6,824 条角色记录、4,614 条独立原行，混合原行仍前向、保留监督记录并全部计分。

每类实际测量两次全 1,060,832 维目标梯度，保存两份后按原四段 8eps 检查。实际候选沿用 16eps 有效下降及 Armijo；不以完整 CE 不增作为门槛。完整 M/S 各类原行错误不得比固定起点增加；已验纯正确、固定终点新修复、部署全部正确及既有联合技能逐行保护。每个候选保存原行 q/logq、原频 CE、来源账本、旧错间隔及分类变化；异常和成功后均恢复原参数。

三个角色各最多 3 轮、每轮固定 20 个步长 `2**(-j), j=0..19`。原角色 0/1/2 缓存 1/3/1 个已重复检验的保护法向，只对真实失败候选新增全部阻挡函数，不按梯度相似性去重。法向总数每角色最多 24，新增法向各实际成对测量，新增间隔梯度上限 46/42/46。
