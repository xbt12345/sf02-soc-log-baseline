## 3. 下一可执行动作：冻结字段解码诊断

当前训练执行会话已明确准备第一层/当前V146第二层×三折，共 **6 次解码拟合**；本报告不将准备计作已执行，也不把诊断拟合隐藏成零计算。它不改原M/S分类器，但依然需要独立记录模型参数、数据角色、计算和真实结果。

执行前应绑定实际缓存/模型、合法来源角色、事实目标、频次、解码器、固定超参与终点，封存源码和依赖；拟合后父侧从原行独立复核。基座已见过内部留出行的分类标签，内部诊断不得称新盲测；已有外折也已多次查看，保持开发边界。

最低解释要求：

1. 原始完整值准确率：对已观察源/目的端口报告整个端口整数是否正确，不以大多数0位的逐bit高准确率代替；合法0端口、未知65536、ICMP不适用分别报告。ICMP类型/代码同理。
2. 类别/角色分母：协议、源/目的角色逐类别报告，缺失不当作正确常量。保持正确的稀缺对照，记录合法事实支持及新组合/新值。
3. 同频次常量对照：逐字段基于合法拟合原频次构造固定常量，不用留出真值取最优常量；高解码分数必须超过其适用范围的无信息对照。
4. 来源边界：拟合区、内部主体留出和外折分开；检查底层输入/主体的重叠，不用支持或局部解码成绩挑层、权重、端点。相同底层输入的浮点变体只算原始真实出现频次，不算新独立信息。
5. 读出限制：线性解码失败最多证明该固定读出不足，不能单独证明信息被销毁。是否需要更强的读取对照，依据失败模式和事前预算决定；若采用新范围，另行登记而不后验调整本轮解码器。
6. 任务分离：字段读取收益不算M/S分类收益。字段已可稳定读取而M/S仍错，下一步必须转查类别对应、同类支持和上下文；不在事实重建方向追加权重硬追。
