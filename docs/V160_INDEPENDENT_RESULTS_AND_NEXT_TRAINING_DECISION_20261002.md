## 两个停止的根因与反证

角色 1 的第二轮方向：一个保护坡度为约 -2.29e-15，超过其计算误差界，因此原独立证书正确拒绝该实际方向。三个法向的奇异值约 2.5676、0.01570、0.01019，条件数约 251.9。仅对保存方向在原法向空间内进行固定三次向内重构，最大方向变化 4.06e-13 后，原独立符号证书通过，两类坡度基本不变。**已返回方向不合格，不等于该局部约束集合没有合格方向。**

角色 2 的原对偶间隙 9.77e-20 超过固定界 2.24e-20。普通 float64 原单位重构与三次残差校正仍未稳定通过，失败保留。对已识别的两自由变量 active set，用 Decimal 80 位对保存原向量内积、二元系统及重构进行独立计算，转换回 float64 后的 fsum 间隙为 2.12e-22，原界仍为 2.24e-20，原符号证书也通过；最大方向变化 3.83e-15。没有修改数值验收阈值。

可复现见证：`training/v160_saved_numeric_obstruction_witness.py`，实际 exit 0，输出 `artifacts/v160_saved_numeric_obstruction_witness_v2_20261002/witness.json`，绑定全部输入和源码哈希。它只证明固定保存 active set 的数值见证；不是通用替代求解器资格，未证明真实有限保护或分类修复。Windows 当前 `np.longdouble` 的尾数仍为 52 位，不能作为高精度替代；首次 JSON 的 NumPy bool 序列化失败也已记录。

## 为什么角色 0 不能仅凭“没有翻类”判无效

实际两类风险下降分别为 8.88445e-5 和 8.88018e-5，均远大于既定分辨率。与固定端点相比，OOF 和部署的每条分类完全相同，没有新增错误，也没有新增修复。

但原错误行确实朝正确边界移动：

|类别|原错误行|正确标签对原竞争类间隔改善|中位间隔增量|原错误间隔中位数|原错误 CE 总下降|
|---|---:|---:|---:|---:|---:|
|M|1,886|1,886|+0.003621|-0.78838|6.92416|
|S|1,414|1,400，另 14 条变差|+0.003121|-27.63098|3.92793|

原正确行 CE 略升但分类全部保持。风险收益主要来自原错误行，不是只强化已经正确的判断。数据来自 `artifacts/v160_independent_safe_probe_error_progress_20261002/review.json`。输出权重最大绝对值原为 1.91113e-5，此安全探针最大输出权重改变量为 0.00390625；只是临时探针，原参数已恢复。

S 翻类距离值得单独监督：固定基线为 `log(mean16p.clamp_min(1e-12))`，831/1,414、813/1,160、319/892 条三角色 S 错误的正确类平均意见低于该下限。角色 0/1 的 S 错误间隔中位数接近 -27.631。**目标概率极小与精确为零不同**：前两角色这些 S 错误并非 16 成员全部精确给零。证据为 `artifacts/v160_independent_fixed_opinion_floor_review_20261002/review_v2.json`。

这定位了“损失下降但尚未跨边界”的距离因素，尚不能证明调温度、改先验或换初始化会提高分类；下一轮不同时修改这些因素。

## 递进执行顺序与判定

1. **修计算，不改问题定义。** 保留模型、原输入、原频原标签、原数值验收和全部保护。为已识别 active set 增加有界高精度/残差 polishing 和向内重构，完整记录原、修正方向及代价。不得以扩大阈值、对角阻尼、删约束或只保留成功角色作为修复。通用方案须通过既有小分量、单位缩放、消去、重复、相反类、无下降、曲率反例，以及三个真实保存端点。
2. **再证实有限安全。** 新入口和调用预算单独封存，实时断言 Python/依赖版本。对角色 1/2 的修正方向重放完整原人口 q/logq、两类下降和逐行保护；不能直接把保存方向见证当成有限步通过。失败记录数值、分类、曲率、约束/预算等具体原因，不能统称收敛或全局无解。
3. **通过资格后，登记有界学习轨迹。** 仍只探索保护约束方向这一因素。每个实际接受状态记录 M/S 原错误数、原错误间隔分位数和改善/恶化数、已修复及新增错误原行、实际损失、四段参数/梯度尺度与约束阻挡。保护当前端点已有正确行和后续接受的修复，防止 V159 的已修复行被后续改回；这项加强须在新训练契约中明确，不能冒称旧保护已覆盖全部增量修复。
4. **不提前截断，也不无限加预算。** 第一步没有翻类不能成为无效判据；错误间隔实际推进只能算中间证据。观察预登记的一段真实接受轨迹，再依据原行分类修复、距离变化和保护阻挡决定延长、停止或切换方法。真实 last-5 状态不得补齐、挑优或复制。不得靠平均 CE、部署冻结路线的高准确率代替学习完成。
5. **验收保持原目标。** 三角色合法 OOF 的非冲突错误仍须实际解决，部署原有技能保持，全部原行和不可区分冲突继续计分；之后再查全 N/M/S 各类召回、误报和来源表现。曾查看的外层仍属于开发审查，不能称盲测。只有第一问题验收后，才转向细行为支持与跨来源修正稳定性。

当前不批准原配置重复全训练，不把第一问题标记完成。下一正式训练是否值得放大，以上述真实有限资格和有界轨迹判断；不能承诺新方法必然显著提升。

## 调研及适用边界

- [GEM 原论文](https://papers.neurips.cc/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf)提供受保护梯度投影思路，但依赖局部线性近似，保护任务平均损失不等于保护每条 argmax；本项目仍必须执行逐行有限保护。
- [GEM 对偶推导修订](https://arxiv.org/abs/2107.07384)提示不能照抄历史 QP 实现而跳过原问题与对偶复核。
- [OSQP 官方求解说明](https://osqp.org/docs/solver/)区分残差、不可行证书与 polishing；可借鉴“固定活动约束后提高求解精度”，不能直接用其 success/默认容差替换本项目实际验收。当前并未安装或采用 OSQP 做官方更新。
- [SciPy least-squares 文档](https://docs.scipy.org/doc/scipy-1.15.3/reference/generated/scipy.linalg.lstsq.html)明确 rank 截断和奇异值条件数。保留原基与全奇异值，避免把被删去的小方向隐藏在保留子空间的 condition 中。

这些资料证明方法和适用边界，不证明本项目分类会提升；最终仍以实际原行结果为准。
