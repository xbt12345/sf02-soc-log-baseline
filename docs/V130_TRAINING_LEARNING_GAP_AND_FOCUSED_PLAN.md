# V130：先解决训练侧未学会分类

日期：2026-09-30。本轮为只读结果复算、方法审查与训练方案设计，**新增模型拟合0次、优化更新0次**。最新实际训练仍为V128：21次拟合、26,700次神经更新，质量失败，无模型晋升。

当前决定：按用户指定顺序，先解决训练侧分类缺口。V129的直接输入与交互研究依据保留，其R/D/X三折九拟合方案暂缓；不同时处理同类支持缺口与跨来源修正迁移，不再用外层总错改善代替训练侧学会。

## 1. 重新界定问题：样本参加过训练，不等于学会

本轮按官方原行真值重新计算三折的训练角色。ASA共有112,807条原行，每条分别参加另外两个折的训练，账本225,614条是训练角色数，不能当成新增独立数据。官方完整数据仍为2,056,871条。41项源文件身份、原行标签、保存概率与逐行判决已独立复核。

| 训练角色 | V125旧直接模型M错误 | S错误 | 实际完整数值输入无混标的S错误 | 所涉及训练来源组 |
|---|---:|---:|---:|---:|
| 第0折 | 14 / 58,840 | 665 / 33,497 | 643 | 138 |
| 第1折 | 0 / 38,886 | 531 / 2,071 | 527 | 145 |
| 第2折 | 8 / 59,770 | 676 / 32,550 | 650 | 134 |

第1折总训练正确率约98.70%，但S只判对1,540 / 2,071，召回74.36%。这是已见训练记录上的分类不足，不只是外部泛化差，也不能把145组的错误归结为几条异常。

规范头版本V124 B的第1折训练结果同样是M零错、S533错；其中按实际CSR输入重新审查仍有527条非冲突S错误。历史成员诊断显示397条S没有任何一个成员判对，说明至少这一部分不能只靠调整16成员平均方式解决。该成员数量来自历史已封存诊断，本轮没有重新推理每个成员模型。

V128第1折P_CF：S交叉熵3.1499→1.6383，S错误1,222→1,220；损失下降，但分类边界几乎没有解决困难S。50轮终点的1,220条S错中，**1,180条在有序正文输入上也没有同文异标签**。按真实完整CSR输入分组，非冲突错为1,214；旧报告按原local分组得到1,216。后续必须使用真实模型输入判冲突，不能沿用旧分组编号代替输入身份。

正文冲突不是教师分数加正文组合模型的不可解下界；基座分数仍可能带有其他信息。反过来，“完整输入不冲突”也不表示正文分支能看到完整区别。

## 2. 第一性原理：已证实什么，尚未证实什么

训练分类必须具备四个条件：区别进入模型；正确监督进入优化；可训练参数能表达区别；训练过程使真实判决改变。总CE或总正确率不能替代其中任何一个条件。

**已经证实：**训练侧仍有大量输入不混标、参加过监督却持续错判的S；这些错误跨许多训练来源；旧冻结教师加正文修正不适合继续作为本任务首选。原行平均风险可以掩盖少数类严重错误，但这不证明旧模型已经达到该风险的全局最优。

**尚未证实：**究竟主要是当前风险目标下的学习取舍、128维表示/参数共享能力、固定预算不足，还是梯度和数值链路存在问题。不能直接宣布“必然是梯度饥饿”，也不能因小样本可记忆就宣布泛化解决。下一轮对照专门辨别这些原因。

当前完整合法表示是规范头文本的byte 1/2-gram、既有事实及独立记录字段；它不是完整保序原文。原文和有序正文继续保留。此次先验证这套真实表示中可区分输入的学习能力，不声称它已经完全保留语义。

## 3. 一个必须排除的新反例：盲目类别平衡会制造M错误

第1折规范输入有一个数值完全相同的输入组：72M、6S；训练总体为38,886M、2,071S。

按原行CE，这个输入独立最小化损失时偏向M。若全局改为M/S各占一半，两个标签的有效质量变成72/38,886与6/2,071，后者更大；不受模型容量限制的逐输入最优S概率约0.6101，判S会错72条M。这是解析损失的独立输入反例，**不是新训练结果，也不等于有限网络实际一定收敛到该值**。

因此排除“给全部S加统一大权重”。新监督目标保留原行CE，只对训练内实际输入单标签的样本增加逐类风险：

`L_focused = 0.5 × L_original_rows + 0.5 × L_single_label_classes`

其中`L_single_label_classes`是训练内单标签输入的M、S各自原行平均成员CE，再取两类均值。真实混标输入仍参与原行CE及所有评分，只不获得该辅助项；不改标签、不删样本、不把多数标签写回原文件。纯输入资格仅由合法训练标签计算，禁止使用留出标签确定。

该目标给稀缺、明确的监督独立作用空间，同时避免对冲突输入强行放大少数标签。系数0.5是本次预设试验选择，并没有本项目实测收益；它不是被证明有效的去偏算法。是否只是移动边界，必须靠同时保护M和旧正确S来判定。

## 4. 执行阶段一：真实困难样本的小批次拟合检查

已建立第1折纯训练诊断面板：527条非冲突困难S，以及相同正文下的344条训练M，共871条原行、314个不同规范数值输入、197个训练来源组。六种正文同时含M/S，但完整数值输入各自单标签；同正文不代表两类真实安全语义已经确定。

已据输入哈希固定64个不同输入，32M、32困难S，六种同正文双类对照都覆盖；所选原行质量为206M、70S。来源、旧预测和标签仅用于合法训练诊断与采样，不成为模型特征。

- 同完整合法输入，直接训练128维及256维模型，共2次小拟合；没有教师分数或冻结残差。
- AdamW，学习率0.002、weight decay=0，只用于排查训练链路；每次2,000步，使用同一完整64输入批次和所选原行质量。
- 保存0/1/10/100/500/1000/2000步状态。终点M/S均零错，最差集成真值概率至少0.90，才取得小批次学习资格。
- 若两个模型都失败，暂停大训练，先核查真实稀疏/稠密前向与梯度、目标对齐、输入精度、激活和参数更新路径。失败只表明当前实现/配置/预算未通过，不证明标签或任务不可解。
- 小拟合模型随后丢弃；正式对照从相同登记初始状态重新开始。小批次成功只证明这些训练输入能够学会。

这采用了[Karpathy的训练排错方法](https://karpathy.github.io/2019/04/25/recipe/)和[CS231n的训练检查](https://cs231n.github.io/neural-networks-3/)中的“小样本先拟合”做法。它是训练调试经验，不是本项目成绩承诺。

## 5. 执行阶段二：目标×容量四臂，先在最差训练角色解剖

不换输入、标签、折、成员数、批次质量和优化器，一次只隔离两个具体因素：

| 臂 | 隐藏宽度 | 目标 | 能回答的问题 |
|---|---:|---|---|
| R | 128 | 原行CE | 同一直接模型延长预算是否足够 |
| O | 128 | 原行CE＋单标签逐类辅助 | 目标取舍是否造成明确S学不充分 |
| C | 256 | 原行CE | 增加表示容量能否在原目标下解决 |
| CO | 256 | 同O | 是否需要目标与容量共同改变 |

四臂都使用完整第1折合法ASA训练人口：40,957原行，38,886M / 2,071S。不会只训练871条面板，面板只是单列审查对象。

共4次正式拟合；均100轮，256个旧local为逻辑批次，原行计数不变，每臂3,200次更新。AdamW 0.002 / weight decay 0.0003，固定常量学习率；基础初始化seed10201、批次seed10201+fold，尽量保持历史直接模型口径。此次不再叠加学习率搜索、焦点损失、批次重排、对比损失或正文Transformer。

100轮是预登记的诊断预算，**没有证据保证足够**。R自身25/50/100轨迹用于判断预算；历史不同输入或随机状态的终点不能直接作延长预算的因果对照。

128宽度两臂初始状态一致，256两臂初始状态一致。扩宽复制共同128块，额外通道随机初始化；额外输出和额外到共同通道的连接初始为零，要求新旧初始输出差≤1e-6。不能将全部新增参数置零导致死通道；初始部分梯度为零是预期，需再核查第1/10/100次更新后的真实梯度。此初始化及完整训练器尚未实现和实测。

采用每个成员独立CE的平均，推理平均概率；这与[TabM作者官方训练说明](https://github.com/yandex-research/tabm)一致。现有SparseTabM是自定义稀疏适配器，不把论文成绩套用到本项目。增加宽度也不保证泛化更好。

## 6. 训练侧成功指标：必须修复错误并保留正确判断

第1折100轮终点，全部同时满足：

1. 全部38,886条训练M继续零错；相同正文下344条M也零错。
2. 原527条困难S剩余错误≤26，即至少修复95%；旧正确训练S新增错误为0。
3. 全训练S非冲突错误≤26、S总错误≤32。数值输入冲突经验最少6错仍计入总错误，不从分母去掉。
4. 原145个困难S来源组中，仍有错误的组≤29，避免只记住一个大组就取得资格。

这是本项目的新训练学习目标，**目前没有任何新模型达到它**。总CE下降、某一轮临时通过、S改善但M退化都不算解决。要求全部训练M正确是这个已有基线零M错的训练角色约束，不是所有未来外部数据必须零错的普遍承诺。

新留出预测文件先封存，四臂完成后仅根据训练资格按固定顺序R→C→O→CO选择最小改动路径，记录后才能读新留出结果。它是在寻找训练可行配置，不授予模型晋升权。全部不通过即停止，不挑临时epoch、阈值或种子追认成功。

## 7. 学会之后怎么推进，学不会怎么处理

- R100通过：预算不足得到该配置下支持，不增加新网络或目标。
- C通过而R不通过：支持扩宽在本条件下有效；不能宣称唯一原因是容量。
- O通过而R不通过：支持明确监督目标改善训练分类；仍要核查留出是否只是先验移动。
- 只有CO通过：记录容量与目标的交互，不把组合收益单独归功于某一项。
- 损失降而错误不降：训练分类未解决，记录置信度/成员/激活/梯度；停止无依据扩训。
- 两类出现此消彼长：保留失败证据，不能将S收益称为成功；不得放宽M预算。

获得训练资格后才将同一种配置固定应用第0/2折；若选中R则新增2次拟合，选中其他臂则加R100匹配控制、新增4次拟合。连同小拟合与主四臂，至多10次拟合、46,000次更新。训练资格不通过不触发这些后续拟合。

此时才报告训练侧与来源外逐类结果：训练变好、来源外不变表示只解决了拟合缺口；仍需另外处理细条件支持与稳定迁移。沿用旧逐类和全量质量保护，不降低2,170条ASA总错门槛或M318/S2,074保护；全量2,056,871原行、233个S来源组、未知参数、头部682、来源组2868及非ASA107错都保持检查。已反复观察的开发折不能叫独立盲测，阶段通过不能自动晋升。

## 8. 关键记录与研究方法的边界

每轮记录原行M/S质量、原行与辅助CE、真实M/S错误、527S/344M修复/退化、完整实际输入冲突、来源覆盖。检查点保存模型哈希、逐行与逐成员判决、分类margin、激活稀疏度、分模块梯度与更新范数。0/25/50/100轮做全训练M/S梯度分解，不更新参数。

[Gradient Starvation论文及作者实现](https://github.com/mpezeshki/Gradient_Starvation)提供研究线索，但V127已有“S仅5.06%却占零残差logit梯度55.55%”的本项目反证，不能说S根本没有梯度。要看梯度是否有效进入特征参数、是否发生持续冲突，以及真实分类是否变化；当前不直接采用Spectral Decoupling或梯度手术。负梯度夹角也不是算法适用性的证明。

历史V116早检查点错误、V118/V121批次重排失败、V104/V113/V128用M退化换S、V129事实压缩反例继续作为约束。新增“真实CSR分组不同于旧local”和“混标输入被类别平衡反转”两项反例，已经进入本轮设计核验。
