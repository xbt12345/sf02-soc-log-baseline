# V143 独立配对覆盖审查：支持定义过严，还是实际监督缺口

2026-10-01。最新实际训练仍 V142，第一问题在登记 TRAIN 范围通过；第二和第三问题未解决。本次零拟合、零参数更新、零模型梯度；不修改模型输入、模型概率、原始标签或历史交付。继续训练和交付由「SF02：逐项修复与下一轮训练」对话执行。

**新决定依据：严格配对为零不是所有可共享支持都为零；放宽源端口的配对检索要求确实找到支持，但直接覆盖的都是已正确记录，尚未覆盖本次 578 条双端口已知 S 错误。当前不以这个覆盖数启动分类器重训，也不把它说成第二问题已解决。**

## 已执行的真实检查

独立读取全 2,056,871 行官方标签和原字段、112,807 行 ASA 事实/预测，以及 10,620 行 VPC；再次核对 V106 指定的全量行/来源/折划分，ASA 和 VPC 根来源身份均一致。VPC 10,620 行全部独立按实际默认 14 字段解析检查，协议、目的端口、ACCEPT/REJECT 与前一审查一致。

在每个合法 TRAIN 补集内构建三种配对检索键：

- 完整事实精确相同。
- 仅放宽动态源端口的精确数值，保留已观测状态、动态范围及所有其余事实。
- 仅放宽 user/dynamic 源端口数值，仍保留其范围和所有其余事实。

这里只改“如何寻找候选同类记录”，不删除模型的源端口输入、不合成改端口的带标签日志、不将新的键当作类别查表。正对资格仍要求真实同类、至少两个不同隔离来源和不同数值输入；查询折标签仅用于事后覆盖诊断，不参与合法 TRAIN 配对。

## 正对增加，却没有直接覆盖当前已知端点错误

双传输端口都已知的 S：

| 检索粒度 | 三个 TRAIN 角色的正对组数 | 三个角色的可配对原行数 |
|---|---|---|
| 完整事实精确值 | 0 / 0 / 0 | 0 / 0 / 0 |
| 放宽动态源端口数值 | 6 / 3 / 5 | 4,368 / 281 / 4,271 |
| 放宽 user/dynamic 源端口数值 | 11 / 8 / 10 | 5,137 / 565 / 4,950 |

这些数是各 TRAIN 角色的频次，不是相加后独立样本量。

全部来源留出中，双端点已知 S 有 TCP 549 条、错 484；UDP 19,727 条、错 94。两项放宽对这 578 条错误的直接同类跨来源正对键覆盖都是 0。动态放宽匹配到 509 条 UDP，进一步放宽匹配到 1,031 条 UDP，全部已经正确；没有匹配到 TCP S。

因此不能将正对数量提升当成缺陷已修复。这不证明辅助监督必然无效：表示参数共享可能产生间接收益。但若要启动试验，仍需独立的参数/梯度机制证据，最终按完整来源外分类检验；没有直接覆盖必须保留在报告中，不能用新增训练次数掩盖。

## 源端口信息不能按这次检索方法从模型中删除

把检索键误当成分类表示，会增加合法 TRAIN 事实投影的混标经验最低错误：

| 放宽范围 | 三个角色新增投影最低错误 |
|---|---|
| 动态源端口数值 | 138 / 122 / 110 |
| user/dynamic 源端口数值 | 344 / 226 / 264 |

这说明精确源端口仍承载区分信息，或与未包含的上下文共同承载区分；不能宣称它全部无用。投影冲突不是完整模型输入冲突，本项目仍保留正文、完整端口和其他输入。

[RFC 6056](https://www.rfc-editor.org/info/rfc6056/)说明客户端临时端口可能由协议栈选择并随机化，这提供了检查“精确数值配对是否过严”的技术背景，但不证明本数据中任意高位端口都可改变而标签不变。本次没有做这种带标签干预。

另独立核对 63,208 条双传输端点已知记录，其中 59,732 条正文源端口与记录字段相同。正文/记录源端口不一致的 S 错误为 TCP 60、UDP 8，主要集中于单来源；一致的 S 仍错 TCP 424、UDP 86。不能把所有错误归因于字段不一致，也不能不经语义验证就把两字段覆盖成一个值。事实输入和独立记录字段继续保留。

## 跨格式补标签的实际反证

[AWS 官方格式与字段解释](https://docs.aws.amazon.com/vpc/latest/userguide/flow-log-records.html)说明 REJECT 描述安全组/ACL等拒绝或连接关闭后到达的数据包，不直接定义攻击类别。VPC 与 ASA 共享协议及目的端口，也不补齐 ASA 接口角色、细上下文和反类证据。

固定诊断规则：“在合法 TRAIN VPC REJECT 中有相同协议/目的端口，就将对应 ASA 查询判为 S”。只对已观测目的参数应用；未部署、未拟合、未覆盖模型预测文件。与 V142 实际逐行预测比较：

| 留出折 | 修复 S 错误 | 新增 M 错误 |
|---|---:|---:|
| 0 | 8 | 2,168 |
| 1 | 20 | 2,824 |
| 2 | 4 | 2,676 |
| 合计 | 32 | 7,668 |

这是直接复制标签规则的反例，不是所有跨格式无标签表征学习都不可能成功的证明。应拒绝把这些 VPC 标签当作已补齐的 ASA 细标签。
