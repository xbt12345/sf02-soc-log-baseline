# v7.4：信息保留、训练覆盖与完整三分类训练方案

日期：2026-09-21。当前仍无新模型晋升；v7.3 的完整开发回放为准确率 99.383581%、Macro-F1 77.430613%、M 召回 28.9923%、S 召回 94.0560%、总错 12,415。本文是下一轮可执行方案，不是新训练成绩。新支持审计只读取官方 train，重新运行冻结解析器，不读取 private 答案、不拟合模型。

## 1. 第一性原理结论与纠正

任务是对每个事件输出 benign / malicious / suspicious。成功需要同时成立：输入留下可区分证据，训练中有支持该区别的监督，学习器能利用证据，评价能反映目标分布。不能再把这四种失败统一解释成“模型能力不足”。

**原始数据不删除；不确定是否有用的信息也不永久删除。** 但归档无损、模型接收信息、模型真正利用信息是三个不同验收。将全文原样喂模型不会自动获得泛化；压成不同向量也不等于恢复了有效语义。不存在凭一次消融证明某字段在所有未来场景“绝对无用”的办法，因此默认保留原件，通过有版本的视图控制使用。

上一轮有两处需要纠正：

1. 不把上游设备判断、严重性、攻击技术信息一律认定为标签泄漏。题目明确允许对日志字段、原始脱敏消息和攻击技术标签建模。设备给出的真实观测有可能有用；直接复制目标标签、事后研判字段、仅在已见来源有效的映射则另当别论。未核清来源的信号保留、分支隔离、做消融，不永久丢弃，也不直接当真值。
2. 单一来源样本不能证明跨来源能力，但不应阻止其他有支持切片继续训练。允许训练内同来源/正文组对照，只如实限定结论。真正零支持的组合单独登记，不用“全项目必须每组满足三来源”作为无限延期条件。

## 3. 新的信息合同：保留原件，显式建模，失败不静默

### 3.1 原件与视图

- 官方 parquet 原文件及哈希、行定位、event_id 始终保留；NULL 与空字符串原状态不混淆。派生文本不覆盖原件。不能恢复主办方脱敏前的信息，不猜 CRED/USER/ORG 标记的原值。
- 每个解析字段/未解析片段保存原文区间、原始值、类型、转换方式、进入哪个模型分支；区间要覆盖全文，不重叠遗漏，不先 strip 再假装原字节完整。变换后仍能按原引用重建原消息并匹配摘要。
- 状态至少区分：真实空、解析失败、脱敏不可解释、可读但未建模、词表/编码未覆盖、长度限制。完整性审计不是把一个 `unsupported` 标记加入模型就完成。
- 长消息覆盖全部分块，不只截前 N 个字符。分块必须保留边界上下文、覆盖账本；一个事件最终只有一份监督损失，不能长日志切成十块就有十倍训练权重。

### 3.2 进入分类器的三个视图

1. **行为视图**：保留动作、对象、否定/引述、结果、请求/命令/参数、协议、完整可见数值及原始单位。端口、流量值不因过去某方案失败就全删；不要用缺失哨兵伪装真实端口。原始数值与语义派生可并存。
2. **残余文本视图**：已知身份/绝对时间/设备结论分离后，未能解析的剩余文本仍进入候选文本分支；不能因不认识而整体置空。对疑似身份/告警字段记录不确定性。保留未知片段意味着仍有捷径风险，需要实测，不宣称一个清洗器能完美识别所有捷径。
3. **设备判断视图**：规则命中、风险分数、设备结论作为独立候选输入保存；只在确认是预测时可获得的原始日志信息后训练独立消融。原始目标标签、答案关联、事后结论不进入推理。字段缺失不能直接决定 M/S。

身份/时间原值保留用于溯源和分组；如需行为上下文，仅派生同一实体内部关系、相对间隔等可解释观测。先确认脱敏保持关联及时间可解析性，不能按绝对日期直接判类别。来源缺失不等于一个真实共同主体；没有可验证上下文时输出上下文未知，不假造邻居。

### 3.3 按真实日志补信息，不用一种清洗覆盖全部问题

| 切片 | 先恢复/保留什么 | 必须有的反例或限制 |
|---|---|---|
| unsupported 内畸形 CEF/WAF | 现有官方训练第 81090 行具有可见请求参数和值。容错词法扫描保留转义原文、请求方法和参数片段；整个 CEF 因引号损坏解析失败时，也不清空其余内容 | 区分日志中的攻击规则名称与实际参数；正常请求中引用 SQL 字符串、否定描述、不同转义要做对照。保留 `AND 1=1` 不等于已经证明该事件必为 M |
| unsupported 内邮件报告 | 第 45738/45750/78222 行有主题、附件类型/后缀、发送与回复字段、设备判断。可读字段分开保存，破损 JSON 的已观测区间不因整体解析失败而消失 | 当前示例并不包含完整邮件正文/附件内容，不能宣称可恢复不存在的钓鱼证据；地址关系仅在脱敏保持可比时使用，发件地址原值不当类别；只有设备结论时单列结论依赖 |
| VPC | 原始 14 列及逐列缺失状态，动作/协议/端口/包数/字节数；duration 仅在时间有效且顺序可验证时派生 | `-`、日志状态和原数值分别保留；ACCEPT/REJECT 是网络处置结果，不等价于 B/M；其他格式同动作的监督是否可迁移需模拟零支持实验 |
| ASA | 保留已可读的方向/动作/协议/可见端口/消息尾部，新增上下文必须有可核实邻居和信息增量 | 原文中已经被脱敏的端口不能猜回；同粗行为 M/S 对照、无邻居、单一大来源分别评估，不再复活已失败的端口编码微调 |
| bounded_payload / 认证 / Windows | 保留命令参数、父子进程角色、路径语法、否定/引述、实际认证结果与策略结果区别；长文本尾部不能截掉 | 文件路径/用户名替换后行为应可识别；`allow_unenrolled_user` 不能等价于认证成功；解析样例正确后仍需各自真实标签回归 |

### 3.4 编码与容量的边界

首个低成本对照采用已有结构化事实＋字符 n-gram 线性分类器，词表只在拟合集构建。保留大小写、标点、否定和数字的对照版本，不默认使用自然语言停用词清洗。逐行报告未覆盖字符窗口及空编码；不能称稀疏词袋为无损表示。

不以 HashingVectorizer 作为“无损保证”：它有碰撞且不能反向还原特征。若稀疏表示的窗口缺失/顺序限制经错误对照确认是瓶颈，再执行包含全部分块的字节序列编码器对照，固定 256 字节字母表并保留位置；字节序列无 OOV 不代表网络不会压缩信息。先用官方训练数据训练，不立即下载大规模外部预训练权重。

## 4. 训练样本缺少怎么解决

**先修我们排除的样本，再借现有官方数据共享行为，最后才讨论真正不可补的监督缺口。**

1. 将完整官方 train 制成新的角色清单，逐条注明因何进入拟合/验证/保留。所有路由都参与候选池，不再把旧 ASA 专项拟合集等同于完整任务训练集。保留原标签，不使用 private 答案训练。
2. 对同一行为跨格式建立统一字段，例如 observed action、transport、可见端口、packets/bytes、请求中的参数结构；“阻断”“可疑”不是恶意真值。共享参数可利用其他格式监督，但迁移有待验证，不能预先声称 VPC-M 已补齐。
3. 对有三类支持的其他格式做“拟合中移除某格式 M，但保留该格式 B/S”的模拟零支持实验，看共享表示能否跨格式找回 M，同时控制 B→M 和 S→M。它只测试迁移机制，不能替代真实 VPC-M 训练验证。若其他格式也缺少足够的类别/独立来源，不把该实验硬凑为三折；明确机制暂不可充分验证，其他可执行对照继续。
4. 极少来源的样本尽可能用于开发学习；若转入原来保留的 30 行，撤销旧保留资格，不重复报告盲测。对该稀缺源只报告正文组留出/同来源表现和无法跨来源估计的事实。其他有足够来源的切片照常推进，不被全局阻塞。
5. 第一轮每条原事件损失权重相同，重复文本仅用于缓存加速。不重新使用未经收益验证的重复降权。后续若确证少数类梯度被淹没，可单独比较类别平衡批次，使用校正权重保持目标损失，并报告真实分布误报；不能因某条已知验证错误就提高其训练权重。
6. 仅靠增广、过采样、模型伪标签或 LLM 判断，不能创造独立的真实 M/S 标注。自监督可改善表示，不能解决任意标签规则缺失。本轮不采集外部训练数据；若共享迁移失败且原信息确实不足，结论应是需要主办方澄清类别规则/补充合法标注，而不是继续无依据训练。该问题可以定位和控制，但不能保证靠现有数据消除。

## 5. 下一轮限定实验：先分清“信息”和“覆盖”各自收益

先完成原文覆盖/解析测试和 train-only 角色登记，然后做小型 **2×2 对照**，避免同时调模型、阈值和权重而无法归因：

| 臂 | 输入表示 | 拟合池 | 目的 |
|---|---|---|---|
| A | 旧表示 | 旧池与新折拟合区的交集 | 同学习器的本轮控制，不把不同验证集的历史分数直接相比 |
| B | 新行为＋残余文本 | 与 A 完全相同 | 分离恢复信息带来的收益 |
| C | 旧表示 | 完整允许训练池与该折拟合区的交集 | 分离覆盖带来的收益 |
| D | 新行为＋残余文本 | 与 C 完全相同 | 检验两种修复是否互补 |

四臂使用相同分类器家族、损失、预登记优化预算和三分类 argmax；不使用答案校准阈值。先选一个训练内诊断折运行四次，再仅把真实有益的变化扩展到其余合法折；首折失败先分清信息、拟合与迁移原因，不盲目增加训练量。所有词表/缩放/选择只拟合该折训练数据。

覆盖扩大还会改变类别/来源比例，因此 A→C 的收益不能自动解释为行为学习增强。每臂必须报告拟合类别先验、来源构成和新增样本清单，核对同一类别、同一行为切片的净收益；若变化只相当于整体概率偏置，需要追加仅在训练内定义的先验匹配诊断，不能直接归功于新证据。相同优化预算也可能令更大训练池欠拟合，需报告收敛轨迹；尚未收敛的比较只能判定该计算预算下的效果，不能判定方法无效。

训练内划分优先按可用主体符号留出；完全重复的事件/正文不得跨角色，混标重复组也整体保留不改标签。模板留出与来源留出单独报告，不能强行把共享的宽泛 deny 模板连接成一个巨大主体。若约束导致大组或类别缺失，报告覆盖和折资格，不静默拆开组。已被历轮查看的数据只能叫内部开发验证；新随机种子不会恢复盲测身份。

若 D 有可信收益，另做一次“D＋设备判断”与 D 的独立对照，不能为规避删除而把高风险字段悄悄混入文本。若 D 仍无收益，按以下诊断决定下一步：

- 连训练内同输入可分样本也拟合不好：检查优化、正则、窗口顺序/编码，再比较字节序列模型。
- 训练拟合好、正文组留出差：检查重复记忆和行为覆盖，不能只加容量。
- 正文留出好、来源留出差：检查来源相关特征和类别条件变化，优先做身份替换/设备判断消融及共享行为表示。
- 实际原文＋可信上下文仍存在混标：保留冲突，报告限制；不强迫模型学习一个并不存在的确定映射。

## 6. 逐项验收与对抗性审查

**第一轮：信息完整。** 原件及全部片段可复原；非空置空为零或逐条有明确可审查理由；尾部请求、畸形转义、否定、被引用的攻击字符串均有真实案例对照。只恢复字面含义，不把解析成功当恶意依据。

**第二轮：捷径与因果混淆。** 保持行为语义不变，只改变身份占位符、产品字段、绝对时间和设备结论，比较逐条概率/类别变化。先保证变换语义有效，再评价模型敏感性；改变端口或实际阻断动作可能改变含义，不能要求任意字段改变后预测都不变。来自合成变换的通过结果只证明该变换，不计入真实识别成绩。

**第三轮：支持与验证污染。** 检查事件/正文跨折、唯一来源、真实拟合成员及类别支持；零支持单列。private 答案与拟合/特征拟合/阈值选择代码隔离。不得依据已知验证标签构造路由。

**第四轮：模型真实收益。** 全量准确率为本项目主指标，同时报告 Macro-F1、三类 precision/recall/F1、混淆矩阵、正常误报和来源均衡结果。原 578/59,640 ASA 清单继续单列，不能换成更容易的分母。每一问题桶分别给旧错误、修复、新增错误、净收益和未解决原因。

保留 v7.3 的完整开发“实质收益”目标：总错误 12,415→≤11,173；M 召回至少 +5 个百分点，Macro-F1 改善，S 召回/F1 不下降、正常误报≤34。它是预先设定的工程目标，不是比赛官方评分公式，也不是保证可以达到的承诺。训练内选择不使用 private 目标调参；完整已查看集仅作固定候选回归。任何指标取舍变更要在下一次实验前明示，不能事后放宽过关。

题目同时列出准确率、召回、F1、AUC、少数恶意识别等考察项，没有给出唯一排行榜公式，因此不能宣称准确率就是已确认的官方排名算法。输出仍严格为全部 event_id 与三类 pred_label，不增加第四个“未知”标签；内部不确定性只用于诊断，不借拒判删掉难样本。
