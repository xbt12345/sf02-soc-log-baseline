# 历史模型效果比较与 GitHub 权重快照

核对日期：2026-10-06。按用户要求，先比较历史训练效果，再上传已有模型；本次不取回 V174 平台权重、不训练新模型。

## 选择结论

**本次发布 V128r3 的 P_IS 三折第 50 轮固定终点，作为现有完整开发评价中总分最高的历史研究快照；同时保留 A0（V125 A，第 25 轮）作为回退参考。**

比较限定为保存了完整 2,056,871 条官方训练原行评价、具有相同三类支持和固定来源折的历史模型。各类支持为 N=1,899,723、M=111,728、S=45,420；不把只有 M/S 的 V164、V169 或部分训练 V174 与完整任务直接排名。保存的质量摘要中有 98 组完整三分类指标，按宏 F1 和错误数组去重后为 36 种结果；重复参照不计为新的模型收益。

P_IS 相对 A0 在完整人口中净少 362 错：M 少 132、S 少 230，正常类漏判均为 0。完整宏 F1 增加约 0.190 个百分点。这里的错误是各真实类别漏判，精确率/误报由完整混淆矩阵另行给出。

本次从官方真值和保存预测独立逐行重算全部人口、身份和标签，结果与原摘要一致。逐行得失为修复 142M+274S，同时新增 10M+44S 错误；总分提升不能掩盖这些退化。来源组平均召回和零召回组数量也重新计算一致，未调用模型生成新预测。

## 结论的适用范围

P_IS 当时登记为训练内评分角色的**控制臂**，原正式候选 P_CF 失败。本次历史比较和权重备份不改写当轮结果，也不追认其正式晋升。P_IS 的内层教师与残差拟合排除对应外折来源；完整评价使用外折预测，未发现外折真值进入拟合。

收益不具备稳定跨来源结论：约 96% 的净收益集中于来源组 29，只有折 1 改善，折 0/2 分别多错 4/6。S 来源组平均召回约 11.51%→10.78%，零召回来源组 198→203，最大三组以外 S 错 1,373→1,387，头部切片新增 20 错。**因此“保存的完整开发总分最高”成立，“未知来源或赛事隐藏测试效果最好”尚无证据。**

旧正式候选与保护合同保持原结论。A0 保留较好的来源保护参考；三折权重按原固定 fold 使用，不能拼接最佳折或把新三折平均集成的成绩冒充原分数。本次检查保存预测与权重身份，没有重新做模型前向或全量重新训练。
