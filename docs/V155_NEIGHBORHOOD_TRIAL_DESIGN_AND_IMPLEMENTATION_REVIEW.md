# V155 有界完整梯度邻域风险对照：设计与实现审查

2026-10-01。**登记一个新的单因素受限试验，A普通原频次成员CE、B完整梯度一阶邻域风险；两臂三折共6拟合，保护已有TRAIN分类。当前本文是设计/实现审查，不是已训练成绩或模型替换。** V154说明有限方向损失敏感，并未证明迁移因果；因果证明不是允许一次可证伪对照的必要条件。诊断、试验资格、完整质量通过和替换资格继续分开。最新完成分类器在V155执行完成前仍V146。

## 具体假说与拒绝依据

当前578困难S两个合法TRAIN角色已全部分类正确，自身来源外仍错576；基础字段可读，不能重新强化这批TRAIN置信度。[V154实测](V154_DIRECTIONAL_NEIGHBORHOOD_RESULTS_AND_DECISION.md)在固定半径、保住TRAIN判决时发现成员CE与来源外判决有方向敏感性。这使“优化参数邻域的一阶风险代理是否改善来源外修正稳定性”成为可检验因素。它没有提供新增独立同类样本，也不直接解决细支持缺口。

[父V154独立审查](V154_INDEPENDENT_NEIGHBORHOOD_AND_LOSS_REVIEW.md)已独立核对3577绑定、六终点参数几何和24点原行概率，并拆分损失：固定local经验熵占原终点成员CE约71.2%–88.4%。这限制了降CE解释，不能删除冲突行，也不能据成员/集成损失组成猜测参数梯度组成。每次完整梯度和proposal分列真实M/S成员CE及pure/mixed原频次贡献；不把冲突熵或Jensen间隙当本题威胁语义。

若B相对匹配A未同时通过M/S、折、大S根以外的作用要求，或完整2056871行A0类别/来源门槛失败，则停止本配置，不追加半径、系数、种子、头拟合或检查点选择。TRAIN保护和少数修复均不代替来源外质量。即使通过开发门槛，也须另有确认计划，不能声称未知环境或官方盲测通过。

## 单因素、资源与数学含义

两臂均从对应折V146 A固定实际终点初始化，既有第二层22528参数可训练，第一层、reference/head/facts缓冲冻结，新增容量0。全部合法TRAIN原行及频次、未知、ICMP、混标多数正确及少数错均保留。没有外折标签方向、错误名单、产品状态、身份特征或新伪标签。

令L为完整合法TRAIN的原频次成员CE。A用g=∇L(θ)。B每个外层尝试先算g，再构造ε=ρg/||g||，随后用g+=∇L(θ+ε)，**忽略ε对θ的导数**；零梯度时ε=0。ρ=0.001×初始化第二层参数L2范数，每fit恒定。它是[SAM原研究](https://arxiv.org/abs/2010.01412)启发的一阶完整梯度适配，不是球内精确最大化，也不是作者小批随机/视觉benchmark复现。[Friendly-SAM](https://arxiv.org/abs/2403.12350)区分完整梯度和小批噪声；本题收益由实际对照判断，不从论文移植。[参数化反例](https://proceedings.mlr.press/v70/dinh17b.html)继续限制L2尖锐性解释。

两臂共同沿用V146归一化方向与同一求解器：初始/max L2步长0.01、缩半、接受后×2至上限、最小1e−8、Armijo1e−4、一次方向最多20回溯。A方向g/||g||，B方向g+/||g+||。每fit最多200外层梯度尝试/200接受更新/600有限proposal；A完整梯度最多200，B最多400，六fit总最多1800。B每proposal还多一次shifted风险前向，实际模型调用单独计数，**不称等算力**。注册有1个1×1 dummy前向/梯度用于解析真实runtime；零步前置有9完整分类梯度（三fold各base两次重复、shifted一次），另计，不隐藏为0。

本次ε在回溯内冻结。B接受检验的是φ(θ_trial|ε_current)=L(θ_trial+ε_current)的Armijo下降，同时未扰动θ_trial实际TRAIN分类不退化；下一方向才重新计算ε。因此不能说移动ε目标每步单调，更不能把g+叫真实球风险梯度。A就是ε=0的同一检验。不要求B普通CE单调，以免偷偷变成第二目标约束；普通CE、固定ε代理CE和接受理由分别保存。端点为注册预算耗尽或zero-gradient/no-feasible-step的最后接受状态，不按外折选点。提前无可行步是明确停止，不包装成200步已完成。

## 已实现的检查与真实执行边界

机器方案：`training/review_policy/v155_guarded_full_gradient_sam_plan.json`。适用profile `v155_runtime.py`绑定所有历史风险动作、上述完整预算、固定端点、类别/来源门槛与旧预算不重置；调用`experiment_review.check_bindings`，全量评价调用既有`evaluate_primary`。旧通用review_plan的25轮/6+12策略不适用本资源终点，因此不伪填epoch或18fit来绕过检查，也不改已封存历史源码。

`v155_sam_objective.py`以functional_call计算当前/固定扰动点的完整原频次梯度，梯度不写入模型.grad；`test_v155_sam_objective.py`实际验证完整类别质量、一阶扰动梯度与手算目标、固定ε有限差分及分类guard拒绝。测试不是SOC训练收益证明。

`v155_train.py`先register，准备三角色真实身份/半径和全部物理运行绑定，零分类模型计算；preflight复核三折原点概率与V146 A精确一致、base梯度重复、重现V154原/正向风险、模型不改、联合V142/V140/V138保护，后绑定activation。fit必须复核全部源码/数据/模型/runtime seal和activation，保留完整gradients/proposals、接受/拒绝、回滚、最近5个不同接受状态及对应冻结ε。未通过seal/activation不得更新。

父`v155_independent_guard_containment.py`已实际核对5个旧范围（V138 40879、V140 92114、V142三角色92315/40951/92292），均包含于对应角色V146 A实际初始正确225558行，真值完全一致。该凭据及其模型/概率/guard身份入方案绑定。因此proposal保护全部初始正确行足以覆盖这些旧链，不每proposal重复载入旧链；终点与五状态窗口仍实际调用联合check。这个包含关系仅对本初始化/数据/角色有效，不默认继承给其他运行。pure225202与correct225558始终分列。

`v155_evaluate.py`逐终点/最后5状态实际重放、冻结ε代理风险与日志核对、联合旧TRAIN保护、缓存无关完整22546数值输入函数验证；之后独立官方真值逐行计算完整2056871三类、ASA逐类、来源修复/新增错及匹配效果。其他格式继承未修改V146冻结预测并独立计分，不声称重新调用了其模型。所有外折已反复检查，结果是开发验收。

当前设计不是关闭①②③的新证书。V142原登记TRAIN掌握继续受保护；第二/第三/full未通过。规则“可以受限试验”不等于“已有迁移修复”，而“未证因果”也不自动无限禁止所有新目标。执行后以实际记录替换当前计划状态，旧V154和父独立文件保留不覆写。
