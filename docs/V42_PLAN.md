## 1. 一手资料与本项目取舍

1. [XGBoost 官方 offset/base_margin 文档](https://xgboost.readthedocs.io/en/stable/tutorials/intercept.html)展示将已有模型的原始分数作为偏置，再学习增量。本次借用该数学分工，旧模型参数、截距和编码器完全冻结；使用现有 NumPy/SciPy 实现小型凸优化，不安装或运行 XGBoost。
2. [DFR 作者论文](https://arxiv.org/abs/2204.02937)及[作者开源项目](https://github.com/PolinaKirichenko/deep_feature_reweighting)说明可先保留已有表示，再针对伪相关改善预测层；其视觉基准结果不能直接推断到 SOC。本项目缺少足以打破相关性的同类正常对照，不把 DFR 的重新配权和公共末层重训直接套入，也不恢复重复降权。
3. [scikit-learn 官方概率校准说明](https://scikit-learn.org/stable/modules/calibration.html)要求注意分类器拟合数据与校准数据的独立性。本轮增量在原 B 拟合侧学习，是受约束的残差拟合；不能将其称为已经独立校准的概率。评价侧完全不参加增量或支持表拟合。
4. [SafePredict 论文](https://arxiv.org/abs/1708.06425)通过拒绝预测控制接受部分的误差，其设置不是本项目的固定三分类输出。本轮只借鉴“支持不足时不强行修改”的思路，返回原 B 三类概率，不追加拒识标签，也不挪用其误差保证。
5. [USENIX Security 的安全机器学习评估审查](https://www.usenix.org/conference/usenixsecurity22/presentation/arp)讨论伪相关、参数选择和不恰当基准。本轮冻结范围后再看结果，保留已见/未见、少数类别、原始次数和历史压力边界。已有开发和旧压力均被查看过，不称为盲测。

## 2. 第一性原理下的职责边界

官方允许开发的 ASA 没有正常样本，只能检验恶意/可疑分型。因此新方法必须保持 B 的正常概率逐值不变，并禁止正常/非正常最终类别翻转。不能用这批数据重新训练正常/攻击边界。

同样，Windows 状态修复范围的 378 行全部为可疑，暂时只保留既有带来源的事实提取成果，不启动“状态→可疑”的分类补丁。Duo 和 Windows 的原 B 预测本轮必须保持原样。

本轮不会通过扩大网络、合并失败分支或增加全局类别偏置来求总分改善。

## 3. 支持范围在训练前固定

网络语义需明确为 deny、blocked，协议为 TCP/UDP/ICMP/ICMPv6；两端区域角色均已观察。TCP/UDP 要求源端口和目的端口都是合法观测值，缺省占位码不算观测。ICMP 要求 type/code 完整，端口不适用，不用端口缺失排除它。

满足完整性以后，键包含**全部现有语义事实及全部语义正文**。仅公共协议、某个源端口或各组件分别见过均不够：完全相同的可用上下文必须在对应拟合侧至少得到三个不同正文键支持。支持表不读取标签，不接纳评价行；三个正文键是最低支持，不是独立事件证明。

全量覆盖预检已经完成，尚无新模型成绩：三折评价侧分别只有 954 / 824 / 972 行具备支持，共 2,750 行，约为 ASA 的 2.57%；其中恶意 2,716，可疑 34，正常 0。范围偏窄是现实限制，不能看到这一点就放宽规则，把缺失上下文改称完整。

## 4. 唯一拟合目标与明确惩罚

记冻结 B 的三类概率为 `pB,pM,pS`。对每个支持上下文 `c` 单独学习一个偏移 `delta_c`，只作用于 `log(pM/pS)`：

`q = sigmoid(log(pM/pS) + delta_c)`，新恶意概率为 `(pM+pS)*q`，新可疑概率为剩余非正常概率，正常概率严格沿用 `pB`。

每个上下文最小化原始拟合行次数加权的二分类交叉熵，加 `10/2 * delta_c²`；限制 `abs(delta_c) <= log(2)`，条件恶意/可疑赔率最多改变两倍。无上下文间共享的新参数，无新增公共截距。使用 64 步向量化二分法求解单调导数，检查边界最优条件、目标不增以及与独立通用优化器的一致性。

这些惩罚和幅度属于本次保守固定实验设置，并非外部理论给出的最优参数，不进行结果后的搜索。原标签、样本次数及三折不变；没有重复降权。正常标签不提供恶意/可疑的子类型目标。

以下情况下逐值返回原 B 概率：上下文不完整、组合未知、正文支持不足、增量为零、B 判正常，或新分型会把原非正常变成正常。这是结构性保护，不靠一个有限惩罚项“希望”无关记录不变。它保护的是不新增退化，不会自动纠正 B 原来的错误。

G 固定对照：用同折旧 P 提供条件分型分数增量，套用与 R 相同的完整上下文范围、两倍赔率上限和正常边界保护。G 不重新训练、不参与候选晋升；用于检验只给已有 P 加保护是否足够。

## 5. 数据、冻结和验收

沿用 B 的 1,378,650 行、508,823 个正文键及三折。复核官方文件 SHA、准备结果、源代码和 B/P 模型；新运行代码、该方案及配置在第一折拟合前冻结。模型保存为原 B 加独立增量，不能修改原 B 文件或其内存参数。支持和增量均只来自本折拟合侧。

主候选 R 必须同时满足：

- 范围外全部三类概率逐值与 B 相同；全部记录正常概率、正常/非正常决策不变；原 B 参数及编码器不变。
- ASA 总错误低于 6,018，至少两折改善，且至少三个不同正文键出现修复；报告各折、正文支持和原始行次数。
- ASA 恶意分型错误不高于 618，可疑分型错误不高于 5,400；不能通过互相转嫁达到净提升。
- 原 B 未见实际输入、未见参数、未见联合值错误分别不高于 1,096 / 652 / 740。用原 B 切片计分，新范围覆盖单列；保护未知范围不等于提升未知能力。
- 所有行为路线×类别，以及路线×原 B 可用性结构×类别的少数切片继续扫描：不超过100行或30正文键均计入；原先有正确记录的小切片不得全部失守。旧关键认证、CEF 12条、WAF可疑和有限正文切片均不得新增原先正确记录的退化。
- 全体 Macro-F1 不降低、log loss 不增加，正常误报不得增加。

若 R 通过，最多一次旧模板/来源协议压力增量拟合；同一配置、固定旧压力 B。压力总错误、ASA 错误、每类召回和原先正确的小切片不得变差。该历史压力仍不是盲测；通过仅保留受限候选，不宣称外部迁移验收。

如果条件未满足，本轮照常完成执行核验并报告失败原因；不临时放宽支持、增大幅度或另训练 G。
