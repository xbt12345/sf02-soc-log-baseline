## 持续轨迹的审查边界

固定错误目标仍是一个代理目标。部分目标修好后，继续降低这些已正确目标的 CE 仍可能掩盖剩余错误的退化。因此应从已经会保存的每步完整 q/logq 分列目标中已修复与仍判错记录的贡献、实际修复数与退化数；不需要新增模型调用，不改变本轮固定目标集合，也不据此临时更换损失。

[H-Consistency Bounds for Surrogate Loss Minimizers](https://proceedings.mlr.press/v162/awasthi22c.html)研究特定模型集合下代理损失与零一分类误差的关系；论文的[原文](https://proceedings.mlr.press/v162/awasthi22c/awasthi22c.pdf)明确将模型集合和 minimizability gap 纳入相关界。我们的工程推论是：不能仅从某一步代理 CE 下降推断逐行分类已掌握。论文不提供本项目 SOC 质量证明，也不直接授予新的损失、门槛或训练预算。

下一步保持原单因素方向：新目标实际梯度重复和有限分类资格，然后才是独立登记的有界训练。第一问题尚未完成，当前最新完整训练仍为 V159 质量失败；已验正确技能、全原行评分和其他两项未完成目标保持原范围。
