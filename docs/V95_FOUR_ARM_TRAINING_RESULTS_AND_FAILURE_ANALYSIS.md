## 4. 失败最集中的具体证据

V区1,346条S中，一个组件有**685条**，对应仅**2种R0输入**（681+4）。A教师、E00、E10对这685条均判错；历史教师全对，但历史教师见过该组件。A+B中没有这两种R0输入的同类原行。V中一个“无已知解析字段”的粗组共有695条S，A教师错685条，四臂均未改善；另一个训练支持的TCP拒绝组有8条V区S，四臂也全部判错。E10的18条S修复只来自另外两个组件，14+4。

两种高频错误输入的脱敏消息含 `Deny icmp ... (type 3, code 13) ...`；R0字节坐标仍保留这些字符，嵌入的合成身份被规范化。当前ASA事实解析对此输出空已知字段。训练区最近的M样本在R0块点积上比最近的S样本更接近目标输入；这只是距离诊断，**不能由近邻距离推出正确威胁等级**。此处同时存在解析表达不足和独立同类支持缺口，尚不能定量区分两者各自贡献。不能把685次重复误当成685条独立迁移证据，也不能根据它们的V标签直接补规则。

## 5. 第一性原理审查与后续决策

1. **分清可学信息与同主体记忆。** 两种R0输入有可见type/code字节，但A/B没有同输入S支持；历史教师见过该组件。换更大网络或继续训练200步，不能自动提供未见组件的正确标签依据。
2. **检查新方法是否改善它声称解决的切片。** MLDG式辅助目标在两个可用V对照组的S上没有带来修复；其中一个组缺少已知解析字段，另一个V仅8条S。跨组件目标本身这轮未获支持，停止扩训。
3. **选模必须用相同教师对照，再过旧能力门槛。** E10比E00只多2条，组件重抽样区间含0；与历史可靠区域对照又出现59/436/387条负翻转。局部分数没有资格晋升。
4. **下一步先做只读证据工作。** 分离ICMP type/code、方向、目标区域和主体模板的训练支持；核对R0字节保留但结构化事实缺失的具体比例。若已有跨主体同类/异类对照，再注册**一个**针对这些字段的增量表达实验；若没有，明确“官方数据在该切片不可辨识”的范围，避免通过重复或V标签虚构监督。这个后续实验尚未获本轮结果证明。
