# V160 修复后真实结果与 V161 训练目标计划

## 新结论

V160 数值重构误停已经在三个固定终点上取得实际有限步反证：角色 0、1、2 分别有步长 1/256、1/8192、1/16，通过各自已登记的实际下降和分类保护，原参数全部恢复。**这解决了该固定方向诊断的数值障碍，没有解决分类掌握。** 三个安全探针相比固定终点均无分类变化；非冲突 OOF 错误仍为 3,278 / 1,960 / 1,586，合计 6,824 个角色原行。

角色 1/2 的新探针实际消耗 410 次前向/特征、19 个候选，新增类梯度、间隔梯度、拟合和永久更新均为零。累计 V159/V160 前向/特征为 15,728，类梯度 368、间隔梯度 10，拟合仍为 6、已接受更新仍为 165。根独立复算全部候选、原标签、原行保护和成本实际 exit0：`training/v160_independent_cached_polished_probe_review.py`，报告 `artifacts/v160_independent_cached_polished_probe_review_20261002/audit.json`。

## 被两类平均损失掩盖的退化

角色 2 的 probe4 符合旧两类整体 CE 下降条件，但实际旧错误在退化：

|类别|原非冲突错误|间隔变差|旧错 CE 合计上升|原正确 CE 合计下降|
|---|---:|---:|---:|---:|
|M|700|696|48.2458|63.9106|
|S|886|854|80.7365|83.3746|

此外混合输入旧错误的 M/S CE 分别升 11.4052 / 0.6716；原正确的收益仍将这些上升抵消。130 个 S 旧错来源根的 CE 全部变差。原 1,698 条全部错误仅 36 条间隔改善，中位增量 -0.105715。平均损失变好因此不能单独证明“正在学会原错误”。

角色 0/1 则不同：其旧非冲突 M/S 错误 CE 均实际下降，说明不能把全部安全方向一概否定。根分解保留原行频数，报告为 `artifacts/v160_independent_safe_direction_objective_alignment_20261002/review.json`。

原正确行的真标签对“原预测类”间隔恒为零，表中其间隔统计不能用于说明信心是否改善；评价它们用真实 CE、正确类对竞争类的实际间隔与逐行分类保护。旧错误使用真标签对起点错误竞争类间隔，定义固定。

## 必须避免的新误区：冻结正确判断，不要求冻结置信度

将完整两类 CE 不增作为新错误修复方向的硬约束也可能再次阻断成功学习。纯合成反例已执行并保存：每类 100 个正确行和 1 个错误行；同一线性参数更新可以保持 100 个原正确行、修复唯一错误，使两类召回从 99.01% 到 100%，同时均值 CE 从 0.13867 升到 0.47408。降低正确样本的过强信心使 CE 上升，分类仍全部正确。反向沿整体 CE 下降时，CE 到 0.09495，但旧错误更远。

来源：`training/v161_synthetic_accuracy_vs_mean_CE_review.py`，实际 exit0；`artifacts/v161_synthetic_accuracy_vs_mean_CE_review_20261002/review.json`。没有官方模型、梯度或训练调用。它证明整体 CE 下降不是保留正确分类的必要条件，不证明本项目的新目标一定可行或一定提高泛化。

因此下一轮不能继续以“平均 CE 下降”替代用户要求的真实分类，也不能仅为更安全的损失数字而保留错误方向。原 V159/V160 封存门槛与记录保持原样；新目标与新门槛须显式登记，不能偷偷放宽旧数值阈值。

## 唯一改动方向：固定合法旧错误目标，保住已验正确分类

模型、初始化、输入、16 个意见成员和原数据保持固定。唯一因素改为学习目标与相应验收：

- 在三个固定 B 起点，用合法训练 OOF 原标签固定两个目标集合：当前可见输入的非冲突旧 M 错误、旧 S 错误。角色原行数量分别为 M 1,886 / 800 / 700，S 1,392 / 1,160 / 886；总 6,824。跨角色为重复实验观察，不能把它们当成额外独立原始记录。
- 每个目标保留其原行计数和完整输入。损失定义建议为该类旧错误 stable CE 原频总和除以该角色原完整类质量，分母在调用前绑定；不用固定 20 倍、100 倍加权，不根据候选成绩选行。目标集合在本轮固定，不因为某行修好或分数变差就动态丢弃或重选。
- 其余原行的合法标签继续构成逐行正确分类约束、完整风险账本和全人口原频评分；当前已验非冲突正确、既有部署技能及后续接受的非冲突修复必须保护。全部冲突原行保留监督记录和评分，不删除、不改标签，也不把当前输入不可区分当成官方原始数据必然矛盾。
- 原完整 M/S CE 每步保存并按原错/原正确/混合、类及来源分解，作为训练和校准诊断。它不再自动成为本轮分类修复的必要下降门槛。明确承认优化目标变化，不能声称全量 CE 目标未改变。
- 对新的两个错误目标保持原 8eps 重复测量、16eps 有效下降分辨率和实际 Armijo；新目标梯度、原保护法向与有限步逐项真实验证。求解器成功不代替真实有限分类。
- 每个接受候选检查全原人口各类错误与已验正确的逐行保持；混合输入的类间权衡、可达下界与 protected mask 必须显式登记，不能用冲突行退出评分来制造纯错误已解的印象。

这里只给出目标策略，正式调用入口与预算由训练工作线程登记。根没有执行新目标梯度或新模型训练。

## 递进验证与验收

1. **对照资格**：用合成例确认平均 CE 下降但旧错退化会被新错误目标拒绝；保持原正确分类但完整 CE 升高的成功修复不会被误拒。相反梯度、消去、单位缩放、小方向、不可行切空间、非线性保护和实际恢复反例继续保留。
2. **固定端点机制检查**：新预算测量两个完整旧错误目标梯度并做重复检验，保留所有失败及成本。在所有三个角色实际执行有限探针，记录新目标下降、完整 CE 变化、所有原行分类与旧错间隔分布。数值止步、切空间止步与实际分类失败分别记账；不能直接宣布模型无解。
3. **有界真实轨迹**：通过资格后登记实际训练。不能要求第一步必须翻类，也不能无限重复无分类收益的微小下降。用预登记的真实接受轨迹观察目标是否将错误推向并跨过正确边界、隐藏参数是否学习，以及全人口类错误是否改善；只有实际状态可进入 last-5，不补齐、不挑最优。
4. **第一问题完成**：三角色非冲突训练错误实际解决、已有正确技能逐行保持、完整原人口仍计分并报告保护约束下的明确残余。平均 CE、概率校准、单个方向资格、部署冻结路线的高准确率均不能替代该验收。
5. **后续范围**：第一问题验收之前，不宣称细行为同类支持或跨来源边界已经解决。第一问题完成后，再按原目标逐项推进，最终核查完整 N/M/S 识别和迁移；已查看的外层仍是开发资料。

## 相关成熟方法的采用与边界

[JTT 论文](https://proceedings.mlr.press/v139/liu21f.html)和[作者实现](https://github.com/anniesch/jtt)使用第一阶段的失败样本为第二阶段提供针对性监督。作者的[原样本处理代码](https://raw.githubusercontent.com/anniesch/jtt/master/process_training.py)按固定阶段的真实预测错误形成集合。我们借鉴固定合法失败集合，不照搬其大倍数重复采样；否则当前输入冲突、重复源和少数源误标可能被放大。JTT 在图像/NLP 数据上的收益不能充作 SOC 的分类收益。

[MGDA 论文](https://papers.nips.cc/paper/2018/hash/432aca3a1e345e339f35a30c8f65edce-Abstract.html)提供多目标共同下降基础。本项目继续使用明确目标的真实完整梯度与独立证书，不直接复制[历史 NumPy 实现](https://raw.githubusercontent.com/isl-org/MultiObjectiveOptimization/master/multi_task/min_norm_solvers_numpy.py)中的 0.999/0.001 边界替代值或 1e-6 固定停止阈值；这些会与已定位的小方向和数值分辨率问题冲突。

[温度校准论文](https://proceedings.mlr.press/v70/guo17a/guo17a.pdf)说明置信度校准与分类正确是不同目标；正温度缩放本身保持类别排序，不能拿校准改善冒称 M/S 错误修复。[LogitNorm](https://proceedings.mlr.press/v162/wei22d.html)研究控制训练 logits 幅值，但改损失、尺度和梯度会引入额外变量，当前暂不混入这一轮。它们作为之后独立先验/校准实验的候选，必须有本项目实际对照才采用。
