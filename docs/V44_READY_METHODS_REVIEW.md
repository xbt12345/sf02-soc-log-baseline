# v4.4：现成方法实测、缺失机制反证与下一步收敛

2026-09-14。**本轮已实际完成两种现成分类器各三折，共 6 次拟合；没有修改官方标签、重复降权、下载外部训练数据或替换公共 B。** 本地 CPU 完成，无需操作平台。所有评价资料在此前开发中已经查看，以下不是盲测或外部迁移成绩。

**当前推荐：暂停 v4.3 自定义分层优化器的实现，优先用现成的独热编码逻辑回归，加严格分组的独立阈值选择，继续验证 ASA 分型。** CatBoost 的本次配置虽总分更高，却在缺失机制变化和未见输入上暴露问题，暂不接入。两种默认阈值候选都未通过质量要求，正式基准仍是 B。

## 1. 第一性原理：这三个问题不能混成一个问题

**观察信息不足。** 单条记录的现有事实完全相同，确定分类器就只能给出同一类别。原三折上的有限样本最低错误数是 1,970，而 B 错 6,018；这是事后描述界限，不是保证能学到的成绩。按“折×相同观察”统计，B 有 2,141 条错误处于混标组，距离该组最低数只差 171；另外 3,877 条错误处于本折标签一致的组。后者值得优先检查，但“评价侧标签一致”不代表拟合侧有足够支持，也不能作为推理开关。

**模型学到了不稳的规律。** 真实端口、协议和方向可能有用；外层日期、产品空值、身份和占位符编号不能成为答案。保留真实端口不等于允许学习端口二进制位或占位符数字。另一方面，统一缺失值只去掉了缺失标记的身份，模型仍能感知“这个值没被观察到”。

**分数与判定目标不一致。** 概率估计和最终分类决策是两个问题。默认 0.5 不保证同时保护恶意与可疑两类。阈值改变也不是增加了观察信息，更不是自动完成概率校准。这次必须分别检验表示、排序和决策点，不能再靠总体 Macro-F1 一项决定上线。

这里“恶意→可疑”是分型错误；两者仍属非正常，不能写成“恶意判正常”或据此推算报警漏报率。ASA 官方允许开发部分没有正常样本。

## 2. 本轮真的试了什么

使用现有允许开发的 106,953 条 ASA 记录，原三折、原行次数、原标签不变。每折只用另外两折拟合。输入为已经核实的 13 项行为事实，包括动作、结果、协议、方向角色、可读端口及范围、ICMP 类型/代码及其语义。所有输入按类别表示；端口范围是既有的语义分组，不引入身份、时间、产品或标签字段。

- **LR：** scikit-learn `OneHotEncoder(handle_unknown='ignore')` + `LogisticRegression`，`C=1`，最多 1,000 次迭代，三折均收敛。类别字典只在本折拟合数据上建立。未知值没有新学到的专属系数，其余观察继续参与。
- **CAT：** 已安装的 CatBoost 1.2.10，CPU、Ordered boosting、500 棵树、深度 5、学习率 0.05、L2=10、类别组合复杂度上限 2、固定种子。没有用评价标签早停、选树数或调参数。
- **MASK 负对照：** 只按 13 项事实的“存在/缺失”模式统计拟合侧类别频率；未见模式用拟合类先验。共三个频率表，不算新增分类器训练。

配置、源码和资料摘要在拟合前冻结。准备阶段曾因把旧 `union_group` 误当成当前折的隔离单位而停止；查阅原准备源码后确认当前按 `body_group` 隔离，修正的是检查对象，没有改变任何划分。25,041 个 ASA 正文组没有跨折，但 26 个旧宽模板组中有 20 个跨折，涉及 106,781 行。**正文隔离不等于宽模板、事件或新环境隔离。**

本轮是固定配置的开发比较，没有宣称做过内层选型。v4.3 提议的内层实验若直接用已拟合整个外折训练侧的 B 评价内层样本，会把 B 的训练内成绩混入比较；后续内层对照需要相同训练边界，不能这样复用。

| 同一批 106,953 条 ASA | 公共 B | 独立 LR | 独立 CAT | 仅缺失模式 |
|---|---:|---:|---:|---:|
| 总错误 | 6,018 | 5,131 | **4,763** | 28,651 |
| 恶意→可疑 | **618** | 984 | 1,238 | 468 |
| 可疑→恶意 | 5,400 | 4,147 | **3,525** | 28,183 |
| 修复旧错误 / 新增错误 | — | 1,365 / 478 | 2,191 / 936 | 462 / 23,095 |
| 未见完整观察输入的错误 | 1,096 | **1,088** | 1,154 | 14,472 |
| 本折混标观察组的错误 | **2,141** | 2,200 | 2,212 | 7,207 |
| 本折纯标签观察组的错误 | 3,877 | 2,931 | **2,551** | 21,444 |

LR 三折错误分别为 1,583 / 2,168 / 1,380；CAT 为 1,525 / 1,976 / 1,262；B 为 1,870 / 2,478 / 1,670。两者三折总错误均下降，收益不只来自一条重复日志：LR 有 650 个正文组净改善、109 个净退化；CAT 为 973 / 205。正文组不是已经核实的独立事件。

保护接入的离线重算中，全体 1,378,650 行 Macro-F1 为 B 0.958712、LR 0.965215、CAT 0.967909；正常误报均为 16。ASA 之外 1,271,697 行的全部概率、所有正常概率和正常/非正常判定精确不变。本批没有发生回退，因此没有用保护回退掩盖独立分类器错误。

**结论：独立分型值得保留，默认阈值下的这两个模型都不应替换 B。** 这次同时改变了局部训练、端口表示和模型配置，不能把全部收益单独归因于某一项编码修复。MASK 成绩差说明“仅缺失模式”不足以解释好成绩，也不证明新模型不依赖缺失模式。

## 3. 真正改变下一步选择的是缺失压力结果

对原本能读取端口的评价记录，统一删除端口值及其派生范围，其余事实不变。记录标签保留为同一事件的官方标签。**这是减少真实证据的压力测试，不是要求预测必须相同的无信息干扰测试，也没有声称复现真实脱敏机制。**

| 压力范围 | 行数 | LR 错误：遮挡前→后 | CAT 错误：遮挡前→后 |
|---|---:|---:|---:|
| 遮源端口 | 70,766 | 839→1,989 | 959→2,533 |
| 遮目的端口 | 87,528 | 3,204→3,971 | **2,950→16,943** |

遮目的端口后的同折相同输入最低错误数为 3,332，仅作事后信息界限。LR 在相同观察下实际错 3,971，因此 CAT 的 16,943 不能全部解释为“信息丢了、任何模型都会这样”。CAT 遮挡后把 16,803 条可疑判成恶意；原始自然缺目的端口的 19,425 行中，17,828 行是恶意。**这支持“模型可能过度套用了自然缺失模式下的类别规律”的解释，但没有识别真实缺失机制或证明唯一原因。**

另外，在“拟合侧同输入只有一种标签、评价侧出现相反标签”的 1,311 行中，B 错 921，LR 错 1,123，CAT 错 1,243。更强地记住拟合分布，不自动等于更可靠的行为判断。既不能用多数票纠正这些官方标签，也不能把相反标签行删掉来改善报告。

所以暂缓的是**本次 CAT 配置的接入**，不是声称所有 CatBoost 或树模型都无效。LR 也不是已解决缺失问题：遮源端口仍增加 1,150 条错误，必须继续计入验收。

| 方法 / 一手来源 | 对本项目有用的部分 | 当前决定 |

| [InterpretML EBM](https://interpret.ml/docs/ebm.html) | 可解释的主效应与交互，是另一种现成实现 | 本轮只研究，没有安装或训练；暂不再加第三个模型家族，现有反例已足够决定下一步 |
| [LightGBM 官方参数](https://lightgbm.readthedocs.io/en/latest/Parameters.html) | 类别和平滑参数可用于控制稀疏类别 | 只研究，没有安装或训练；不能因另换一个树库便认为缺失与反向纯标签问题消失 |

## 5. 收敛后的下一次执行方案

**只推进一个主候选：现有 LR 表示与正则不变，验证“独立选择分型阈值”是否能保留收益，同时避免增加恶意→可疑错误。** 自定义分层优化器暂停；本次 CAT 不进入接入阶段。先解决已被证据指向的决策点与验证问题，不先扩大模型容量。

1. **在每个原外折的拟合侧形成三个内层分组折。** 同一正文和相同完整观察输入都归同一组。本轮已核对：每个正文只对应一种完整观察，故可以按完整观察键隔离，同时保证正文不跨组；若以后表示改变，须重查这项事实。先检查两类支持和大组规模。全程只用官方允许开发资料。
2. **每个外折做三次内层 LR 拟合，获得真正样本外的分数，再固定阈值。** 外折评价标签不参加选择。以降低可疑→恶意错误为目标，约束内层恶意→可疑比例不高于预先固定的 0.8%；逐内层折、协议和可用性组同时报告，不能只看混合平均。这个约束是下一次实验目标，接近当前 B 的开发误分水平，不是对真实环境的保证。阈值从事先固定的 0.01～0.99、步长 0.01 的集合选取，同目标并列取更低阈值以优先保护恶意分型；无可行且有效的结果就停止。
3. **内层阶段同时检查原始输入与两种端口遮挡。** 原始和遮挡资料来自同一内层留出行，不能被同时放进拟合侧。遮挡结果报告实际错误和分型，不要求与未遮挡预测一致；不以遮挡后的错误组标签反向修改模型。小类缺少支持时写“未验证”，不能把 0/0 当通过。
4. **通过内层反证后，固定各外折阈值，评价外折。** 本次三个外折 LR 已用全部对应拟合侧训练，其配置、数据和来源不变时可直接复用，避免重复拟合。禁止在看到外折结果后改阈值、追加更大的候选集合或选择性回退。报告独立分型、正常边界保护接入和缺失压力三套结果。若公式仍使用原始条件概率，单独用冻结阈值作决策；不能把调过阈值的类别决策伪称为已经校准的三类概率。
5. **外折质量门槛保持严格。** ASA 总错误减少、至少两折改善；总体恶意→可疑不超过 618，可疑→恶意不超过 5,400；未见完整输入错误不超过 1,096；非 ASA 概率和正常边界精确不变。独立缺失压力必须公开，并与本次固定 LR 的同批压力成绩比较，避免靠默认场景提分掩盖更大退化。这些是已见开发资料的回归门槛，不是外部置信保证。
6. **外折通过后才做旧宽模板压力复现。** 使用旧压力协议自己的训练/评价职责，在其训练侧重新做分组选择，不能沿用在压力评价行上学到的阈值。旧压力集早已查看，只能称历史压力复核。没有未知来源标注数据，仍不能宣称迁移完成。

下一轮预计先做 9 次很轻的内层 LR 拟合，配置不变时复用三个现有外折模型；任何新增阈值与决策规则需独立冻结。**这 9 次拟合、阈值选择和旧宽模板压力本轮尚未执行。** 当前本地依赖已齐备，暂不需要平台包或新数据。

为什么值得先检验阈值：本轮只做了明确标为“使用评价答案的事后容量检查”的扫描。对于 LR 和 CAT，确实存在同时不增加这批 M/S 错误及未见输入错误的阈值，说明默认点失败不等于分数完全无用。但这些阈值来自答案，不能直接部署，不能作为新模型成绩，不能抄入下一轮配置。具体数值仅留在 [诊断文件](../artifacts/v44_ready_methods_20260914/threshold_capacity_diagnostic.json)。

0.8% 约束还受正文内相关性、可疑定义及有限恶意子组影响；普通按行二项置信区间会高估有效样本量。需要区间时按正文组重采样并说明其不是独立事件或新环境保证。优先完成上述有停止条件的比较，不引入额外概率校准工具链。

## 6. 本轮多轮对抗审查与实际结论

| 反证问题 | 本轮实际证据 | 取舍 |
|---|---|---|
| 是否只是改报告，没有训练？ | 六个保存分类器、逐行概率与预先冻结配置 | 已完成真实开发试验，未晋升 |
| 是否主要应该继续清洗冲突标签？ | 新方法改善主要在纯标签评价组；混标组反而增加错误 | 不自动改标，重点检查拟合规律和决策 |
| 总分高是不是就更好？ | CAT 总错误少 1,255，但恶意→可疑增加 620 | 否决按总分直接接入 |
| 能处理空值是否就不依赖空值？ | CAT 遮目的端口 2,950→16,943；同观察 LR 为 3,971 | 不把工具能力当抗分布变化证明 |
| 拟合侧标签很纯是否可信？ | 反向纯标签行 CAT 错 1,243/1,311 | 不使用多数票改标或确定性规则 |
| 新分组高分是否就是迁移？ | 正文不跨折，但旧宽模板大量跨折；资料已看过 | 保留未见组合及旧模板压力，拒绝盲测表述 |
| 能找到阈值是否就解决了？ | 答案扫描显示可行性，独立选择尚未执行 | 不应用事后阈值；下一步先内层验证 |
| 产品/时间/身份是否仍直接进入本候选？ | 官方原文 16,874 种输入重建相符；每模型 5,616 条指定干扰预测差异为 0 | 指定干扰检查通过，不扩展成所有字段/环境保证 |

这八轮是实际实验、反例和交叉检查的轮次，不是八个独立外部评审。

保存模型重新加载后，共 213,906 行样本外条件概率与保存结果精确相符；官方原始数据和三个公共 B 模型的哈希在训练后核对不变。六模型分别核验原文、外部元数据、采集时间、地址/接口和脱敏标记变换。保护接入的完整概率只做离线重建，没有安装新的生产推理接口。

结论是：**方向应当从不断自定义局部补丁，转成“最简单的有效分型器＋严格独立的决策选择＋缺失/未知组合压力验收”。** 官方数据足够完成这一步算法对比；仍不足以证明正常 ASA 识别或未知环境迁移，更多拟合不能补上缺失的验证事实。
