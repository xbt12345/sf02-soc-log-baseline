# V127：有据修订 V126，先关闭输入缺口，再检验有效分支学习

2026-09-29。**本次只有零拟合诊断与方案修订，分类器拟合、校准拟合、优化器更新均为 0；最新实际训练仍是质量失败的 V125。** V126 是未执行的方案，不能把本次方案调整说成新模型改善。历史模型和封存文件保持不变。

建议保留“冻结共享基座＋输入贡献对照”的主方向，但修改四点：让时间头规范化覆盖整个 ASA 模型；把常量控制做成带数值收敛验收的小型凸优化；取消不能复现原联合训练条件的旧日程 F 臂；将监督和验收按故障机制细分。主试验从 12 次缩为 **9 次拟合：6 次神经分支＋3 次常量偏置**。唯一候选仍为 P，禁止事后挑控制臂。

## 1. 先质疑旧方案，再用实际诊断决定改动

### 1.1 输出近常量，不等于注意力低熵

新回放覆盖 B/C、三折、初始化/第 1/25 轮，共 18 个状态。每折按固定种子从训练角色 M/S 各抽最多 256 个不同输入，仅作诊断；没有调整训练频次。显式注意力路径与原前向最大 logit 差不超过 1.44e-6。

最差第 1 折 B 的第 25 轮，第一层四个头的归一化注意力熵约 **0.760–0.838**，第二层约 **0.992–0.998**。它与已确认的近常量输出并存；并不是所有头都将注意力集中到单个位置。相反，第 2 折某头出现约 0.0009 的低熵，但这也不能单独解释第 1 折的主要失败。

**决定：**不能因为论文使用“collapse”就把 σReparam 或 SAM 加进训练。记录 attention entropy、池化表示差异、残差输出差异和梯度四个不同层面；不奖励高熵或高方差，不把它们当分类成绩。Pre-LN 仍是有理论与外部实验依据的候选，但“本项目近塌缩由 Post-LN 导致”仍待验证。

### 1.2 可疑类占比小，不等于残差没有收到它的信号

在冻结 A 的零残差起点，共享残差 logit 的 CE 梯度是 `mean(member_probability) - one_hot(y)`。按全部训练原行计算每条梯度的 L1 范数，再相加，S 在三个折的占比分别为 **55.47% / 55.55% / 57.87%**。第 1 折 S 虽只有 2,071/40,957≈5.06% 的训练行，其 logit 梯度绝对量并未被 M 压没。

这不是梯度向量合成后的范数，不是编码器参数梯度，也不证明 S 已学会或不存在特征竞争。它直接反对“类别少，所以立刻再加大 S 权重”这一推断。执行本次拟采用的时间头投影后，对相同冻结基座重算，S 占比仍为 **55.70% / 55.76% / 58.17%**。

**决定：**保持原始频次，不增加类权重、Focal Loss、重复降权或新辅助分类损失。训练期间再测实际参数梯度；没有诊断依据，不因比例悬殊就重复过去牺牲 M 换 S 的方案。

### 1.3 旧基座保留头部依赖，纯正文残差不能保证消除它

V126 冻结了存在已知头部缺口的 A，却只给分支无头正文；对同一正文的两个头部形式，分支输出相同，基座输出可能不同。残差或许通过足够大的间隔偶然让分类一致，但没有结构保证。把这个问题完全推给新分支，会混淆“正文学得不好”和“原通路仍暴露无关头部”。

本次将 V124 已验证的完整 ASA 头规范化应用于**保存的 V125 A**，不重训：

| 同一权重、同一原行 | 原输入 A0 | 规范头输入 AH | 代价 |
|---|---:|---:|---:|
| M 错误 | 318 | 318 | 0 |
| S 错误 | 2,074 | 2,114 | 新错 40、修复 0 |
| 总错误 | 2,392 | 2,432 | +40 |

原文、规范真实时钟头、规范脱敏时钟头三者经过同一投影后的文本，在全部 **112,807 条 ASA** 上相等；仅原来的 682 条模型输入发生改变。历史准备凭据另已验证正文原字节不变、事实矩阵不变、无新增跨折输入；经验输入冲突下界由 26 增到 28，原行和标签全部保留。这是指定头部形式的不变性，不是任意未知日志格式的保证。

**决定：**投影进入基座和分支共同的输入合同，关闭这条直接暴露路径；同时保留未经投影 A0 为硬参照。后续不能以更弱的 AH 为唯一基线，把追回 40 条称为整体净收益。该投影本身是有分类代价的鲁棒性修复，未被接受为正式升级。

### 1.4 常量控制也必须充分求解

V126 的 K 只用低学习率走 50 轮，尚无证据证明足以找到良好的常量偏置。若 K 欠优化，P 胜过 K 不能有力说明输入贡献。ASA 没有正常类，直接无约束拟合三类偏置还有把正常 logit 推向负无穷的有限解问题。

**决定：**K 改为训练侧全批量 float64、中心化三类偏置、固定微小 L2 的凸目标，以梯度残差验收。它仍计入拟合次数；优化器报告 success 但梯度不合格时仍算失败。求得的是这个明确正则化 CE 目标的数值解，不是所有常量分类规则的最少错误解。

## 2. 外部成熟方法：采用可迁移的部分，保留适用边界

|---|---|---|

这些论文不是相同 SOC 脱敏数据的现成成绩单。这里采用的是有用的机制和实验做法，没有发现能直接证明本项目 M/S 边界已解决的开源模型。

## 3. 修订后的下一轮执行合同

### 3.1 两个不拟合基线，三个拟合臂

共同权重为各折 V125 A 的第 25 轮模型，全部参数/buffers 冻结。A0 使用旧输入，只作严格原参照；AH 使用审核过的头部投影。新臂全部使用 AH 的输入合同与成员 logits，正文分支继续使用完整规范化正文，不截断，不造真实参数。

| 对照 | 训练内容 | 定位 |
|---|---|---|
| A0，0 次 | 无 | 原能力的硬参照，M/S 错 318/2,074 |
| AH，0 次 | 无 | 只做头部投影，M/S 错 318/2,114；单独核算预处理代价 |
| K，三折共 3 次 | 全批量常量偏置凸拟合 | 可靠的“只平移边界”控制；不是候选 |
| W，三折共 3 次 | 冻结 AH＋Post-LN 正文分支 | 稳定学习率共同条件下的归一化控制；不是候选 |
| P，三折共 3 次 | 冻结 AH＋Pre-LN 正文分支和末端 LayerNorm | 唯一预登记候选 |

删除 F 不是它已在冻结条件下被证明失败，而是本轮目标收窄到“这个规范化、冻结的方案能否有效学习并迁移”。F 既不复现原联合训练，又增加一个优化因素。减少它后**放弃单独归因学习率收益**，换取更小且清楚的主对照；不能声称已经证实 warmup 修好了 V125。

### 3.2 K 的目标与有限解

固定每成员基座 logits `z_i,k`，令 `b=(u,v,-u-v)`，优化：

`L_K = mean_original_rows(mean_members CE(z_i,k + b, y_i)) + (1e-6 / 2) * ||b||²`。

只用该折训练侧官方标签与原始行频次；float64，L-BFGS-B，解析梯度，初值零，`maxiter=1000, maxfun=5000, gtol=1e-8, ftol=1e-15, maxls=50`。完成后独立重算实际目标与梯度，梯度无穷范数≤1e-7 且目标不高于初值（1e-10 数值容差）才合格；否则本轮 K 无效，不能宣布 P 胜过充分拟合常量。小正 L2 和中心化去掉不可辨识平移，并为无正常样本的三类问题给出有限目标解。K 与 W/P 不宣称相同计算量。

### 3.3 W/P 训练

- 固定 seed=12701，三折完整执行。正文宽 64、两层四头、FF128、GELU、dropout=0、正弦位置、masked mean、零输出头保持原计划。Post/Pre-LN 的共有张量初始化匹配；Pre-LN 末端 LayerNorm 属于整个归一化方案因素。
- AdamW，峰值 lr=0.0003，前 10% 总步数线性 warmup，之后恒定，wd=0.0003；无额外 class/group weighting、裁剪、解冻、辅助损失或外折阈值。
- 固定 50 轮；每臂每折 3,650/1,600/3,650 步，W/P 合计 **17,800 次 AdamW 更新**，相对 V126 的 35,600 减半。K 的优化迭代另记，不能将它写成 0 更新。
- 检查点 0/1/2/5/10/15/20/25/35/50。第 50 轮为唯一分类终点；25 轮只作学习进度比较，不做赢家选择。损失、参数更新仍变化时如实报告预算未证收敛，不临时延长。
- 保留全部合法 fit 行与原行频次。时间头归一化后合并相同输入不合并原行质量；旧 local 仍为逻辑批单位，避免再改变批次组织。每个成员 logits 都缓存，不能先平均成概率再改训练目标。

### 3.4 三种干预防止“换一种偏置就算学会”

固定检查点后，对保存模型进行三项**不拟合、不选模**诊断：

1. **关闭分支：**必须回到同一 AH，检查基座是否真冻结。
2. **训练均值替换：**用训练侧原行加权平均分支 logits 代替逐输入分支，量化分类和逐类 CE 差异。
3. **固定无标签置换：**在既定角色内按固定种子打乱“分支输出与输入”的对应关系，按每条原始记录置换，保持原行频次下分支输出的边际分布与基座不变，检查输入与修正的匹配是否有用。不能只打乱频次不同的 unique local 后声称保持原行边际分布；不根据标签置换，不把置换样本当真实训练标签或可部署模型。

第三项加强“输入特异性”证据，但它不是词序消融：本轮仍不能声称收益源自词序，不能把干预结果写成真实外部分类成绩。

### 3.5 监督到具体层面

每步保存训练 M/S 原行质量、分支各模块梯度与更新范数、各类 loss/logit 梯度贡献、有限值状态；零头第一步编码器梯度为零为预期，持续失效须单列。固定检查点看 token 表示/池化表示/输出，不能只看 attention entropy。

输入端核对完整 span、正文、事实/未知值保全、全部已注册头部变体和重复输入的频次。保留规范化产生的 28 条经验冲突下界相关记录，单列冲突且仍计入总分；不删掉来提高成绩。

学习端单列 136 条不同训练 S 与 206 个重复角色、全部非混标 M/S 错误，不拿角色数放大样本量。迁移端继续覆盖历史 62/186/192/1,796 分层、已知 682 头部记录及本次 40 条预处理新增错误、来源组 29、最大三 S 组之外和所有剩余原行。上述切片只定义报告，不能定义训练权重或推理路由。

不同支持层的判断必须不同：已知参数且多来源双类支持仍错，优先审查学习/表征；未知参数池化支持不能冒充精细支持；精细无同类而粗行为有双类，必须测试是否迁移到有用组合，不能伪造 fine-level 标签。所有切片照常计分，不因解释困难而排除。

## 4. 胜负标准与失败处置

**门槛不因 AH 变弱而放松。** P 对 A0、AH 都报告逐行修复/退化；主分类门槛始终相对 A0：ASA M≤318、S≤2,074、总错≤2,170；完整 2,056,871 行逐类召回/precision/F1 保护、至少两个折改善、最大三个 S 组外不退化、组平均召回不降、零召回组不增。总错 2,170 仍是项目研究预算，不是比赛及格线。

相对 AH，只追回 40 条最多回到原 A0，不算新方法净提升。实际收益拆成 `AH-A0`（输入代价）、`K-AH`（偏置效果）、`P-K`（相对常量控制的差距）、`P-A0`（最终净收益）；逐行使用每条记录的真假变化，四个总体错数差只作汇总。K 与 P 优化形式不同，P-K 单独不足以做唯一因果归因，还须结合冻结均值/置换干预。

机制通过须有 P 的训练侧学习和输入匹配贡献；分类通过仍需真正改对来源外记录，P 的 ASA 原行总错还须严格少于合格 K。优化统计不能替代最终计数，P 失败但 W 好不能事后换候选。K 不收敛属于控制无效，需要技术审查，不得将其归为分支胜利。

全部原始质量/输入完整性/注册头部无害变体零翻转通过后，才运行预定 seed=12702/12703 确认：每种子三折 A25＋冻结投影后 P50，共额外 12 次拟合。只确认整体方案是否胜过匹配原 A，不宣称跨种子证明独立的 LN 因果效应。未通过则不追加。重复开发折仍不是盲测，不能更换随机划分制造“独立”。

若 P 在训练侧依然没有超越 K/均值替换的有效学习，终止此次稳定化假说；若学会但跨来源仍不达标，停止该微型正文分支路线，将问题回到行为证据与标签可辨性。只有找到新的可观察缺失信息或合法训练监督缺口，再登记辅助事实学习或新的模型路线。不开无限优化循环。
