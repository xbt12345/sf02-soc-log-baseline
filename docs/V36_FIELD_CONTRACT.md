# v3.6 字段使用与失败边界

本轮预测只接收 `message_sanitized`。`event_id` 仅用于输出关联；原标签仅用于允许职责中的监督与评价。产品、厂商、管线、外层时间、IP、主机、用户以及产品缺失标志，不传给编码器、分类器或推理路由。来源只参与声明的训练划分、统计切片，以及单独报告的校准诊断。

这份约束不能被解释为“模型不依赖任何字段”。检测必须依赖可观察信息；应排除无关信息和未经验证的快捷判断，并检验必要信息在新来源中的作用。

| 信息 | 实际处理 | 验证与限制 |
|---|---|---|
| 产品为空或未见产品 | 同一条消息推理路径；不补产品、不按缺失建模 | 真实记录改产品/时间/身份的端到端概率对照；未知消息格式仍可能保留隐含来源信息 |
| 采集日期、时间残片 | 已确认 RFC 5424、RFC 3339 系统日志头及显式消息包装内处理 | 日期变化不应改变这些路径的表示；不宣称未知正文日期均已消除 |
| Windows 句柄、进程/登录 ID、身份槽 | 明确 ID 槽中的十六进制编号和 SID 规范化；状态码保留 | 测试编号变化不影响表示，状态变化仍可见；未知或损坏字段名不猜回原名 |
| 设备原生认证事件 | 校验原生提供程序和事件位置后，将完整 4624/4625 对齐到认证成功/失败 | 这是观察语义，不是比赛类别。未核实的提供程序、部分脱敏代码、载荷中的数字不解码；正文与代码冲突时不替模型选一个结果 |
| Windows 文本/XML 包装 | 提取有明确边界的完整正文和已知结构事实；后部容器损坏时，允许在核实原生来源及边界后恢复前部完整正文 | 不补全残缺正文；拒绝多个候选正文、嵌套载荷冒充正文；不满足恢复条件时保留诊断回退路径 |
| 回退路径中的根级元数据 | 仅隔离有明确边界的 sensitivity、标签、产品、厂商、管线、组织、风险评分等根级包装字段 | 不全局删除 normal、malicious 等词，不误删真实载荷；未识别布局仍不能保证完全隔离 |
| WAF | 区分 CEF 分隔符与真实载荷；保留路径、操作符、完整端口/状态/动作；排除未核实的检测名称、严重度等意见字段 | 拒绝不完整引号；损坏请求方法名不猜值。`DENY` 不等于 malicious；正常样本也必须检查误报 |
| Duo | 保留完整 reason/result 等认证事实；统一部分有文档依据的事实语义 | result 脱敏时不填 success；263 行没有观察事实的记录不强制改类 |
| ASA | 保留协议、方向、完整端口、ICMP；具体 DMZ 名称抽象为角色，ACL 名称留原文诊断 | 具体分区和策略差异可能有真实意义，当前没有策略定义。角色抽象后的同文异标签不能称为已解决或原标签错误 |
| Duration / Count | 保留明确记录的时长和数值 | 只代表日志报告值；未证明是攻击窗口/连续失败次数，不制造速率或跨事件链 |
| 原文为空、事实为空 | 原样参与行级评价；另外报告信息覆盖 | 空记录不得因 event_id 不同被计为多份独立检测证据；不生成额外比赛类别 |

原生事件含义参照 [Microsoft 4624](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/auditing/event-4624)、[Microsoft 4625](https://learn.microsoft.com/en-us/previous-versions/windows/it-pro/windows-10/security/threat-protection/auditing/event-4625)；认证原因参照 [Duo Admin API](https://duo.com/docs/adminapi)；WAF 字段语义参照 [Barracuda 日志格式](https://documentation.campus.barracuda.com/wiki/spaces/BWAFv76/pages/2721209/Exporting%2BLog%2BFormats)。这些资料用于解释格式，没有引入外部 SOC 训练记录或下载预训练权重。

单字段删除用于暴露依赖，并不天然保持事件含义：删掉状态、结果或端口后成绩下降，不能单凭这一点认定捷径。反过来，包装变换不翻转也不能证明所有来源迁移成立。两类实验分别报告。

所有学习型统计只使用当次允许拟合行：词表、IDF、事实类别表、数值尺度、重复权重。选 C 用 selection，最终重拟合用 fit＋selection，阈值用 calibration。目标来源不参与这三步；评价数据不回流成自动伪标签。
