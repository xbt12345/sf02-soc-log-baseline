# V158复盘与V159下一轮决定

2026-10-02。独立审查；最新已经训练并完整评分的版本为V158。此文是下一轮决定，不能作为V159已训练或已通过的凭据。

**决定：停止追加V158原配置；支持V159在真实零步与逐类梯度检查通过后，执行一次有界六拟合对照。** 允许试验的依据是已找到并实际复核了可表达性、逐类监督和验收相容性问题。没有证据保证下一轮必然显著提升。

## 按因果顺序定位问题

1. **先检查输出能否表达正确分类。** 原融合为非负、类别共享的概率凸组合。当16个当前专家的正确类别概率均小于另一类，任何此类加权都无法改正。在三个合法OOF训练角色中，可疑S的这类原行计数分别947、865、395；这是角色计数，不能相加冒充独立原行数。加入旧N1没有解除其中任何S限制。因此继续只调专家权重没有理由。
2. **再检查训练目标是否奖错方向。** 总CE下降不约束S错误不增，也不保证逐类CE下降。候选采用M/S两个完整原频率类风险的共同下降方向，有限步仍检查实际两类风险与受保护分类。共同下降可能不存在，也可能被守卫阻断；这种停止不能称已经收敛或学会。
3. **检查数值和步幅是否允许纠错。** 旧成员极端错误置信度所需纠正间距最高约3,546.98。此前受限步幅的条件上界64不足，不能把这种失败解释为模型永远无法学习。新候选从当前16概率均值的固定1e-12底数开始，零步分类必须完全一致，训练用稳定log_softmax；这是一项数值初始化政策，不是新行为证据。
4. **最后检查验收要求是否相互矛盾。** 若把全部初始正确OOF行都冻结，角色1/2最少错误会被锁为72/110，而完整可见数值输入经验下界是4/26。原OOF正确从未被验收为既有能力，因此B保护当前X纯标签输入组的初始正确行；混类原行全部保留原频次监督及计分。225,558条已验收部署TRAIN正确角色行及V138/V140/V142联合范围继续全部保护。

独立补充检查实际exit0：当前CSR已排序、无重复坐标、无显式零；规范化前后数组完全相同。把OOF和deployment两种输入人口联合检查，没有同完整X+无序16概率要求两个受保护标签的矛盾；联合保护后的OOF经验下界22/4/26，兼容注册当前X目标22/6/28。这个检查只排除了精确数值身份上的冲突，不能证明有限宽模型或预算一定能达到目标。

## 下一轮只回答一个问题

当前聚焦仍是“训练侧分类没有学会”，不同时引入外部数据、重标、重复降权、来源权重或关系网络。保留现有完整66,287列模型输入，使用16个合法来源隔离当前专家概率，训练自由三分类修正头，允许最终预测超出专家凸组合。保留所有现有输入列不等于已经证明原始日志预处理无损。

固定两个匹配臂，各三个训练角色，共6拟合：

- A：原行频率总CE方向；保护已验收部署TRAIN能力。
- B：M/S两个原行类均值风险的共同下降方向，有限步要求两类风险均满足登记下降条件；另保护纯输入OOF旧正确。

两臂函数、输入、初始模型和种子相同。A/B检验的是“方向、逐类风险守卫与OOF分类保护”的组合干预，不能把收益全部归因于单一梯度算法。新头相对V158还同时改变可训练函数与输入直达路径，机制证据支持这一探索，但不能据此拆分各项实际分类收益。

固定预算：6拟合；每拟合最多200次梯度迭代、600次累计候选步、200次接受更新；2400个训练完整类梯度加12个预飞行梯度，最多77,832个官方头前向与相同数量的意见特征块。拒绝步计入预算，技术失败保留成本；不自动换种子、补预算或挑早期有利模型。

## 递进验收与失败处置

1. **入口合格**：真实源码、导入依赖、输入、角色和预算在官方函数前封存；运行检查要支持实际协议，不能套用旧25epoch方案。零步逐原行分类不变，概率误差不超过3e-12；重复前向及两类完整梯度一致；类梯度分母使用全角色原始该类质量，而非每块均值。合成测试只能证明实现覆盖，不能代替真实预飞行。
2. **训练侧掌握**：三个B角色全部当前X纯输入错误0；总错分别不超过22/6/28，所有混类行仍计分；末五个真实不同接受状态均满足要求；已验收能力新增错误0。状态不足五个即不能声称稳定掌握。此关失败，记录余错、方向冲突、拒步和实际终止原因，不进入额外确认。
3. **任务效果**：全2,056,871原行逐类评分；匹配B相对A的M/S错误分别不增且至少一类减少，至少两个来源折改善，大组之外S不退化；保留578困难S、51对照、缺失端口、ICMP、混类和全部来源。既有任务门槛M错≤318、S错≤2074、ASA总错≤2170保持，不按本轮结果下调。
4. **解释结论**：若训练角色过关、来源外仍失败，结论是这个可训练函数已经拟合监督人口，但仍未解决迁移；随后再审查同类行为支持及OOF/部署专家分布差异。若训练角色未过关，不能继续把剩余错误统称泛化不足。非ASA107个历史错误仍完整计分，不申报本轮学会正常N。

## 借鉴方法与证据边界

采用交叉预测训练最终分类器并允许原输入直达，参考[scikit-learn StackingClassifier官方说明](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)。本项目使用来源分组隔离，不直接照搬随机折或在已拟合输出上重新训练的prefit用法。

逐类风险共同下降参考[Sener与Koltun的多目标优化研究](https://papers.nips.cc/paper_files/paper/2018/hash/432aca3a1e345e339f35a30c8f65edce-Abstract.html)及[作者代码](https://github.com/isl-org/MultiObjectiveOptimization/blob/master/multi_task/min_norm_solvers_numpy.py)。将其用于M/S两类风险是项目推断，论文没有证明本项目安全日志分类必然改善；风险下降仍须通过真实分类验收。

训练约束满足不能替代来源外约束满足，参考[Cotter等的约束泛化研究](https://proceedings.mlr.press/v97/cotter19b.html)。本轮部署TRAIN守卫用于保护已验收范围，并不是这篇论文所要求的独立验证人口；不借其结论宣称已获得泛化保证。
