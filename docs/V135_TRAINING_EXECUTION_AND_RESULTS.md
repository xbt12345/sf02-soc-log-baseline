# V135：按 V133 执行的稳定学习试验

当前状态：12次主拟合、71,200次参数更新全部完成；训练掌握与来源外质量均未通过预登记验收，无模型晋升。完整批准方案仍为 [V133](V133_TARGETED_TRAINING_DESIGN_AND_RESEARCH.md)，其机器计划未修改。V135 是修复执行层非确定性后的新运行版本，不是另换训练目标。

## 执行前审查与问题处置

1. 新训练器已经实现，方案、实际源码、依赖、官方输入、折角色及参照文件在第一次参数更新前封存。六项专项测试与十四项历史反例检查通过；这些仅证明执行约束。
2. 第一次执行 V134 已停止。相同初始状态、相同批次顺序、前80轮相同学习率的两臂，在第10轮出现24条原行预测差异，第20轮概率最大差约0.03016。此时日程尚未分叉，不能将差异归因于日程。
3. V134 实际启动3次拟合，完成2次；步骤日志记录至少20,693次更新，第三次拟合完成83轮。强制停止时最后一个进行中更新可能尚未写入日志，因此该数是已记录下界。全部原日志、模型、封存和中止收据保留于 `artifacts/v134_stable_learning_trial_20260930/`，不充作新运行成功结果。
4. 真实输入重复前向/反向验证发现：旧稀疏计算即使开启确定性开关仍不一致。V135改为全部活跃列的紧凑稠密乘法，参数、初始化、代数及66,287维输入均保留。三折、两类输入面板、两种损失共12组实际检查中，新实现重复前向和梯度逐位一致；旧/新logit最大差约1.49e-8，梯度差不超过3.73e-9。诊断未进行任何参数更新。这里只定位到整体稀疏计算路径，未逐个CUDA内核定位。
5. 每个衰减臂的前80轮都与对应恒定臂逐原行核对概率和预测，任一差异立即中止并保存问题。固定96–100轮由实际模型重放，再对照原行账本；不能只相信汇总字段。

参考：[PyTorch 2.7确定性算法说明](https://docs.pytorch.org/docs/2.7/generated/torch.use_deterministic_algorithms.html)、[复现边界](https://docs.pytorch.org/docs/2.7/notes/randomness.html)。确定性开关本身不足以证明整个程序可复现，故使用上述实际输入检查和运行中的配对轨迹检查。

## 固定训练与验收

原行CE/纯输入辅助监督 × 恒定/末20轮余弦衰减，四臂三折，共12个主拟合、71,200步；唯一任务候选仍为R_decay。128宽度、16成员、100轮、AdamW、原划分、原标签、原始行质量不变。全部角色每轮完整参加监督；不早停、不按新来源外结果改权重或选轮次。

所有四臂TRAIN资格先封存，再进行新HELD预测和独立真值关联。学习验收为各折第96–100轮纯M/S均零错，完整M零错、S只剩当前表示的混标最低22/6/28；不能把表示冲突解释成现实不可区分。质量验收保留旧A0全部逐类与来源约束，并增加与新R_const的匹配保护。任一失败不运行后3次种子确认、不晋升模型。

关键数据：每个更新的损失、M/S质量、学习率、梯度及更新范数；每轮全部TRAIN原行概率和来源×类别错误；固定模型和优化器状态；最后五轮实际重放；独立官方2,056,871原行逐类计数；修复与新增错误分别报告。

### 第一性原理审查：已证实与尚未证实分开

- **对照缺陷已修复，分类缺陷没有因此自动解决。** 66项绑定源检查保持一致，6组前80轮配对共36,098,240次原行比较逐位一致。旧/新执行源码分别保留；不得用计算修复冒充业务精度提升。
- **固定80轮衰减不代表学习已经完成。** 第0折R到80轮仍有139次非混标错误，O仍62次；末期衰减能减少部分反复，也可能保留错误。O在第2折有收益，第0折反而增加S错；不能宣布衰减普遍无效，也不能继续按统一时点认定学完。
- **辅助监督改变优化取舍，没有新增行为信息。** 原行/辅助两损失的同日程对照表明，TRAIN错误减少而来源外M增加；下一轮不能依据训练S归零继续盲增S权重。
- **不能把残错统称为所有成员都缺能力。** R_decay的80次纯输入残错、O_decay的48次均存在正确成员；此标志已由实际模型重放验证。成员存在正确输出不等于组合判决正确，也不提供无需真值的选成员方法。旧直接投票失败仍保留，不事后改变本轮聚合。
- **梯度相反只是诊断，不能直接认定唯一根因。** 第1折R_decay终点原行M/S在facts_direct上的梯度余弦约-0.999868；二分类竞争及目标平衡也会形成相反方向。需和真实错误、置信度及配对干预结合，不能据此直接加入PCGrad或新权重。
- **保护切片失败仍未解决。** 12个头部S错误与2868大量M错误必须逐行保留。当前结果没有证明它们都是日期依赖，也没有证明缺少的上下文靠更强模型可补齐；须分别做合法输入对照与来源支持核查。

### 验收证据与后续边界

独立审核90,245,600次TRAIN原行×轮记录；60个末五轮实际模型重放4,512,280次原行概率、预测及成员失败标志；全部终点对照绑定的原始官方真值与2,056,871条原行计数。12个训练角色均未通过五轮稳定要求。无留出标签参与梯度，未改变种子、官方标签、输入、候选或门槛。执行测试与实际重放通过仅说明过程可信；学习和分类验收均失败。

停止本轮扩训和晋升。后续先拆分“成员已能表达但组合仍错”与“持续学习/置信度取舍”，在合法TRAIN来源内做匹配验证，再核查来源2868缺支持的M及其正确对照；任何新日程、聚合或目标需另行登记，不能把本轮其他臂事后拼接为赢家。本轮不启动新的未登记训练。
