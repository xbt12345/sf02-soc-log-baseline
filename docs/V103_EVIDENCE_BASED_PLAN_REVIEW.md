# v10.3：对下一轮方案的有据评价与最小修订

2026-09-28。审查对象是 v10.2 下一轮计划。本轮新增 **0 次分类器拟合、0 次校准拟合、0 次参数更新**。执行了全 2,056,871 行的划分与训练支持预检查、一种现成分层方法的零训练对照，并核对作者实现与历史实验。实际最近训练仍为 v10.1；质量未通过，无新模型晋升。最近完整开发回放仍为 v7.9 的 5,947 错。

**评价：大方向值得保留，但上版尚不足以原样执行。覆盖优先、停止残差扫参、保留原行和组指标有本地证据；“扩池会解决多少错误”“TabM如何接入”“训练多久”还混有未经验证的假设。本次只修正能证明更合理的实验或实现部分，没有把修改方案写成模型效果已提高。**

## 1. 哪些保留，哪些修正，依据是什么

| 项目 | 评价与决定 | 支持依据 |
|---|---|---|
| 扩大合法官方监督覆盖 | **保留，优先执行匹配教师对照** | 按原定新折实际计算，历史113条目标中101条从小池零支持变为大池有支持，而非仅凭全数据存在相同标签 |
| 不再盲目延长旧残差/MAG | **保留** | v9.2训练达到经验界却新增500条M错；v10.1长训留出退化，不能再把步数当突破依据 |
| 原行指标＋连通组指标 | **保留并补充折/大组贡献** | v10.1 S原行召回94.69%、组均22.35%；新全人口划分仍有不可拆的大组 |
| “80.50%错误来自缺监督”式解释 | **收紧为严格行为键的关联诊断** | 230条严格键零支持S错，粗协议/方向键全部有同类训练支持；不能说它们没有任何可迁移证据 |
| 共享128维映射后才建立TabM多成员 | **修改顺序** | 作者实现明确要求先形成不同成员表示，再首次混合输入特征；旧接法不符合其关键设计 |
| 固定100轮当成合适训练长度 | **改为预算上限和统一检查点选择，不认定最佳轮数** | 历史已有长训退化；研究也强调验证驱动的模型选择，不能把预算终点当最优点 |
| 一开始默认跑完15次 | **改为先6次覆盖对照，后续9次需登记具体剩余问题再启动** | 扩池、规范化、骨干各自应回答问题；目前没有TabM在本项目上的收益证据 |
| 直接换为分层三折 | **暂不采用** | 行比例改善，但S组数明显失衡；没有证据表明这个候选划分全面优于原定方案 |
| 等组加权、删端口、增加伪标签 | **不增加** | v5.4/v5.5等已有反例，本轮没有推翻它们的新训练证据 |

## 2. 扩池支持存在，但应以实际训练侧为准

使用 v10.2 原定的全局连通组及固定种子10203，不改种子、不看新预测，把每条记录放入三折，再从它对应的其他两折查询支持。这里没有训练模型。

| 原先113条“来源外官方组存在同类支持”的S错例 | 实际数量 |
|---|---:|
| 新全人口训练侧确实有同类严格行为组 | 105 |
| 小池仍无支持、全池新增支持 | **101** |
| 在新的匹配小池中已经有支持 | 4 |
| 支持组和它一起落在留出侧，训练侧仍无支持 | **8** |
| 全池训练侧达到至少2个同类组 | 59 |

因此，“113条可能受益”应更新为：**101条是本划分下干净的支持增加诊断目标，8条仍无训练支持，其余4条不是从零到有的覆盖收益。** 这些数字不代表101条将被修复。训练仍使用全部合法训练行，不只加入这101条，不改变原标签。

### 对“零支持”的解释必须分层

旧严格行为键包含协议、动作、结果、方向及目的端口或ICMP type/code。把后面的协议参数仅从**审查键**去掉，输入模型的完整原始字段不删，重新查询旧折支持：

| v10.1严格键零支持错例 | 粗键有同类支持 | 粗键仍无同类支持 |
|---|---:|---:|
| M：224条 | 8 | 216 |
| S：230条 | **230** | 0 |

这支持更精确的区分：多数这些M错例是较粗层级也缺支持；S错例主要面临**新端口/新子类型组合的迁移问题**。粗键有支持不证明它足够分M/S，也不意味着可删端口；v5.4删有效端口后明显退化是保留它的反证。

后续错误账本同时列严格键支持、粗键支持、字段完整性、完整输入冲突。支持计数使用真实标签仅作监督审计，不作为预测特征或未知样本的路由条件。更粗键支持不能冒充精确反例，精确键零支持也不能冒充模型一定无解。

## 3. 分组验证：有真实结构限制，不应靠换种子掩盖

原计划固定哈希三折的ASA S留出数为 **659／31,639／1,761**，其中一折占全ASA S的 **92.89%**。各折含S组数为 **90／83／99**，组数反而较均衡。

我试跑了官方提供的 `StratifiedGroupKFold(n_splits=3, shuffle=False)`，按“格式×类别”分层，仍保留全部连通组：

| 零训练划分比较 | 原固定哈希 | 格式×类分层候选 |
|---|---|---|
| ASA S原行数 | 659／31,639／1,761 | 6,046／21,266／6,747 |
| 含S组数 | 90／83／99 | 62／31／179 |
| 最大一折S占比 | 92.89% | 62.44% |
| 同组跨折 | 0 | 0 |

最大单个S连通组就有 **21,206条，占全部S的62.26%**。任何完整留出此组的划分，都不可能把每折S均分为三分之一；拆开这个组会破坏隔离。

**本次不采用这个分层候选，也不继续扫种子。** 它改善了行平衡，却恶化了组数平衡；用户要求有更好依据才改，当前没有充分依据替换。保留原定哈希作为固定开发分布压力，补充以下解释和评价约定：

- 原行主指标按所有OOF原行汇总；组指标按所有组汇总。不能先把不等规模的三个折等权平均，然后称全人口结果。
- 每折必须与同一折、同训练定义的基线成对比较。报告完整分母、训练类别比例和最大组贡献；不把三个折当三个独立重复实验。
- 同时列出最大组及其余组的贡献，全部组都保留在主评分中，不因困难或大而删除。
- 原文“最差折不退”具体指三折中最低的**M/S等权F1**不低于匹配基线的最低值；另列逐折每类退化，不能用该最小值掩盖其他折的错误交换。原有逐类、旧正确保护的正式晋升要求不放宽。
- 预检查发现 `cef_fields/S`、`windows_message/M` 各只有2条原行，不可能保证每折都有这两个格式×类单元。无评价支持记N/A，不记作零错通过，也不复制样本填满三折。

[scikit-learn 官方说明](https://scikit-learn.org/stable/modules/cross_validation.html#cross-validation-iterators-for-grouped-data)介绍了组隔离和类别分层的不同作用。选择分层方式只能改变开发评价的工程条件，不能增加真实独立组，也不能恢复已经多轮观察数据的盲性。

## 4. 扩池对照能证明什么：收紧归因，避免再次误判

T-small与T-full保持模型家族和公共评价组相同，这点合理。但是扩池同时改变样本量、行为覆盖、格式比例和类别比例，不能将收益全部归因“模型学到了新行为”。例如原定第0折ASA训练M/S比由 **3.11变为1.49**；第2折由 **3.74变为1.71**。

修订后的名称是 **“扩大官方训练人口的总效果对照”**。首轮仍仅6次教师拟合，不为追求解释完整性提前增加一堆控制模型。必须同时报告：

1. 原行逐类P/R/F1、正负翻转和各类预测数量。
2. 每个输入支持从小池到全池的变化；严格零→有、粗支持→精确支持、仍零支持分别计数。
3. 相同留出人口上的M/S分数排序指标与混淆矩阵，区分边界整体移动和判别排序改善；分数仍不是已校准正确概率。

若后续需要声称收益主要来自新增行为证据，再登记类比例匹配的有限控制；它不自动成为生产权重。没有这个控制时，只报告扩池的总效果。关于类别比例漂移的[BBSE研究](https://proceedings.mlr.press/v80/lipton18a.html)要求类条件分布稳定等假设，本项目尚未满足，不能直接套用先验修正或用留出真标签调偏置。

## 5. TabM保留为候选，但修正接入方式

v10.2拟议流程是“完整稀疏输入→共享128维映射→TabM”。[作者实现的重要说明](https://github.com/yandex-research/tabm#important-implementation-details)明确要求：不同成员的表示应在首次线性混合之前形成，并列出“先普通Linear再EnsembleView”的不推荐例子。

因此，原计划中这个细节有明确修改依据：

- C-MLP：完整稀疏输入→普通稀疏线性层→骨干。
- C-TabM：完整稀疏输入→成员各自的输入缩放→共享稀疏线性变换及成员输出缩放→集成骨干。按作者BatchEnsemble语义在首个混合层建立成员差异。
- 不先做一个所有成员完全共享的128维瓶颈。保留128维作为当前初始候选宽度，不宣称它已最优或数学无损；没有新证据就不继续改宽度。
- 保留所有输入坐标和事实直连；按成员分别算交叉熵后平均，推理平均概率。原行权重仍为1。
- 实施时验证稀疏与密集公式的前向、梯度、输入列覆盖和保存重放；检查成员初始化确实不同。该验证只证明接入正确，不证明泛化提高。

这是**修正与作者方法不一致的结构顺序**，不是宣称换TabM必然优于MLP。上轮已有字节特征、128维投影和三类输出等多种设计选择；C-MLP与C-TabM应共享同一人口、坐标和训练目标，不能将改输入、改损失和改骨干同时算作集成的功劳。

不在本次把ASA头强行改为二分类：目前ASA原行没有B，但历史v5.4的正常ACL反例说明直接屏蔽正常输出并不安全。最终组合中的B边界必须明确：开发质量比较使用**同折训练的基础模型**；冻结的历史正式模型只能另作安全回归参照，其可能见过当前评价行的输出不能充当新的OOF泛化成绩。独立候选原始三类输出和实际组合输出分别保存。

## 6. 训练与选择：只改已发现的执行歧义

**先执行阶段A的6次覆盖对照，完成原因分解后，才决定是否启动后续最多9次拟合。** 覆盖对照不合格不等于禁止后续学习研究；启动后续应写清是在检验表示/骨干，还是修复退化，而不是默认跑满预算。

若进入候选对照：

- 原100个周期改为**初始预算上限**，25／50／100为预定候选检查点，不再暗示最终100周期一定最好。优化器、学习率、宽度等未经新实测的参数暂不再改，不增加大网格。
- 每个检查点在全部三折共用同一个周期数。检查点、方法的选择都属于已观察的开发OOF选择，不称独立验收；不能按每折的标签各挑最优再拼一个虚高OOF结果。
- 在满足原有逐类/组/最差折继续条件的候选中，以全OOF原行M/S等权F1选择；相同分数优先更短周期。记录所有检查点及训练、留出曲线。不因看到外侧错误再临时增加新周期。
- 首次结果报告所有候选，不在选中的结果上仅靠同池bootstrap宣布成功。原两次额外种子复核保留为有潜力候选的条件性后续工作，不用多随机种子挑最好一次。
- 研究继续与正式模型晋升仍分开。旧正确、M/S和正常/其他格式的正式保护条件不变；没有合格模型就不替换。

[ERM++](https://arxiv.org/html/2304.01973v4)用验证曲线研究训练长度，而不是将固定预算等同于充分泛化；[Cawley与Talbot的模型选择研究](https://www.jmlr.org/papers/v11/cawley10a.html)说明反复优化有限验证集本身也会过拟合。本次据此明确选择职责，没有为看起来严谨而再次层层切小稀缺训练人口，也没有声称这些已看开发标签重新变盲。

## 7. 未采纳的修改及理由

- **不恢复重复降权或组均衡训练**：组指标揭露失败是评价依据，不能直接推出训练权重最优；v5.5有实际退化反例。
- **不删除真实端口**：粗键支持审查只改变统计尺度；实际输入保留完整可观察字段。
- **不改成大语言模型或加更多辅助损失**：本轮尚无证据证明能解决本地困难判别。
- **不把规范化宣布为最终输入赢家**：v10.1 N1教师仅多2错、N1分支多94错，说明方法交互需要检验，尚未确定N1在新候选中优胜。
- **不新增放宽M保护或负翻转预算**：没有实际收益依据支持更改用户的重要约束。

本轮真正得到的改进是：支持机会由笼统的113条收敛到实际划分下的101条；明确严格组合支持和粗行为迁移的区别；找出并修正TabM的接入顺序；明确同折基线、检查点选择和分组统计边界。**这些提高了下一轮实验回答问题的能力，模型精度是否更好仍必须由下一轮真实训练决定。**

零训练预检查数据在 `artifacts/v103_plan_preflight_20260928/`。v10.2及其绑定证据保持不变，本文与新契约作为显式修订，不回写历史结果。
