# V159 独立全量复核与下一项机制决策

结论：V159 已完成六次拟合与完整评价，但没有解决“训练侧没有学会分类”。停止当前配置的追加训练，不启动确认或替换模型。下一项先验证**共同下降方向是否能主动满足保护约束**；通过真实有限步资格之后才开展新训练。不能用更长训练、缩小步长、较低 CE 或参数数量来替代这个验证。

本报告依据独立读取官方 2,056,871 行原始真值、六个固定终点、逐行概率账本及实际调用日志重算，未调用官方分类器、特征函数或梯度，未更新模型参数。

## 2. 训练侧究竟发生了什么

| 角色 | B 接受更新 | B 纯输入错误：初始 → 终点 | 修复 / 新错 |
|---|---:|---:|---:|
| 0 | 10 | 3,302 → 3,278 | 24 / 0 |
| 1 | 0 | 1,960 → 1,960 | 0 / 0 |
| 2 | 19 | 1,600 → 1,586 | 14 / 0 |

这些是合法训练角色的原行计数：角色重复不能当成独立新样本。B 合计仍有 6,824 条纯输入训练错误。部署 FIT 的既有能力保护通过，但这不能证明使用交叉拟合意见的训练路径也掌握分类。

六个终点均为 `no_feasible_step`。这个状态只表示**当次固定方向及登记的步长范围**没有获准更新，不能改称全参数空间无解、模型收敛或数据无法分类。

B 三角色分别有 51、39、60 次拒绝：即使仅按原有限数值标准检查，两类 CE 都能够下降，分类保护仍阻挡。角色 1 总共试了 40 次，39 次属于这一情形。B 的主要阻挡来自 OOF 原本正确的纯输入记录；A 则主要受到部署 FIT 保护阻挡。单纯将同一方向反复减半没有利用这些约束的信息。

保存的 B 终点中，OOF 受保护且仍正确的记录有 2、10、2 条对数概率间隔不超过 1e-10；部署侧没有这种记录。这个阈值仅用于诊断，没有删行、放松保护或更改质量门槛。拒绝试探没有保存逐行预测，因此这些近边界记录尚不能被认定为实际阻挡者，下一资格必须补齐这项证据。

另一个候选卡点是梯度启动：零输出初始化使初始 1,060,784 个隐藏/输入/意见/偏置参数的梯度严格为零，只有 48 个输出参数获得梯度。角色 1 没有接受更新，确实从未启动隐藏学习；角色 0 的输入参数最大变化仅 3.57e-11。不能据此声称所有容量都已充分使用，也不能直接证明改初始化即可解决保护或泛化。

## 3. 已研究的现成方法及适用边界

- [GEM 原论文](https://papers.neurips.cc/paper/2017/file/f87522788a2be2d171666752f97ddebb-Paper.pdf)与[作者实现](https://github.com/facebookresearch/GradientEpisodicMemory/blob/master/model/gem.py)：使用约束梯度调整方向，提供保持旧能力同时继续学习的思路。原方法保护的是记忆任务平均损失，不能直接保证本项目每条已正确记录的 argmax；需要替换为实际分类间隔约束，并保留全行有限步检查。
- [MGDA 原论文](https://papers.nips.cc/paper_files/paper/2018/hash/432aca3a1e345e339f35a30c8f65edce-Abstract.html)：支持寻找多个目标的共同下降方向。V159 已使用两类梯度最小范数方向；缺口在于方向求解没有纳入分类保护条件，不能把继续使用同一 MGDA 当作新方案。
- [GEM 对偶推导修正](https://arxiv.org/abs/2107.07384)：历史实现不能不经验证直接复制；新求解器必须核验符号、原问题残差和可行性。
- [LoRA-GA](https://arxiv.org/abs/2407.05000)及[作者初始化补偿说明](https://github.com/Outsider565/LoRA-GA/blob/main/doc/detail.md)、[PiSSA](https://papers.nips.cc/paper_files/paper/2024/hash/db36f4d603cc9e3a2a5e10b93e6428f2-Abstract-Conference.html)：提供保持起始函数同时改善初始可学习方向的经验。它们的收益来自其他任务，不能外推成 SOC 收益或直接安装低秩适配器解决本项目。

本项目已执行两项零官方调用的反证：2D 数学例表明，固定共同下降方向所有步长失败时仍可存在安全方向；三种种子的 CPU 合成中心化残差例表明，起始输出严格保持时也可以让全部参数分段获得非零梯度。前者只支持保护方向资格，后者只支持备用梯度启动资格，均未证明真实 SOC 分类改善。

## 4. 下一轮的递进顺序：先解决方向与保护的冲突

**唯一优先因素：在现有 V159 模型及三个固定 B 终点上加入主动保护约束的方向求解。** 当前完整输入、16 个合法教师意见、原频次、真值、来源划分、既有能力范围和质量门槛保留。暂不同时改架构、初始化、权重或增加模型规模。

1. **先定位阻挡者，零永久更新。** 按登记的有限诊断预算重新核验固定 B 终点及原方向，先保存概率、对数概率和风险，再保存实际翻转的原行身份、合法训练角色、真值、保护类别、间隔及对应的竞争类别。区分 OOF 保护、部署保护和数值拒绝，不用来源外标签生成方向。
2. **让方向主动满足约束。** 在两类完整原频次平均 CE 梯度之外，引入实际阻挡记录的分类间隔法向；方向必须同时给两类明确负斜率、保持保护间隔。只看来源平均 CE 不够。相同 local 不等于相同真实输入；只有完整数值输入、意见和标签约束完全一致才能合并重复约束，损失仍按全部原行频次计算。
3. **实际有限步验证。** 局部线性约束可行不等于非线性模型有限步安全。每个候选都重新检查全部注册保护人口、两类实际 CE、更新身份及数值分辨率；失败后补入实际阻挡约束，受固定轮数、法向数量和调用上限限制。求解失败或没有可分辨的安全共同下降方向即停止并记录，不换种子、不松保护。
4. **资格通过才训练。** 正式训练须新版本绑定全部源码、依赖、输入、终点和真实调用预算；匹配对照使用同一固定初始函数和人口，单因素比较方向算法。固定终点与真实最后五个不同接受状态，不能挑最好状态。预算不得通过改版本无理由重置。
5. **验收三个层次。** 机制通过：三角色均出现有明确数值余量、全保护通过的真实有限共同下降。训练问题通过：三角色纯输入错误为零、全部原行含冲突组计分并达到登记的 22/6/28 输入范围要求，最后五个不同状态均通过，联合旧能力新增错零。任务通过：官方全量原始真值下逐类召回/精确率、修复/退化、来源与困难组满足原质量规则；已看开发折不能冒充盲测。

若真实约束诊断不支持安全方向，不进行无收益的长训练；再独立评估函数保真的非零梯度启动因素。中心化残差会增加冻结锚与额外计算，不能仅因可训练参数数量相同就声称架构和运行成本相同。两种因素不能同时更改后再猜收益来源。

## 5. 执行故障、成本与防复发

实际完成六拟合，342 次完整类梯度、574 次试探、165 次接受更新；训练 13,376 次头/意见块。包括预检技术失败和修复，累计 14,586 次头/意见块、362 次完整类梯度。

评价首版来源 CE 汇总误差检查错误，消耗 110 次调用；修复版又把终点行表与最后接受状态的来源表混配。后者已完成 360 次实际重放，保存的三角色数组独立复核通过，复用后只补 280 次。没有重复拟合，最终评价恢复实际 640 次，连首失败累计 750 次，原 720 阶段预算的技术净增加为 30。全部旧失败源码、日志、成本保留。
