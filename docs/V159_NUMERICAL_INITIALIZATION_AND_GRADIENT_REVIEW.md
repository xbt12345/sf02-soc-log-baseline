## 合成梯度反例及最小处理

合成真类 S、旧概率 `[0, 1, 0]` 的结果：

- `softmax(log(max(q,1e-12)) + delta)` 配合稳定 `log_softmax` 损失，在零修正时仍有 S 修正梯度约 −1，损失和梯度有限。
- 若为精确保存概率，使用 `where(delta==0, old_q, new_q)`，零初始化梯度全部为 0；这个写法不能进入新训练器。
- logits 修正达到 ±1,000 时，保存概率可能下溢为零，但稳定 log-loss 仍为约 2,027.63，梯度仍有限。不能把“先 softmax、再对概率 clamp 后取 log”的截断值冒充实际训练 log-loss。
- 给所有专家均偏 M 的合成概率增加自由 S logit，可以跨出旧凸融合范围。它只证明这一类自由函数具备相应表达，不证明真实网络学会了 SOC 判据。

推荐执行器在更新前锁定一个可审查的数值政策：例如 10⁻¹² 的底数和不超过 3×10⁻¹² 的零步概率容差，同时要求原点全部判决保持。不能为追求 bitwise 原概率而截断学习，也不能看到结果后修改底数。实际模型必须用自己的完整头、输入验证、参数和损失，另行完成合成反向传播与起点真实保存数组比较；本补充的通用变换不代替那些资格。

当前补充没有规定新头的 N 输出处理方式。若只允许 M/S 修正，执行源码必须明确 N 的保持、归一和零概率处理；若使用自由三类 logits，则必须记录 N 的变化、三类守卫和全任务验收。两臂同函数、同数值政策、同初始化，不能把数值修复误归因共同下降算法。

## 执行前必须满足

1. 所有注册概率合法、形状正确、有限且归一；不通过底数修复负数、NaN 或错误人口。
2. 与当前角色原点的概率误差和逐原行判决差异均保存，容差在任何正式更新前绑定。
3. 合成零真类概率、极端 logits 和当前完整头均有有限且可用于学习的真实梯度；零输出初始化的内部层初步零梯度与整个头断梯度须分开。
4. 训练稳定 log-loss、保存概率的截断 CE 及逐类错误分别记录，不混合比较。
5. 本项数值资格不能授予模型质量通过；后续仍按完整来源外及三分类门槛判断。
