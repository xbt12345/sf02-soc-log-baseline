## 精确对象与计算

实际函数为逐成员 `H2@head_weight + head_bias + facts@head_facts.T`，实际判定为16成员softmax概率平均后argmax。完整保留三个类别、全部成员；平均logit只记录为可能不同的诊断，不改真实预测。N不因ASA缺正常训练记录而被删去。

固定三折，每折全部22546 actual locals按2048分块，共36次完整SecondRepresentation.forward。通过无改值的features包装捕获该次真实前向的H2，内部共36次features调用；它们包含在完整前向内，不是另加36次features。捕获后重复头部投影和facts矩阵计算以验证真实logit代数，保存body/facts/bias、各成员实际logit/概率及汇总。模型张量身份、grad空值及与V155已保存共同原点概率的逐元素精确身份必须通过。

477既有facts坐标按真实representation_contract名称分组，另18个记录源端口坐标按原v75_metadata编码作为完整一组（16位、observed、conflict，固定缩放）。总495坐标各覆盖一次，包括当前不活跃的其他字段；不只看13解析字段、不删未知或ICMP不适用状态、不覆盖body源端口。分组之和允许1e-12舍入差，重建概率差≤2e-12且argmax一致；body+bias+facts按原顺序相加必须逐元素完全一致。

36次完整前向之外的body/facts及全部字段矩阵分解也有计算，但不冒充独立分类器前向或新能力。全部112807原行对齐每折的真实概率；三折338421角色行（225614合法TRAIN角色、112807outer原行），不是新增独立数据。原频次、混标、未知、正确对照及原困难578/严格正确51/V155新错16均保留。所有已经查看的外折只用于事后诊断，没有阈值/门控/层/检查点选择。

## 运行与失败边界

新增分类或decoder拟合0、参数梯度0、参数更新0。登记阶段不运行官方分类器或features，只准备完整字段分区、原行身份、真实初始化及依赖；在任何官方模型求值之前绑定机器方案、入口/helper/tests、本设计、父V156独立复核、三个实际V146 A checkpoint、H1/H2/facts、保存概率及全部runtime物理依赖。每次入口检查prospective seal、Python/包版本。技术错误保留source/seal/实际调用进度，修复另版，不从部分点交付完整结果。

## 能作的下一决定

分量是注册当前坐标下的函数代数，不是独立概率、安全语义因果或移除字段后的效果。父V156坐标/head逆缩放反例保留；V150可解码字段不自动证明当前head正确使用条件。大/小分量、分类翻转归属和同类支持不能混用。

本轮应明确后续训练究竟需要新函数路径还是当前信息的不同使用条件，而不是无限叠诊断。若证据仅支持缩放/删除facts、换平均logit、移阈值、改半径或重启旧head，拒绝直接续训。若发现H1可提供当前函数缺乏的类别关系，也不能仅凭余弦直接启动新头；须核对合法TRAIN的功能性类别信息及完整保护能力，并说明与历史H1/H2线性读出的实质差别，另立有界匹配方案。尚无新训练因素时明确缺口，不宣称已解决第二第三或全任务。
