## 固定目标、实际状态和联合保护

三个角色从 V159 固定 B 终点继续，分别固定合法纯错误原行 3,278 / 1,960 / 1,586，总 6,824 个角色观察、4,614 条独立原行。保留原频数，目标 stable CE 分母始终为完整原类质量。当前已验纯正确和后续新接受的纯正确修复累计纳入保护；目标集合不重选、不删除修复行、不按候选表现增权。完整 M/S 类错误每次接受不得高于当前实际接受起点；混合原行保留监督记录和评分，完整 CE 仅诊断。

初始零步重放 OOF 和全部署 q/logq、目标与完整原类 CE，按既有 8eps、精确 argmax 与已保存固定终点比较，参数哈希不变、联合既有技能保持。每角色第一步仅重放已有限合格的唯一安全方向与步长：角色 0/1/2 的 2^-10 / 2^-14 / 2^-20，四份原实际目标梯度已重复合格并绑定。第一步仍执行真实候选并核对参数哈希，不把旧诊断当永久更新。

之后每个真实接受状态对 M/S 两个完整目标梯度各实际测量两次，保存四份后按原四段 8eps 检查；候选保持原 16eps 下降、Armijo。求解及数值重构保持 V160 v5/Decimal80 已资格模块；每迭代先无新增保护法向地生成共同下降候选，最多 3 轮真实阻挡函数收集。法向在当前参数起点实际成对测量，完整函数身份去重，每轮保留全量阻挡原行；不得将旧参数点的梯度作为新起点的法向复用。每迭代最多 24 个法向、40 个固定步长 `2**(-j), j=0..39`，没有阻挡但风险不降/低于分辨率、法向/求解/预算问题均分别停止，不宣称全局不可行。

接受后真实赋值并保存参数、全部原行 q/logq 和来源账本，再累计新增纯正确保护。联合检查使用已完成的新角色终点和当前真实候选，其余角色仍使用原固定 B 终点，不能只拿旧模型凑联合通过。持续记录隐藏层/意见层/bias/输出层梯度、更新与起点距离，旧错误真类对起点错误竞争类间隔，以及固定目标当前仍错误/已修复两部分的原频 CE 和来源分解。

训练掌握沿用实际纯错误为 0、保护退化为 0、全部原行错误不高于原明确界限，并要求最后 5 个真实不同的接受参数状态全部掌握。窗口不足不补齐；不挑中途最优状态作为终点。达到原明确预算或局部资格失败即保存最后实际接受终点，失败及全部候选保留。
