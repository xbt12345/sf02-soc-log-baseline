## 当前可以做出的判断

- 本次新测量的差异处于很小的双精度浮点间距，支持修复“必须所有梯度逐位相同”的验收要求；没有证据要求更换模型、抹掉原输入、密集化矩阵或换设备。
- 这不认证其他角色、非零输出状态或后续模型都具有同样误差。原失败也可能有不同量级，无法从本次重测还原。
- 具体CUDA算子的因果归属仍未证明。CSR SpMM源码和NVIDIA文档是排查候选，不是已验证的算子定位。
- 预测/log概率完全一致是工作对话的实际封存断言，诊断没有保存这些数组供父对话单独重算；父对话只对已保存梯度、组合方向和调用费用提供独立重算证据。

## 最小修复候选的必须条件

保持相同输入、模型、种子、标签频率和六拟合假说，仅版本化修订数值重复与模型重放检查：

1. 固定float64尺度准则，检查有限性、完整参数区段、重复梯度相对范数及组合方向。不能用过大的绝对底数吞掉真实小梯度；近相消或不稳定下降符号必须单独拒绝。
2. 用具有真实输入维度、稀疏密度的合成数据，在非零输出权重状态测试概率、log概率、完整梯度与有限步。零输出状态不能覆盖隐藏扰动对真实输出的影响。
3. 保留实际下降要求。有限步风险改善落入计算分辨率时不追认成功；不因重复容差允许loss未变却记录有效学习。分类判决、旧能力保护和任务质量门槛继续精确检查。
4. 非零状态的risk、保存概率与模型终点重放也要使用经测试且预登记的数值准则，不能仅改gradient检查后在下一次调用处重复失败。
5. 新入口及依赖另行封存，原失败不覆盖。若重新完成三个角色的12个重复预飞行梯度，总技术梯度将为20、总类梯度上限2420；总头/意见上限78,196，而正式拟合仍6、训练类梯度仍2400、每拟合proposal仍最多600。这是故障后有依据的技术预算升级，不能声称原2412预算已经完成所有验证。

该候选尚须实际资格与真实预飞行通过，不能凭此报告开始拟合或宣布第一问题已解决。

## 研究边界

[带函数噪声的线搜索研究](https://arxiv.org/abs/1910.04055)分析的是在误差假设下到达与噪声相关邻域；[BFGS误差分析](https://arxiv.org/abs/1901.09063)也指出精确函数/梯度的假设与有限误差情形不同。这里借鉴的是区分有效下降、数值分辨率和真实收敛，不能把其收敛结论直接用于当前神经网络，也不以它为放宽分类门槛的依据。
