# SF02 选模审查与实验执行约束

本文件是本项目后续训练审查的通用入口。用户当前明确指令优先；规则更新应有证据、保留历史和重新验证，不新增用户审批环节。历史发现只在其证据范围内成立，不自动升级为普遍规律。

**三个不同结论必须分开：可以做试验；分类质量通过；有资格做独立确认或正式替换。** 工程检查、低训练损失、局部机制收益均不能跨级替代真实分类结果。

## 1. 唯一职责与当前约束的范围

- 本文件说明决策逻辑和失败处置。
- `training/review_policy/history_cases.json` 保存历史反例、证据哈希和必须对应的执行动作。
- `training/review_policy/next_batch_plan.json` 是下一项批次实验的机器可读方案；其 25 轮、6+12 次拟合及 ASA 错误预算只适用于该实验，不是永久训练定律。
- `training/experiment_review.py` 实现方案前置检查、执行绑定、终点检查、完整评分和逐类结果重算。每轮报告描述事实，不维护另一份冲突的规则。
- 最新实际训练仍由现有交付凭据确定。审查/方案更新不能改写为“已训练”或“质量已通过”。

## 2. 规则是否合理：先回答四个问题

1. **它测的是什么？** 例如 argmax 不变只说明分类未翻转，不说明概率停止学习；参数已见不说明同类支持已见；较低 CE 不说明跨来源分类更好。
2. **它覆盖什么人口？** 单列 K/U 或其他切片可以，但主风险报告必须包含所有注册的留出记录。未知值、缺失参数和困难组不可从分母移除。没有某类时相关质量不可估计，不能赋成满分。
3. **什么证据会推翻它？** 每项新方法需要明确失败结果与停止条件。保留不利折、种子和来源。存在反例时缩小主张，不通过换划分、权重或挑种子隐藏反例。
4. **它有权做哪个决定？** 描述学习状态的指标只能用于诊断；允许新试验的机制证据不能直接允许模型晋升；已经查看的外层结果不能成为同轮阈值或检查点选择答案。

这四项包含科学判断，脚本不能自动证明其全部正确。脚本用于检测已知矛盾、缺证、越权和历史失败模式；通过后仍须在报告中写明尚未验证的假设。

## 3. 历史风险必须变成动作

| 历史风险 | 必须执行的限制 | 触发后的处置 |
|---|---|---|
| V116 弱 K/U 平手选早 | 当前实验固定终点；保存早期状态但不自动晋升 | 拒绝未登记终点，不将完整训练误述为物理早停 |
| K/U 遗漏缺失参数与 collateral | 主评分与独立参考行身份逐项一致，无漏行、重行或额外行 | 拒绝完整评分声明，修评分实现；不删除难例 |
| 已知参数缺对应类别 | 分开报告参数支持、同类支持、来源覆盖及集中度 | 弱挑战任务保留计分，但不授予其普遍停止权 |
| V81/V110 损失或内部结果改善、来源外退化 | 训练侧与来源外逐类结果分列 | 分类质量失败即不继续确认，不用更低 CE 覆盖失败 |
| V104/V113 用 M 退化换 S/总分收益 | 从逐行真值重算 M/S 漏判、误报、修复、退化及完整三分类 | 任一注册类别保护失败就拒绝候选 |
| 收益集中单折大组 | 固定多折要求和大组以外保护，保持原行主指标 | 局部发现只能称局部，不称稳定跨来源收益 |
| 新旧基线漂移、数值非确定性 | 新 A/B 匹配基线，固定种子与初始化；合格后做预定确认 | 小收益不声称稳定；开关或相同种子不代替实测 |
| V117 局部梯度收益，V118 第 2 折反向 | 方法只进入有界试验，全折保留，不按折 ID 特供方法 | 六次主试验分类门槛未过，不追加十二次确认 |
| 看结果后修改规则 | 训练前绑定方案、训练器、依赖、数据/折；运行前复核哈希 | 修改后旧执行绑定失效；必须新版本重新审查 |

明确区分：漏行、污染、错终点、身份变化是**执行错误**；支持不足、数值波动、机制不普遍是**已知能力/证据限制**。前者应阻断或修复，后者可以支持一个边界清楚的试验，不能假装已经解决。

## 4. 后续每轮的必要流程

### 训练前

读取当前状态与本文件；核对将要复用的结果及其原始凭据。只继承适用的历史结论，不把不同人口或不同表示的分数直接排名。明确变化因素、假说、原行质量、合法拟合/验证角色、候选终点、真实胜负指标、种子与停止条件。

每项适用风险必须在方案中绑定到具体动作及来源。先运行：

```powershell
.\.venv-v61\Scripts\python.exe training/experiment_review.py plan --plan training/review_policy/next_batch_plan.json
```

当前方案通过只表示可以开展受限对照。新训练器实现后，在任何参数更新前调用 `seal_run(...)` 绑定真实入口和**全部**导入源码、配置、数据映射与划分依赖；在训练入口及每次新的拟合调用 `require_run_seal(seal_path, __file__)`。依赖清单需通过代码审查确认完整，散列本身不能自动发现漏报依赖。执行绑定不能事后补造。

通用工具目前实现的是当前固定终点、单因素批次方案。将来若引入自适应早停、其他训练目标或其他范围，必须另有设计证据和历史反例回放，并升级验证实现；不要伪装成固定终点以绕过检查。正常方案迭代无需增加用户批准环节。

### 训练中

按注册规则使用全部合法训练记录及原始频次。每轮记录实际步数、每类累计质量、在线损失与数值状态；固定检查点保存模型身份、逐类概率和错误。在线 CE、成员平均 CE、集成概率 CE 不混用。目标标签仅用于合法训练/诊断角色，不使用外折错误来即时调权。

质量波动不授权同轮改方案。技术故障保留日志、模型身份和未完成状态，诊断后按版本重新执行；不从失败运行挑一个早期检查点充当完成结果。保存诊断概率不等于它们被用于选模。

### 训练后

先调用 `require_checkpoint(plan, metadata)`，再将**独立绑定的参考真值**和逐行 A/B 预测交给 `evaluate_primary(...)`。它忽略预测文件自带的角色元数据，并拒绝自带真值与参考不一致，重算每类分母、错误、F1、折及来源保护，不接受调用方自己填的 `all_checks_passed=true`。

完整人口必须包括正常与其他格式。ASA 子表可做诊断，但不能因 ASA 指标好就获得全任务通过。当前预登记完整人口为 2,056,871 行；模型重放、原始数据/训练输入完整性和实际拟合完成度还须单独核验。逐行计数重算不等于预测确由注册模型产生。

主质量通过仅允许注册的确认阶段；不自动晋升。确认失败不得替换为新种子。真值、指标和来源定义不在看到结果后改变。若未来确需修订门槛，说明任务依据、保留旧结果并创建新方案版本，不能追认旧失败为成功。

### 写入和恢复

每轮至少保留：方案及执行绑定、实际运行状态、逐行预测账本、类别/来源修复退化、未通过项、问题及下一步决定。新增实质性反例进入项目历史案例库并增加可运行回放；同一问题不只再写一段总结。

更新 README、训练入口及只读 MCP 时，区分当前方向和最新实际训练。不修改旧交付和历史哈希。`AGENTS.md` 只引用本文件，避免多处复制形成不同规定。

## 5. 必须保留的反证测试

- 真实 V116 的已完成 25 轮但选用 15 轮候选应被拒绝。
- 真实 K/U 不得冒充包括 collateral 的完整评分。
- 真实 V113 总错误减少但 M 新错 52，不能被总分/低损失覆盖。
- 真实 V116 多出 2,542 条 S 错误，不能被少错 24 条 M 覆盖。
- 全判正常的高总体准确率、缺类、重复/漏计记录、篡改真值必须被发现。
- 已绑定方案、训练器或依赖改变后，旧执行绑定必须失效。
- 存在一个满足条件的合格小型对照应通过主质量计算，避免校验器“永远拒绝”却看似可靠。

运行：`.\.venv-v61\Scripts\python.exe -m unittest discover -s training -p test_experiment_review.py`。

这些措施降低重复犯已知错误的概率，不构成模型必然提升或未知数据必然正确的保证。没有系统级沙箱阻止任意手工运行旧脚本；约束覆盖遵循本项目入口、调用和执行绑定的新训练流程。历史脚本作为证据保留，不作为未经复核的下一轮入口。

## V140新增实际反例的适用边界

V137/V138末层链现已两轮12拟合用尽（V140替代旧第二轮目标，未执行旧C_margin），V139参数锚定未训练，不能在同链追加。后续第一问题的新机制须有独立证据并改变有理由的可训练范围，不能只改版本重置预算。此约束属于该具体末层链，不是永久禁止训练。
