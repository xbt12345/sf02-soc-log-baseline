# v4.3 方案复审：保留有效信息，独立学习 ASA 分型，先验收再接入

2026-09-14。当前已完成一手资料研究、全部 106,953 条允许开发的 ASA 记录的信息审查及独立计数复核；**本轮没有训练新分类器、修改标签或使用外部训练数据。** 最近实际训练仍是 [v4.2](V42_EXECUTION_REVIEW.md)，其 R/G 零修复、零退化，未晋升。

**优化后的主方向：冻结公共 B，重建独立的 ASA 恶意/可疑分类部分，允许缺少部分观测，保留有效端口和行为事实，用分层共享参数处理稀疏组合。** 完整键只用于支持与冲突审计，不再充当“必须所有字段齐全”的硬开关。候选先独立暴露全部分型结果，再检查接入 B 后的三分类效果，不能靠回退掩盖模型自身无能。

这是一条待验证的最小主路线，不是已经证明优于现有模型的结果；实施与拟合前还需冻结具体配置和内层划分。

## 1. 第一性原理：分别处理信息不足、模型不足和评估不足

### 1.1 已有信息仍有价值，不能再大范围删字段

本轮重新读取原三折与冻结预测，将完全相同的观察输入按“折×输入”合并计数。对一个固定的单条日志分类器，同输入只能给出同一类别；组内最多正确 `max(n_malicious,n_suspicious)` 条，所以这批记录的最低错误数是各组 `min(n_malicious,n_suspicious)` 之和。

| 输入视图 | 不同输入键 | 三折逐折最低错误数 | 合计 |
|---|---:|---|---:|
| 保留现有全部可观察事实 | 16,874 | 662 / 634 / 674 | **1,970** |
| 统一移除源端口及派生范围 | 5,171 | 1,092 / 1,062 / 1,048 | **3,202** |
| 统一移除两端端口及派生范围 | 26 | 1,672 / 1,597 / 1,656 | **4,925** |
| 仅保留哪些字段可用，不保留值 | 11 | 9,403 / 8,855 / 9,402 | 27,660 |

当前 B 实际错误为 6,018，距全部观察事实的事后最低数有 4,048 条差距。**这不是承诺能修正 4,048 条，也不是总体 Bayes 错误估计、Macro-F1 上限或迁移成绩。** 它使用已经查看的评价标签，只说明“相同输入必须同答”的有限样本约束，以及不同表示丢失了多少区分能力。三个折各有自己的模型；不能拿跨折合并的单模型最低数 2,510 混作这个逐折界限。

这次还确认：ASA 当前语义正文全部为空，模型所用差异来自结构化事实。换一个更大的文本编码器不能凭空增加当前输入的信息。215 个跨折合并的混标语义键涉及 23,220 行，但这不等于 23,220 行都无法分类；应按每组类别构成分别计算。

**取舍：保留真实读取到的端口，停用占位符数字和无意义编码规律；不再把“对字段敏感”一概当成错误。** 改变真实目的服务可能应该改变判断；改变产品空值、身份和外层日期则不应改变本项目的行为分类。

### 1.2 主要缺失范围并非完全没有可学习对照

v4.2 因源端口不可用而排除的 4,076 条错误中：

- 2,451 条在拟合侧的相同可观察语义下，两种分型标签都出现过；
- 其中 1,287 条对应的两种标签分别有至少三个不同正文键支持；
- 原 v4.2 却因源端口不完整，将它们全部排除。

全部 ASA 中，“拟合侧两种标签分别有至少三个正文键”覆盖 10,297 行及 1,287 条现有错误。这个范围只是一项支持审计结果，**不是新的晋升名单，也不证明这些错误全部可修复**。数量反证了“缺一个字段就完全无法学习”的假设。

另一方面，拟合侧某输入只有一种标签、评价侧却出现相反标签的记录有 1,311 条，B 在其中错误 921 条；这提醒我们不能把拟合侧纯标签当确定规则。v4.2 的“正文支持不足”错误中，865 条属于这种反向纯标签情形，不能统一按更多支持或加权解决。

### 1.3 单个被拒绝的数据包不等于已证明的攻击

[Cisco 的 ASA 106023 官方解释](https://www.cisco.com/c/en/us/support/docs/security/adaptive-security-appliance-asa-software/217679-asa-access-control-list-configuration-ex.html)说明其记录的是被 ACL 拒绝的数据包。结合[官方系统消息说明](https://www.cisco.com/c/en/us/td/docs/security/asa/syslog/asa-syslog/syslog-messages-101001-to-199021.html)，连续同源行为才可能提示扫描。这支持一个任务边界：仅见 `deny` 不能直接推出本题的 malicious 或 suspicious。

当前没有脱敏后时间/IP 关联真实性的说明，也没有额外标签规则。因此目前不根据绝对时间造攻击链，不把原始 IP 当可信会话标识，也不将 Loglizer 的窗口异常分数直接替换为本题三分类标签。

数据证据：[信息审查](../artifacts/v43_information_audit_20260914/identifiability.json)、[独立计数和错误支持交叉表](../artifacts/v43_information_audit_20260914/verification.json)。

## 3. 收敛后的唯一主候选

### 3.1 公共基准与局部分类分工

- 公共 B 的源码、输入投影、编码器和参数保持冻结；非目标日志的全部概率必须与 B 相同。
- 新 ASA 分类器直接学习 `q = P(malicious | 已观察的行为事实, 非正常)`，只用官方允许开发的 ASA 恶意/可疑记录；不再以 B 的恶意/可疑分数为固定起点，也不限制在两倍赔率内。
- 接入层沿用 `p_benign`，将原非正常概率质量分配为 `p_malicious=(p_malicious_B+p_suspicious_B)*q`、`p_suspicious=剩余质量`。原 B 判正常或重分配会改变正常/非正常判定时回退，明确报告回退数量。
- 目标资格由已审查的消息结构和行为事实识别，不由产品字段、日期、标签、IP 名单或缺失模式确定。
- 输出两份评价：**候选在全部目标记录上的独立分型**，以及**带保护接入后的三分类**。未知组合也要评价独立预测，不能因为最终回到 B 就说新模型通过迁移。

这继承的是 v4.2 的隔离边界，舍弃了其无法产生收益的固定分数起点、极窄完整性门控与过小幅度。ASA 没有正常训练样本，仍不重新学习正常/攻击边界。

### 3.2 表示与分层共享

首个候选采用结构化、带分层惩罚的二分类逻辑模型，验证可观察信息的共享假设。选择它是因为能直接检查每个值、交互和未知组合如何贡献分数，且当前字段少、样本规模可在本地处理；尚未证明它优于所有其他模型。

拟合输入只包含：协议、动作/结果、方向角色、真实可读的端口、ICMP type/code 等已核实事实。端口作为有名称的离散观测使用，避免把整数位模式或大小关系直接等同于攻击语义；派生范围与原值的重复职责在此局部新表示中明确列出，不能再影响其他来源。

参数结构为：

`分数 = 公共行为项 + 行为组合的偏差项 + 已观察参数的条件效应`

行为组以协议及两端角色等语义组合定义。参数效应结合所属行为组收缩到共享父项；样本少的组更依赖父项，样本充分时允许差异。未知端口没有专属已学参数，缺失端口也不填 0、平均值或占位符号码；其余可观察信息继续参与。缺失原因单列在审计资料中，不作为带类别偏置的新分组截距。

必须承认：不显式加入缺失指示列，并不等于模型完全无法感知哪些项没有出现。对同一可见事实而言，`null`、空值、不同占位符类别和编号应投影一致；从完整记录删除一个真实字段可能改变信息量，不能要求这种删证据变换的预测一律不变。

保留原行次数。对完全相同的拟合输入可聚合计算以提速，但交叉熵乘回原次数；不恢复重复降权。

### 3.3 混标语义只审计，不自动清洗

将疑似问题分为三种：

1. 原文有可读取的差异，当前表示却合并：修正有来源位置的语义提取，再重新验证；
2. 原文差别只是身份、外层日期或脱敏占位符：不重新引入这些标记以凑高分；
3. 现有观察不足以解释标签差别：保留原标签，输出概率与信息限制，继续计入完整评价。

这里没有人工确认的软标签真值。将组内标签频率写成软标签 `q_k=n_k/n`，再乘原次数 `n` 的交叉熵，恰好等于逐行硬标签的交叉熵。**这可作为计算压缩，不能单独算优化算法，更不能保证修正冲突。** 本轮已做数值等价检查。若不用原次数，则改变了样本权重，需要独立比较，不能隐瞒成“去冲突”。

## 4. 训练前必须补齐的比较设计

本轮已完成的是信息审查；以下是下一次执行的顺序，尚未运行分类器：

1. **先冻结一套候选、表示与有限配置。** 在外折拟合侧再划分内层职责；相同正文与指定完整组合按连通约束隔离，检查两类支持和大组造成的不可划分情形。困难切片无有效支持时注明未知，不能改成随机按行切分。
2. **先做一个内层反证实验。** 使用固定小规模正则候选集合，选择依据限于内层；观察项、缺失投影和组合测试提前固定。候选在内层没有实际分型改善或只能依靠缺失比例追分，则停止，不支付三个外折的无效拟合成本。
3. **通过后执行原三折独立比较。** B 直接复用；单一新 ASA 候选按各外折重新拟合。参数选择、支持、字典和任何概率校准都只能来自该外折拟合侧。若需要校准，另设独立职责；不能将拟合分数当已校准概率。
4. **分别报告五类证据。** 同协议整体成绩；源/目的端口可读性×协议×类别；完整组合未见、已见部分组件但组合未见；混标/纯标签/反向纯标签语义；旧来源或模板压力。旧压力集只能作为已见压力资料。
5. **只有通过后才考虑接入。** 在同一批行上要求 ASA 错误减少、至少两折改善且多正文受益；恶意和可疑的错误分别不得净增加；原小切片和非目标记录保持保护。既看 Macro-F1，也看每类召回、正常误报和分组损失。不能靠只降低多数类 log loss 晋升。

若采用 bootstrap，按正文组而不是按行重采样，同时报告原行次数与正文等权的评价摘要；正文等权仅作为诊断视图，不悄悄改变训练权重。区间反映这个开发样本内的变化，不能升级为真实新环境保证。

### 缺失机制压力要正确设计

压力分两类：

- **无信息变化的干扰**：替换外层日期、产品空值、用户名、地址身份、占位符的拼写与编号，保留可观察行为。要求相同投影与预测。
- **确实减少观察的遮挡**：在可读日志上遮掉源端口或目的端口，只用来观察分型损失、置信变化和覆盖。不能把未遮挡预测当作唯一正确答案，也不能宣称随机遮挡复现了真实脱敏机制。

真实未知端口通过留出其组合评价；替换目的端口可能改变实际服务含义，不作为必须保持标签/预测的干扰操作。不同缺失组重新配比只用于汇总已有压力指标，不能从评价标签学习模型补偿项。

## 5. 七轮对抗审查与方案修正

| 审查轮次 | 反证 | 已完成检查或形成的约束 |
|---|---|---|
| 1：删字段是否真的更稳 | 源端口全删是否损失有效信息 | 全量描述界限 1,970→3,202；两端全删→4,925，否决普遍删值 |
| 2：缺失是否使整条日志无效 | 无源端口但其他事实有两类对照 | 查到 2,451 条现有错误有拟合侧两类支持，其中 1,287 条每类≥3正文；取消全字段完整门槛作为主学习限制 |
| 3：支持多是否就是可靠标签 | 拟合纯标签遇反标签评价 | 1,311 行、921 条现有错误；纯标签规则和仅按正文数的确定性判断不成立 |
| 4：软标签是否创造了信息 | 频率软标签和原始 CE 的数学对照 | 保留次数时完全等价；不将其宣称为单独提分方法，不自动改标或过滤少数类 |
| 5：更强惩罚是否万能 | Group DRO 可能持续追逐冲突组 | 先用分层收缩和最差组评估；暂不把 hardest-group 加权作为新主目标 |
| 6：保护是否掩盖无能 | v4.2 回退后零退化却零收益 | 新候选独立分型与保护后的三分类同时报告；未知组合单列，零变化不算通过 |
| 7：高分是否能证明攻击检测 | ACL deny、失真时间/IP 与已看过标签 | 用 Cisco 语义确认仅观察拒绝；不捏造时序关联、不改三分类含义、不宣称迁移完成 |

这七轮包含数学反例、全量资料计算和方法前提审查；它们不是七次新模型训练，也不是独立外部评审。新分类器仍欠实现、内层反证、外折评价和保存模型回放。

## 6. 应当明确舍弃与保留的内容

**舍弃：** 原样重复 v4.2；恢复脱敏端口数字；普遍删除所有端口；仅扩大固定偏移；多数票自动纠正官方标签；把冲突少数类交给 CleanLearning 自动过滤；在尚不可信的时间/IP 上构造行为链；把论文或开源示例的高分当本项目效果。

**保留：** 官方原始数据及原标签；原始行次数；公共 B 与非目标记录的隔离；真实可观察行为；完整组合留出和小类评价；可重放的概率、来源与版本记录。

研究和本轮审查已在本地完成，没有下载新数据或安装研究项目。下一步唯一推荐的执行是上述独立 ASA 条件分类实验，先做内层反证再外折；当前无需操作训练平台。若该路线在独立分型上仍失败，应转回剩余语义与题目标注可识别性审查，不能继续用更多补丁掩盖。
