# 成员 CE 与集成 CE：续接审查补充

## 已有事实与反证

本地 `training/v131_model.py::objective`、`training/v138_readout.py::full_gradient` 使用成员负 log-softmax 后求平均；实际推理平均 softmax 概率。

[TabM 作者 README 的 Training/Inference 部分](https://github.com/yandex-research/tabm/blob/main/README.md)明确采用成员分别训练、平均损失，推理再平均概率。[论文](https://arxiv.org/abs/2410.24210)讨论独立成员与集成的训练动态。本项目 `docs/V132_TRAINING_MASTERY_REVIEW_AND_NEXT_PLAN.md` 也已经记录这一点。因此两种目标不同是事实，但不能把这种不同直接称为实现缺陷或已证实的残错原因。

固定主体表示、仅拟合当前末层不是原作者完整网络训练设置。因此直接集成 CE 可以作为不同目标的有界对照，不宜因原作者默认做法就禁止；也不能把改目标本身称为修复成功。

## 可检验的数学差异

对一条合法原行真类 y，成员真实类概率为 p_k，K=16：

- `L_member = -(1/K) sum_k log(p_k)`。
- `L_ensemble = -log((1/K) sum_k p_k)`。
- Jensen 不等式给出 `L_member >= L_ensemble`。差值非负不等于分类错，也不等于集成损失训练一定更好。
- 对共享末层参数求导，集成损失等价于将成员 CE 梯度按 `r_k=p_k/sum_j p_j` 组合，而成员损失按 `1/K` 组合。高真类概率成员会取得更高的责任系数。这可能帮助集成，也可能削弱其他成员的学习；实际责任集中程度须用合法 TRAIN 测量。
- 线性读出上的成员 CE 是凸目标；平均 softmax 后的 CE 不宜自动视为凸目标。不能继续借用旧全成员线性 margin 可行性作为其全局最优或无解证明。

## 单问题对照的检查要点

1. 同起点/输入/合法原行频次/参数范围/求解器预算；只更换损失，保持推理仍平均概率。不能同时引入类权重、成员路由或容量变化。
2. 用 `logsumexp(log_softmax(logits), member_axis)-log(K)` 计算平均概率的 log 值，防止极小概率导致不必要数值下溢；需实际前向、梯度与原行质量对照验证。
3. 在合法 TRAIN 的剩余错误与预登记正确对照中报告两种 CE、真实类概率/间隔、成员责任分布和梯度。诊断数据不自动获得调参、挑终点或改变权重的权限。
4. 实际分类缺口、已登记保护新错和来源外逐类结果分别计数。集成 CE 下降不能替代纯训练错误修复与成果保护，更不能证明跨来源判据成立。
5. 若未通过，分别检查损失计算/求解不充分、目标改变未带来正确边界、稀缺输入支持或表达限制；不凭“对齐推理”继续无限追加轮次。
