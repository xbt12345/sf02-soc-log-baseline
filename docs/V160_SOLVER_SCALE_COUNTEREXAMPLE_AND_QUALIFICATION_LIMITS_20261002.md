# V160 新求解器资格中的实际数值反例

本轮仍聚焦训练未掌握分类。V159 已完整失败；当前没有 V160 正式训练或官方有限诊断结果。

新增纯合成试验已实际完成，输入不含官方数据、模型或梯度。在 2 维和 1,060,832 维的相同几何问题中，将两个类别梯度和保护法向共同缩放为 1e-6，SLSQP 在一次迭代后均返回 `success=True`，实际保护法向斜率却为 **-1e-12**。两个类别斜率分别为 -2.5e-12、-4e-12；类损失下降方向不能证明保护可行。

同一个正公共尺度归一后，求解返回方向 `[0,-1]`，两类保持下降、保护法向斜率为零。公共尺度不改变两类权衡或约束可行锥；不能用分别归一两个类别梯度替代。这个正例只证明上述合成反例可处理，不证明真实模型的数值资格或分类收益。

此前合成反证还覆盖：约束共同下降确实不存在时返回零方向；局部线性保护通过、非线性有限步保护仍失败。新入口必须区分数值无法分辨、固定切空间不可行、有限步失败和实际分类失败，不能统一写成模型收敛或数据无解。

对下一诊断的具体影响：

1. 求解器成功标志只能记录运行状态，不能授予安全方向或训练资格。
2. 必须登记正尺度处理，并在原单位核查方向、两类斜率、保护法向残差和 KKT 条件。合成脚本使用的 1e-10 断言、1e-14 优化器停止值不能直接成为官方数值政策。
3. 保留独立的完整人口有限步分类检查；不因线性约束残差在数值范围内就忽略实际翻转。真实误差政策须有资格与固定边界，不能在看到失败后放宽。
4. 真实诊断前绑定三个固定 B 终点、合法训练角色、完整数据/来源与预算；保存实际阻挡原行、概率/对数概率、梯度及求解残差。禁止用来源外标签生成方向；没有永久更新或新拟合。
