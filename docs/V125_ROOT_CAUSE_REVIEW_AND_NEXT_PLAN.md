## 2. 本轮新增的根因证据

### 2.1 输入变化和重训变化已拆开

对 682 条时间头记录，固定第 25 轮模型，只交叉输入，M 的 44 条始终判对；638 条 S 结果如下：

| 固定模型 | 旧 A 输入 S 错误 | 修复 B 输入 S 错误 |
|---|---:|---:|
| V124 A 模型 | 0 | 54 |
| V124 B 模型 | 0 | 50 |

这比只比较 A→B 更具体：两个已训练模型都对旧头部编码有依赖。重训 B 只使新输入下的错误从 54 降到 50，**没有学会充分替代被移除的线索**。这里比较的是完整头部修复，不能将全部 50/54 错都归因于某一个日期数字。

其余 112,125 条输入完全未变，B 修复 134 条 S、新增 20 条 M 错误。这些变化来自训练后模型参数差异，不能称为对应记录增加了行为证据。冻结输入回放不是将训练随机性、梯度顺序、表示变化全部分开的随机因果试验。

因此，V124 的净收益既不能证明时间头修复提高分类，也不能证明单纯删除来源线索就能获得迁移性。工程修复仍有价值；失败分类器不热替换。

### 2.2 可见数值没有在已检查链路中消失

从官方文件重新核对全部 112,807 条 ASA 原文和标签，并核对 event_id 映射；重建 22,546 个旧 local 的文本矩阵、112,807 行事实矩阵与记录级端口元数据。对原文中的已知端口及 ICMP type/code，独立读取原文数值，再从真实矩阵位坐标解码：**173,142 次数值比较，0 次不一致**。

另有 **52,472 个不可用端口槽位**。这是端口出现次数，不是记录数；它们没有被猜成真实端口。已验证的数值保全不等于任意语义保全：当前文本仍是 byte 1/2-gram 计数，不保任意长程词序和条件绑定；事实字典是否遗漏其他可用语义、原始脱敏是否删除标签所需上下文，仍未完全证明。

目前不支持再次把主要失败归因于“可见端口数值被压缩掉”。也不能由低输入冲突率推出“安全判据充分”：独特的记录级端口或正文外观足以让输入不同，却未必提供可迁移的 M/S 依据。

### 2.3 训练侧确实还有非冲突学习缺口

62 条已知参数难例对应 8 种可见参数行为、15 个外折×行为条件。V124 的 206 个训练 S 角色实际只有 **136 条不同官方记录**；总训练角色 7,904 条实际是 6,566 条不同记录。

| 重点训练参照 | A | B |
|---|---:|---:|
| S 训练角色判对/206 | 122 | 120 |
| S 错误角色 | 84 | 86 |
| 至少一个训练角色判错的不同 S 记录 | 60 | 62 |
| 错误涉及的来源组 | 19 | 19 |
| 错误角色处于真正相同矩阵异标签组 | 0 | 0 |
| 留出的 62 条 S 判对 | 0 | 0 |

按真实矩阵哈希核对，不能用旧 local ID 近似同输入。第 1 折的对应训练 S 只有 16 个角色，A/B 全错。A 的重点训练 S 错误从第 1 轮 176/206 降到第 25 轮 84/206，说明确实发生了学习；但七个检查点的留出 62 条始终全部错误。不是整个训练没执行，也不能用“还没学完”自动批准继续加轮。

范围扩大到全部合法训练 ASA：A 三折 S 错误分别为 669、531、694，其中同输入混标内的 S 错误只有 22、4、26；即分别仍有 **647、527、668 个非混标训练错误角色**。三折人口重叠，不能加成独立错误总数。这排除了“剩下都是输入冲突”的解释；但尚不能分清优化、表示归纳偏置和有效监督覆盖各占多少。

### 2.4 小收益还受训练轨迹波动影响

V121 旧 A 总错 2,560，本轮匹配 A 总错 2,760，差 200；本轮 A/B 净差只有 64。旧/新 A 的三折初始化相同，最后状态不同。**200 不是噪声标准差或置信区间**，不能据此做显著性判定；但足够说明不能拿不同轮最低分拼接收益，也不能称单种子 64 条为稳定改进。稀疏 CUDA 非确定性只是待核假说，尚未证明是唯一原因。

## 3. 最底层的判断，以及前几轮给出的限制

模型输入是脱敏观测 X，目标是官方标签 Y。识别成功至少需要：X 含有足够线索；表达能保留并组合线索；训练能学到；该联系在未参与拟合的来源中仍成立。当前四环都不能用另一个环的成功替代。

1. **存在已证实的头部线索依赖。** 删除线索暴露了替代行为判据不足；不是删除动作本身已经完成去偏。
2. **存在真实的训练学习缺口。** 非混标训练错误很多，不能再笼统说模型容量肯定足够。应检验表示和学习机制，但不能反过来断言只要扩容就能迁移。
3. **存在细粒度监督覆盖缺口。** 持续 S 错误中 1,796 条在当前目的参数分辨率下没有同类训练支持，但粗行为层都有 M/S 支持。“精确条件未覆盖”不等于整个行为无支持，也不等于模型一定能从粗层共享标签依据。
4. **M/S 的标注解释仍有缺口。** 以拒绝事件为例，端口/协议/阻断事实不直接说明主办方为什么标 M 而非 S。Cisco 对相应拒绝日志描述的是访问被拒绝；不能拿它生成比赛标签，也不能据此断言官方标签错误。[Cisco 原始文档](https://www.cisco.com/c/en/us/td/docs/security/asa/syslog/asa-syslog/syslog-messages-101001-to-199021.html)

历史反例限制下一轮：V61 的 SecureBERT 内层高分未迁移；V92 的自由分支接近拟合经验界，内层却新增 500 M 错误；V104 更久训练损害 M；V110 降低拟合错误仍损害来源外；V113 接口规范化的 S 收益集中且损害 M；V121 改批次使训练侧改善而外折明显退化。人口、表示、折不完全一致，不能把它们的分数直接排名，但足以否定“更低训练损失/更大模型/更均衡批次本身就够了”。

## 5. 下一轮只检验一个能力假说

首选：**现有 N1 完整通路 + 可训练有序正文分支 + 同容量乱序负对照。** 不全盘替换已验证的信息链路，也不继续单独重跑 V124 时间头因素。

假说是：当前输入虽然保住已知数值，却可能未有效利用正文中更长的组合关系；额外可训练的保序表达能帮助非冲突稀缺条件，并迁移到未参与拟合的来源。现有证据尚未证明词序是主因。过去要求“先证明真实跨来源规则，才允许能力试验”过强，应改为“具体可证伪的表达假说、合法对照和固定预算允许一次诊断试验；分类晋升仍严格验收”。这不是降低 V124 的失败门槛。

### 5.1 训练前一次性准备

- 全部官方 ASA 和原始频次保留；不只训练 62 个错例，不按历史错例 ID、root 或外折答案路由/加权。136 条训练参照及 2,236 条持续难例是诊断切片。
- A 保留原 N1。B/C 的新增通路使用同一个经过边界检查的正文规范化字节串，排除整个 syslog 时间头，保留可见数字、角色词、未知占位符和未解析剩余正文；全量跨度账本可回溯原文。记录级端口仍留在原通路，不猜不可用值。
- 新表示若拆开旧 local，所有臂使用同一原始行到扩展输入的映射；旧 local 仍作为逻辑采样单元，一个单元内各正文按原始频次计算损失。绝不选一条代表正文丢掉其他变体，也不因表示合并而给重复行降权。预先审查全输入跨折相等/近重复与来源闭合。
- 固定命名/时间变体测试、已知数值回读、src/dst 条件绑定挑战和未知格式保真回退。绑定挑战只检验表达能否区分字段关系，不伪造 M/S 标签。
- 做固定小批量的前向、损失、反向重放检查；保存初始化、批次顺序、优化器、环境、源码哈希。若重复操作不一致，先报告差异并检验可用确定性实现，不能仅设置随机种子就声称排除波动。失败不静默换算子或批次。

### 5.2 三臂三折，一次有界实验

| 臂 | 唯一作用 |
|---|---|
| A | 新鲜匹配 N1 + 原 SparseTabM |
| B | 同一 A 架构，加小型有序字节编码器，联合训练，通过残差三类 logits 接入 |
| C | 与 B 完全同架构/初始化/优化预算，只将新增通路的正文非 padding 字节按无标签确定性置乱；原 N1 通路不动 |

候选新分支采用 byte vocabulary 0–255 加独立 padding、64 维、2 层 Transformer、4 头、FFN 128、dropout 0、固定位置编码；带 mask 的池化后投影为 3 类残差 logits，初始输出为零。新增参数上限 250,000。B/C 参数数逐项相同，基础通路初始参数与 A 对齐；共享通路仍可训练，不把训练侧正确强制冻结当成来源外保证。

正文不截断。长文按长度分批；若必须分块，所有 token 都须参与，规则在封存前确定；原逻辑批内梯度累积后只更新一次。这里的小 Transformer 是本项目待测实现，不声称复制 ByT5 或 TabM 原论文。

三折按 V106 来源闭合，seed 10201，原行频次三类成员 CE，AdamW lr=.002/weight_decay=.0003，旧 local 逻辑批 256，固定 25 轮，检查点 1/2/5/10/15/20/25 仅诊断。共 **9 次主拟合、13,350 次预期更新**（每臂三折 1,825/800/1,825）；预检若映射导致步数变化，应在训练前重新审查登记，不能运行时静默改变。无阈值搜索、无校准、无类别或重复降权，同时变更因素限于上述表达分支。

乱序 C 是破坏性机制对照，不是标签保持的数据增强，也不具备晋升资格。B 优于 C 仍不能独自证明安全因果关系，还可能来自文本形态相关性；必须同时优于 A、保护 M 并通过跨组和外观压力检查。若 C 同样改善，不能将收益归给顺序，应停止相应机制结论，而非挑更好的一臂改故事。

### 5.3 验证直接决定下一步

训练结果必须同时回答：

1. 在全体训练非混标输入及重点 136 条 S 中，是否真正降低错误，M 是否受损？训练 CE、概率间隔、成员分歧分开记录；这仅回答“是否学会”。
2. 在全部 112,807 条 ASA 来源留出行上，M/S 正确数、precision/recall/F1 是否改善？62/186/192/1,796 四桶、682 时间头、小组和非 ASA 全保留分母；这回答“是否迁移”。
3. B 相对 A 与同容量 C，新增修复来自哪些原行/组？收益是否至少跨两折，并在最大三个 S 组以外成立？压力变体是否揭示更强的文字外观依赖？这回答“收益来自哪里”。

如果 B 没减少非混标训练错误，不宣布解决学习缺口；如果只减训练错误而来源外不改善，直接拒绝该方向，不接着默认加轮；如果只改好 62 条却破坏全量 M/S，同样拒绝。

沿用旧晋升预算 ASA M≤318、S≤2,094、总错≤2,170，同时满足匹配 A 的 M/S 召回/F1 保护、完整三类保护、至少两折改善、大三组外保护、S 等组召回不降及零召回组不增加。它们是项目阶段预算，不是官方及格线。**解释某个机制有效**和**分类器允许确认**仍是不同结论。

只有 B 主质量全部通过且负对照没有推翻机制归因，才运行 seed 10202/10203 的 A/B 三折 12 次确认；失败保留全部结果，不换种子。未通过外观不变/字段完整压力检查，不作“已消除时间影响”的主张或模型晋升。

### 5.4 缺支持与缺标签解释并行处理

保持仅官方数据。补一张按可见行为而非错误 ID 定义的完整覆盖表：两类各有多少不同输入、多少来源、是否被单组支配、参数是否真实可见。对 1,796 条无细粒度同类支持和 186 条未知参数池化支持，不用伪造端口、SMOTE、同标签假语义对比或 LLM 改标去“补齐”。

从现有真实记录形成最小 M/S 原文对照卡，列出相同已知事实、剩余不同字段、训练来源支持和仍缺的判定口径。这是待澄清证据，不对外自动发送，不把未解决行剔出质量分母。没有新外部标签时，可开展有界共享表达实验，但不能保证当前官方观测足以解释全部边界。

## 6. 对抗性审查结论与本轮记录

- **反问：数值都保留了，何必新编码器？** 当前证明的是数值可回读，不是更长关系易于学习；新实验必须与同容量 C 区分，不能预先归因为词序。
