# v4.0 执行方案：缺失中性事实与受控交互

更新：2026-09-13。**状态：本方案已执行，九次主拟合完成，整体质量未通过，未触发压力拟合。** 实际结果以 [V40_EXECUTION_REVIEW.md](V40_EXECUTION_REVIEW.md)为准。I 降低 ASA 错误，但 Duo 10 条和 Windows AD 18 条原先正确的可疑记录退化，未见 ASA 输入也变差。当前没有晋升的新分类器。

以下保留已执行约定；训练前未更改的原件在 [approved_plan.md](../artifacts/v40_local_r1_20260913/prepared/approved_plan.md)。第 2 节已更正“零向量移除缺失信息”的过强解释；这没有改变训练代码、冻结配置或实际输入。本轮依据仍为 [制定阶段复审](V40_RESEARCH_REVIEW.md)和 [v3.9 实测](V39_EXECUTION_REVIEW.md)，不能将制定阶段假设视为已成功验证。

## 1. 目标与不变边界

优先解决有实测依据的两项问题：全局缺省码参与分类，ASA 位编码线性模型仍有明显无冲突拟合错误。同时检查少数类和来源外推是否恶化。

只使用官方训练数据。沿用 v3.9 最终允许开发池 1,378,650 行、508,823 个正文键及三折角色；原外层评价继续排除出拟合。新的特征词表、支持统计、缩放和模型参数只能在各折拟合侧建立。旧开发和旧压力数据均已查看，不重新命名为盲测。

维持原行等权、三分类完整输出，不做重复降权、硬改标签、自动 JTT、全局可疑偏置或报警门槛。正文组计数用于证据支持与验证，不改变训练行权重。

禁止产品、供应商、原始时间、事件 ID、资产字面编号、用户名、IP 字面身份进入模型。既有有依据的相对角色和行为时长继续保留；所有字段并非都应无影响，真实行为值应能改变预测。

## 2. 必做改动：观察事实与缺失状态分开

新增独立 v4.0 编码器，不改 v3.9 冻结代码和模型。

1. 对原有限码，**未观测/不适用不生成可训练的缺省码分量**。现存 65,536 等缺省哨兵不得当成端口值。
2. 保留观察到的零值、每个合法端口、ICMP 码等。固定码采用合法值 `n+1` 的位编码，零向量留给未观测；按各字段合法范围分配足够位数。无效值停止或标明解析失败，不截断成另一个合法码。**执行后解释更正：规则取消主动激活的专用缺省码，零向量仍可识别缺失，因此并没有消除缺失状态信息。** 有限合法值与缺失仍可一一对应；表示改变了线性函数与正则化的作用，不能由“信息可区分”推断分类等价。
3. 有效枚举与数值继续在观测时激活；数值零与缺失分开。未知、脱敏、部分解析等状态写入质量侧表，不直接为某个类别提供独立分数。
4. 将认证的同一个结果规范化为一个共享事实，保留无效凭据、未响应等真实细节。只有同一语义重复才去副本；不按标签相关性删特征。通用操作失败与认证失败不能盲目合并。
5. 原文抽取、类别事实及副本合并均记录来源位置。修改产品/时钟/身份包装后，规范事实和预测应保持不变；观察值、事件结果等有效信息变化则应正确进入编码。

必须承认剩余限制：观察到哪些事实仍会暴露可用性，文本仍可能携带模板形态。缺失中性不等于领域完全不变。复用冻结 v3.9 可用性模型作为弱基准，另统计新观察模式的同结构切片；不声称它是新编码的可用性模型，不额外增加三次对照拟合。该诊断不加入正式分类答案。

## 3. ASA 的主效应与交互：不再只让数值位相加

在缺失中性编码上增加观察参数的稀疏类别主效应，再增加预先限定的交互：

- `transport_protocol × dst_port`；
- `transport_protocol × src_port`；
- `icmp_type × icmp_code`，只在相应 ICMP 协议下形成；
- `action × transport_protocol`。

首轮使用现有 scikit-learn 稀疏工具，不增加 EBM/CatBoost 运行依赖。结构借鉴 GA²M 的“单变量函数＋少量交互”，**不是宣称复现 EBM**。相对原端口数值，类别函数和联合类别项具有新增非线性表达能力。

类别词表只由拟合侧观察值建立，不用标签编码，不用特征哈希。未见类别项可以不产生已学系数，但第 2 节的固定观察值编码保留，避免再次把所有未见端口压成一个输入。交互项只在两个值都被真实观察时生成；不要生成 `缺失×缺失`。

为限制正文复写被当成参数关系，每个联合值至少在该折拟合侧 3 个不同正文键中出现，才建立该交互系数。该数值是有界开发的支持门槛，不是统计独立性或泛化保证；不足时仍保留各单项与固定编码。禁止全参数组合查表、`src_port×dst_port` 笛卡尔积及资产编号交互。

不把任意端口关系解释为攻击真相。单报完全未见端口、未见联合值、已见输入及同输入反向标签情况；只在已见端口上变好不能称参数外推改善。

## 4. 有界比较，区分机制而非连续调参

冻结以下首批候选，均沿用原标签与原行损失定义：

| 候选 | 表示与拟合 | 它回答的问题 |
|---|---|---|
| B：冻结 v3.9 对照 | 复用三折最终 SEMANTIC，`C=0.1` | 同协议原结果 |
| R：正则化对照 | 原 v3.9 表示，仅固定 `C=1.0`，三折 | 是否主要被原惩罚强度限制；不继续搜索更多 C |
| N：缺失中性 | 第 2 节编码、同语义去副本，`C=0.1`，三折 | 缺省投票与重复事实整理后的完整三分类表现 |
| I：主效应与交互 | N 加第 3 节类别与交互，`C=0.1`，三折 | 新表达是否在 N 之上改善 ASA，是否带来记忆/外推退化 |

首批最多 **9 次新拟合**，原 B 不重训。N 同时处理编码与明确副本，不能把其全部增益归因于单一子改动；本轮 R 用于识别明显正则化限制，并非严格匹配新表示的全部隐含正则化。

全程逐模型运行，缓存固定正文与解析，不把全部日志扩展成巨大稠密矩阵。若资源不足，先在独立临时目录验证内存，再沿用相同数据与算法分批变换；不能静默抽样替代正式比较。优化器必须收敛，序列化回放与推理入口必须一致。

三折检查完成后，只有在同协议无实质退化且目标切片改善时，选定一个候选做 **1 次旧协议压力拟合**。压力数据不得用于早停、调正则化、选类别词表或反复换候选。选择次序：先检查少数类与正常误报退化，再检查 ASA/认证目标错误，最后才比较总 Macro-F1；成绩接近且目标切片同等时优先改动较少的候选。

若 I 仍明显存在无冲突拟合不足，则下一步采用有明确交互约束的 EBM/浅层 boosting 对照。它不再依赖对比配对资格，但必须先核实分箱、未见参数、分组验证及实际环境兼容性；此分支不偷偷扩展本轮九次拟合预算。反之，若训练改善而未见组合恶化，停止扩容量，转向支持与表示检查。

## 5. 验收与失败识别

所有指标来自完整折外记录，保留 B/M/S 精确率、召回率、Macro-F1、混淆矩阵、正常误报、分组支持和固定协议。保持每条记录的原始计分次数，不能删除冲突或困难记录提高成绩。

必须输出以下检查：

1. **ASA 四类错误账：**固定复核 v3.9 的 1,522/921/2,479/1,096 四个子集，并另按新实际编码重新分类。不能因编码变化重新划类而让旧错误消失。观察字段保真测试必须覆盖全部合法端口及缺失/零边界；分开报告主动更改的缺省编码与意外碰撞。
2. **拟合与外推：**每折无冲突拟合错误、同输入经验冲突、已见/未见联合值的变化。类别参数频次不等于独立事件数量。
3. **Duo/认证：**逐条列出 8 个未响应和 2 个无效口令的三类概率；不能只看“正常→非正常”。来源留出仍是最终压力检查，不能根据这十条手写规则。
4. **稀有来源：**WAF 两条同正文可疑和有限命令正文继续全量计分。只要缺支持，能力声明仍受限。流量恶意召回改善与同格式正常误报能力分开报告，后者当前无法由官方样本验证。
5. **捷径与输入：**指定真实时间/产品/身份包装变换保持预测；缺省码不能再出现独立加分列；完整编码与质量侧表分开。重新审查有效事实出现模式能解释多少成绩。
6. **概率：**除准确率外看 log loss/Brier 与分来源误差；不直接将 Softmax 数值称为真实正确概率，不用 0.95 门槛冒充迁移能力。

近重复问题继续保留：v3.9 的 4,823 个跨正文键模型投影只是候选，不是已验证泄漏。训练前核对原始非空重复、正文键跨折仍为零；抽查与目标错误相交的候选是否还含包装变体或近复制。若找到新的确定性重复，先修订独立协议并对所有候选重建同协议基准，不能只给新方法换更容易的划分。脱敏时钟的真实顺序和事件关联仍未经主办方确认，不把按时间排序自动称作真实未来测试。

推进最低条件：目标改进至少在两折出现， pooled ASA 目标错误降低，且不能以 M/S 召回任一类别下降超过 0.5 个百分点或新增正常误报超过每万正常 1 条交换；这些是本项目比较容忍线，不是赛事或部署标准。容忍线内的每一项退化仍须列出，不自动表示可接受。极小尾部切片按实际修复/退化条目审查，不用总体阈值盖过它们。

旧压力下若 ASA/认证问题未改善、流量只是同格式恶意优先、或 WAF 仍无独立支持，分别保留“未解决”，不发布“全部迁移问题已解决”的结论。

## 6. 冲突与证据不足的处置

原标签完整保留；不使用全量或评价标签构造训练冲突表。只根据拟合侧记录以下侧信息：相同观察输入的类分布、不同正文支持数、是否出现过关键参数/组合、对应行为族有哪些类别证据。

证据不足标记不变成第四个比赛类别，不删行，不自动改成正常或可疑，也不等于保证能识别所有未知数据。跨正文相同输入关系可能改变；拟合侧纯标签也可能是脆弱支持，code 13 已实际证明这一点。

本轮已由本地 CPU 完成，不需要上传平台或补充训练数据。仍维持“尚无通过迁移验收的最终模型”。下一步问题收敛见 [执行报告第 7 节](V40_EXECUTION_REVIEW.md#7-本轮处置与下一步的最小问题)，不要原样重跑本方案或擅自启动压力训练。
