# V158 独立结果复核与下一轮训练决定

2026-10-01。V155 的原配置已停止；此前有互补证据，允许并已完成一次 V158 留来源 OOF 专家融合试验。现在实际完成 60 项拟合及全量评分，**V158 未通过，停止本配置，不晋升、不追加权重、温度、种子或轮数。下一项暂不直接启动正式训练。** 先解决新证据暴露的 OOF 训练监督允许牺牲类别和固定融合的表达限制，不能再拿普通 TRAIN 零错替代这两个问题的验收。三个问题和完整目标仍未关闭。

本文件是完成结果补充，不改写此前已经封存的 `V158_INDEPENDENT_TRAINING_DECISION_AND_PROGRESS.md` 及训练前方案，也不把技术记录修复当作分类收益。

## 2. 第一层：排除“完全没有学习”和保护阻挡

从共同零步到B终点，M修复1,306且无新M，S新增214且无S修复。零步相对V146已经修M184、新S29，所以退化含初始旧专家份额的影响，也含后续学习影响，不应全部归因初始化或全部归因优化。

六项融合的每次提案均接受，没有分类守卫拒绝。实际部署FIT的全部225,558条原正确角色记录及既有联合能力，终点和最后五个不同参数状态均保持。九条新底层链最终纯FIT M/S错均零。这只证明登记训练人口的保持，没有证明新OOF监督已经学会分类或来源外迁移。

## 3. 第二层：监督目标的直接缺口

融合梯度来自合法OOF行，现有保类守卫却检查部署基模型已学过的FIT输出。二者不同；FIT零错并不阻止实际OOF监督中的类别退化。

|B的外角色|OOF M/S 原行支持|总CE：初始→终点|S平均CE：初始→终点|OOF S错：初始→终点|
|---|---|---|---|---|
|0|58,840 / 33,497|0.167695→0.160446|0.336997→0.360916|1,420→1,470|
|1|38,886 / 2,071|0.340730→0.333400|4.805856→4.985405|1,190→1,220|
|2|59,770 / 32,550|0.096614→0.091380|0.170937→0.162285|938→900|

这是真实的“合法监督总目标变好、其中一类的训练判断和风险变坏”反例。第1角色S只占约5.06%，不能因总CE下降忽略它。也不能说所有折都同向失败：第2角色的OOF两类均改善，但来源外依旧没有S修复。以上足以否定用总CE/普通FIT守卫判定问题已经解决；不足以证明某一个类别梯度是所有部署退化的唯一原因。

下一项应把OOF训练分类、逐类风险和部署FIT保持分开记录并约束。不要凭直觉把S权重调高：旧类别/主体平衡已有M/S交换反例；训练与验证的真实效用都要检查。使用合法OOF类别约束或最差组风险只是候选机制，必须和相同函数、相同人口的普通目标配对验证。

## 4. 第三层：固定模型族的硬边界

进一步对全部ASA原行检查真实17专家库：

|B仍错的类别|全部专家真类-另一M/S类间隔严格为负|存在正确专家、B未使用|
|---|---:|---:|
|M，414错|148|266|
|S，1,872错|979|893|

对任意非负归一、两类共用的专家权重，融合间隔是这些专家间隔的加权平均。全负仍为负，因此本固定凸概率族不能修复979S和148M。这扩展了先前仅针对困难188的证明。它不是全部原始信息不可区分的证明，也不是所有类型stacking无效的证明，更不证明2,170总错门槛在整个凸族内数学上不可达到。

578条固定困难S全部错；51条严格正确S对照从V146的0错、零步21错变成终点49错。S零召回来源数由V146的183变为203；逐来源平均S召回17.90%降至11.16%，大来源之外错1,334→1,387。不能以修复大批M遮盖稀缺来源退化。

固定支持诊断：979个共同失败S中，36条有历史精细同类行为支持、126条有目的端同类支持、全部979条有较粗行为S支持。578困难S则精细S支持0，目的端支持160，粗行为支持578。支持的粒度与来源集中度必须分开；“有粗行为支持”不等于足够，“无精细邻居”也不能证明没有可共享规律。计数来自已经绑定的历史支持账本，不构成错误因果证明。

## 5. 调研：借鉴可复现的方法，拒绝算法名称代替证据

- [scikit-learn官方StackingClassifier](https://scikit-learn.org/stable/modules/generated/sklearn.ensemble.StackingClassifier.html)：最终分类器用交叉预测训练，可用逻辑回归等自由判别器，`passthrough=True`还能读取原输入。这和本轮强制非负凸平均不同。借鉴方向是允许根据完整可观察证据直接形成M/S判断；默认随机折、未经校准分数或训练内prefit不能照搬。这个方向在本SOC任务还没有获得有效性证据。
- [DomainBed原论文](https://arxiv.org/abs/2007.01434)和[作者代码](https://github.com/facebookresearch/DomainBed)：域泛化方法与选模方式必须共同评价，训练域内、留域验证与测试域oracle是不同权限。借鉴独立来源验证及匹配对照；不能把多次看过的外折当新的盲测，也不能用其错误名单训练路由。
- [Group DRO原论文](https://arxiv.org/abs/1911.08731)和[作者实现](https://github.com/kohpangwei/group_DRO)：在其图像/NLI实验中最差组改善依赖正则化等条件，朴素组重加权并不自动解决泛化。借鉴类别/组风险显式监督，不据论文保证SOC成功，也不直接启用历史已失败的类别权重或后验早停。

历史V128已经试过交叉教师+正文残差，V129/V110等也有迁移失败。未来自由判别头不能只换名称重试：须证明相对于这些旧方法新增了实际可用的行为/专家证据、改变了哪一项表达限制，以及如何防止已有类别再次被牺牲。

## 6. 下一步：先资格审查，再决定有限训练

现在不立即开启另一批正式拟合。下一项仍聚焦**训练监督未学出兼顾M/S的判据**，按以下递进顺序推进，不同时更换解析、多个权重、编码器和来源划分。

1. **复用现有合法OOF产物，停止重复54项底层生成。** 先核对拟议输入的真实身份、完整可观察输入冲突和同类行为支持；979与893两类缺口分账。原文和全部既有行为证据保留，不把32维正文投影当完整原信息，不用时间、产品、来源身份直接建立标签查表。保存数组可复用不等于旧模型及所有角色都能不经审核复用。
2. **只提出一个可证伪的新函数候选。** 优先评估“交叉预测＋完整行为输入的类别判别头”，允许直接学类别边界，能够跨出所有专家一致错误的概率凸包。先用合成数学反例证明函数可表达这种变化，并与V128/V110实际函数和预算核对差异；这不证明真实S已经可分。不能仅修改温度、常量偏置或正负融合权重后宣称补齐模型能力。
3. **监督约束先具体化。** 下一项配对控制应使用相同函数/输入/初始化/原行人口，普通目标与逐类OOF风险约束只改一项。候选的OOF M/S原正确保持、逐类CE/错误变化、稀缺行为同类支持分别报告，已有部署FIT能力继续独立保护。若约束无可行下降，记录冲突/梯度/拒绝原因并停止，不能偷偷放宽条件。
4. **独立性和成本合格后才登记拟合。** 最终头拟合见过的OOF行不是该头的独立验证；必须安排来源隔离的内部评价，审查底层监督、元学习监督和所有守卫是否读了对应留出标签。全部计入实际拟合/调用预算。来源、保类预算和终点在更新前锁定；不从现有外折结果调参。不建议再次大规模搜索编码器或追加邻域风险。
5. **真实验收与停止。** 训练侧逐类分类/风险改善和部署FIT保持是第一阶段；完整2,056,871原行、每类precision/recall/F1、来源外修复退化、多折/大组外、578/51/979各账本是第二阶段。旧门槛继续保留，新增候选门槛必须训练前登记，不能追认V158。一个配置最多按预定的一至两轮预算验证；失败结束，不靠换版本继续相同机制。不能承诺所有数据缺口必然在两轮解决。

上面是下一候选的设计要求，并非已通过资格的训练器或已启动的新模型。下一步可自主完成这项设计审查；无新增用户批准环节。当前正式新拟合为0，若资格证据不够则继续定位具体缺口，不启动模型来制造进度。
