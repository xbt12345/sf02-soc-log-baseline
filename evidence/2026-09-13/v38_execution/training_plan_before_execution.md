# v3.8 下一步方案：修复事实编码，直接验证三分类

更新：2026-09-13，依据 [v3.7 平台结果](V37_CLOUD_RESULT_REVIEW.md)及[定向研究、两项实测和六轮反证](V38_TARGETED_RESEARCH.md)。替代先前“二分类风险优先、再条件分型”计划，旧文本已保存为 evidence 中的修订前快照。

**状态：局部编码审计与旧模型决策探针已执行；新版训练、全量验收和单文件执行包尚未完成。没有通过质量验收的新模型。**

## 1. 目标和范围

比赛主输出直接为 benign、malicious、suspicious。优化和选择评价最终三类，不能以“先报警”替代三分类，不能以全判正常实现低误报。报警作为下游业务策略和诊断分数，不成为第四类、不改写比赛类别、不排除难例。

0.1% 是历史工程误报预算，题目未强制规定，改为诊断参考。主开发选择暂以受支持切片的三类 Macro-F1 为比较量，同时完整报告三类召回、精确率、正常误报和来源差异；不宣称它是官方唯一排名指标。评分细则若公布，再对照调整目标。

仅使用官方数据；原标签不删除、不自动改标；停用重复降权。冻结 v3.7 源码、模型、职责、指标和失败回执。五协议和已审计的官方验证答案都是已查看资料，不能重新命名为盲测。

模型必须依赖可解释的事实；禁止利用产品名、日历时刻、任意身份、上游判定和无行为内容的包装。不能以“原字段依赖越少”本身为目标，否则会继续丢失有效信息。

## 2. 已完成的局部结论

- ASA hard 固定编码追加实验：不同向量 1,406→10,748，经验最少总错误 3,246→1,776；两端口 34 维码的完整单端口值域往返通过。只证明保值，没有新模型成绩。
- 去掉原模型报警门槛直接 argmax，known_dev 恶意正确识别为 0；校准侧类别偏置所得 Macro-F1 为 0.79700，低于旧正式 0.97885，AD/WAF 可疑漏检及 ASA 可疑零检出未修复。
- 屏蔽 authentication 类别独立特征，使 known_dev 正常误报 39→0、Duo 62→0；须在新特征源中实现并重训确认。
- WAF 正常分数整体超出校准正常范围。不能读取评价标签来反选一个新报警常数。

因此不执行原样重训、旧模型只换报警常数、只换 argmax、只加两个类别偏置、直接替换通用 BinaryEncoder／Hashing 等简易方案。

## 3. 阶段 A：表示与支持审计

建立正文→观察事实→实际编码对应记录，区分未观察、明确脱敏、解析失败、模型未见。状态用于审计；若进入预测须独立消融，不能让缺字段成为来源捷径。

必要修复：

1. 动作、对象、结果分开；认证成功、凭据有效、允许、失败不偷换。修 Duo 凭据事实被未见类别丢失，移除 authentication 这种无具体行为的类别独立分数来源，检查正文绕行。
2. 传输协议与应用／安全协议分开；CEF tlsv1.3 不自动补成观察到 TCP。JSON 键名、容器和占位符不独立代表风险。
3. ASA 保留可核对的协议、端点角色、动作、结果；IANA 定义只作注册背景，不能推断安全或实际服务。
4. 端口使用预定义完整整数域保值记录，不依赖训练词表判断是否存在。0 与缺失严格分开，非法值和不同缺失原因在审计中分列。本次 17 位探针只覆盖合法整数及一个缺失哨兵，完整解析错误状态仍须实现。
5. 身份和绝对时间留在审计侧；不以未经验证的 IP、时间拼造会话或攻击链。保留包装、时刻、产品为空的全部既有反例。

验收分开：审计事实可还原；预测分支允许的信息不被无解释地编码合并。报告原始、解析、实际向量三层冲突下界和合并原因。审计保值不代表所有精确值都获准进入主模型。

## 4. 阶段 B：先确认内部验证支持

每个既有外层协议，仅使用其允许开发行构建内部来源／行为家族留出。共同联合组不跨拟合、选择和评价角色。来源只用于划分与报告，不用于按产品挑门槛。先输出角色×来源×标签行数、独立组数、已见／未见事实组合支持。

若类别仅有一个联合组，不能拆组制造独立性，也不能在缺类折声称验证完整三分类。先核查巨型组是否源于过宽连边；只有实证证明误连才能修分组，全部比较分支重新共享切分。若无可辩护的独立支持，仅报告开发现象，阻止迁移结论和“质量通过”。

内部拟合学习表示和分类器，内部选择比较最终类别；若校准概率，另设不与选择评价重叠的数据。共同内部评价在候选规则冻结后使用。已看的外层评价作开发回归；重复行、复用折不增加独立样本数。

## 5. 阶段 C：有界三分类输入对照

在相同新语义、相同职责、相同三分类逻辑回归和原行权重下，比较三个递进分支：

| 分支 | 输入 | 要回答的问题 |
|---|---|---|
| A | 审查后的共享事实，无精确端口编号 | 可靠语义能区分到何种程度 |
| B | A＋目的端口固定值域码 | 目的端口有无跨组、未见组合的实际收益 |
| C | B＋源端口固定值域码 | 源端口收益是否值得其环境捷径风险 |

精确端口字符串不得在 A/B 的正文或字典中绕行，按事实键和正文槽位核查。A 的粗语义映射在评价前冻结。C 的保值已有审计证据，预测质量仍待验证。

沿用原有限正则候选集合，不扩网格。词表只在拟合侧建立；参数选择使用最终联合三类输出。首阶段同一原行等权和决策规则，避免同时换表示、损失、门槛。v3.7 结果作历史参照，不与不同切分混称严格配对。

同时观察全行混淆矩阵、来源错误、已见／未见端口与组合、编码冲突／非冲突子集、正常误报、恶意与可疑互换。保值后非冲突子集错误未下降，先区分模型容量和训练支持，不直接宣布编码方案有效或无效。

端口扰动仅用于安全语义有依据保持的情形。例如能确认是临时客户端端口时，才检查改变该端口是否改变判断；角色不明确或可能改变服务时，不强行要求不变。无法建立有效反事实时依靠来源／组合留出，并保留“捷径风险未排除”。不以目标标签定义服务类别。

## 6. 阶段 D：只针对剩余机制追加一个学习对照

固定阶段 C 选定输入，保留原行等权对照。

若输入与拟合侧类别有支持，但少数类仍系统性被多数类压制，只追加一个训练侧类别平衡候选：权重取拟合侧类别计数的平方根倒数，再归一化使平均样本权重为 1。它是待检验的工程候选，不是论文保证；不与重复降权、重采样或新门槛同时启用。若召回收益伴随来源正常误报恶化，不自动晋升主模型。

若证据表明主要是非线性关系学不到，则优先选一个小型三分类树模型，与线性模型在同一紧凑事实输入上比较。必要协议×角色等关系须有拟合支持。两条路线不同时展开，由阶段 C 误差机制决定先后；不能仅因训练分数更高选大模型。

未见、低置信、解析失败不能自动改标 suspicious。每行仍输出官方三类之一；不确定标志为解释附加项，全行指标不删除这些行。ASA 编码前剩余 1,776 个经验最少错误仍是信息边界，不能通过重分配类别隐藏另一类新增错误。

## 7. 选择、报警和停止条件

正式开发成绩只从唯一 pred_label 入口计算。概率、风险排序、业务报警分开命名。选择调用的最终预测函数与导出相同，不重复“argmax 选参数、报警后分型出成绩”。

内部选择先拒绝：等价包装改变决策；借产品、时间、身份、空字段绕行；整来源全误报；受支持风险类别零检出。其余候选比较完整三类切片 Macro-F1，同时展示每个有支持来源的正常误报、风险召回和精确率。缺类切片单列，不伪造完整三类分数。出现实质性误报与召回冲突时记录取舍，不以总分遮盖；数值容差须在下一次训练配置冻结前声明。

如后续需要业务报警，从冻结分数建立独立策略，按业务代价在允许开发侧验证。0.1% 保留对照预算，不对未覆盖来源给保证。概率校准单独报告来源外可靠性；正温度缩放不改变 argmax，不能当成分类纠错。当前不优先训练独立二分类风险模型。

停止条件：没有可辩护的类别／组支持；收益只来自源端口记忆或身份恢复；去门槛后只得到全正常；输入不可区分且无新增可观察事实。出现这些情况，停止扩大同一路线训练，记录具体阻碍和最小必要信息，不继续堆模型或门槛网格。

## 8. 执行与交付

先在本地完成对应缺陷的准备审计和小对照，确认可学习与可验证后再进入平台五协议回归。共享预处理和矩阵缓存，失败即停，不先启动全部候选。

平台沿用用户已选的单执行包＋单命令；原数据不重传、不拆分。评价前固定源码、表示、职责、配置、依赖与摘要。当前使用已验证 CPU 环境，新依赖另做兼容检查，不照搬开源 CUDA 环境到昇腾。

回放器区分连续数值容差与实际决策一致性：身份、职责、标签、冻结主决策精确核验；概率及诊断量按预声明容差报告，边界翻转单列。旧失败回执保持原样。

官方数据足够支持本阶段实现和受限开发对照；缺少可信关联、类别细则和独立环境时，不能承诺所有 ASA 分型冲突或外部迁移已解决。本次完成的是研究与方案修订，不是新一轮全量模型验收。
