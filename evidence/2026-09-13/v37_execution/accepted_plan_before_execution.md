# v3.7 当前训练方案

**当前选择：停用 B2-W，修复输入契约，保留未加权风险模型，分离风险报警与细分类，并记录抽象冲突和未见关系的支持情况。** 根据 [方法研究与五轮复审](V37_RESEARCH_REVIEW.md) 更新；仍仅用官方数据。该方案尚未实施或形成新平台训练包。

历史结果见 [v3.6 回传审查](V36_CLOUD_RESULT_REVIEW.md)。v3.6 源码和模型保持冻结；本次研究新增的 ASA 输入核查已完成，以下工程与训练仍待执行。

## 1. 纠正前提，停止无效路线

全部 112,807 条可解析 ASA 中，原始同文及去采集头后的完整正文同文没有异标签。旧 B0 规范化才产生 75 组，B2 为 215 组。不能据此判定原始错标，也不能因为原正文能区分标签就恢复身份记忆。

B2-W 从候选、默认配置和调参网格撤下，不继续调权。原行等权监督；重复隔离用于验证，组级统计用于集中度诊断。组等权软标签仍改变重复权重，不能改名重启。

停止包装失败后整段回退、只检查 argmax 翻转、自动多数投票／高损失清洗、按日期或产品缺失路由类别。暂不引入 JTT／Group DRO／DFR、强制域对齐、大模型或时序图替换。只有所需条件和匹配实验支持时重新评估。

## 2. 阶段 A：输入与信息审查，不训练

**唯一事实入口。** 采集头与正文独立解析：已核实 CEF 包装的完整、缺失、脱敏时钟不能改变正文入口。无法确认边界时不猜补；不得把任意引用或嵌套的 CEF 当外层头。标量解码一次，事实与正文复用同值。

**字段语义。** 取消无依据的源端口存在性独立风险加分；端口按协议限定的名义类别或保守类别表达，不假定越大越危险，也不将服务端口等同于应用。缺失／无效状态留作信息支持记录。区分参数分隔、封装转义与实际载荷语法。保留完整可观察的动作、对象、结果及原文来源，否定、引用、脱敏不补成事实。

**双通道与缺失产品。** 所有输入能追溯原文片段与转换；正文和事实中的同一字段同时干预。外层产品、时间等只供审查，不供风险路由。产品为空按可核实语法解析，缺失桶不等于一个真实来源。未知和空证据计入全行输出，不能自动视为可靠正常／可疑。

取消端口存在性项时，也要检查正文中的独立 `src_port` 词元和缺失占位是否重新学出同一捷径。已识别端口通过专用、有类型的表达保留，原始字段及其跨度留证；不能只移除数值通道的一项就宣称问题修好。保留有效端口信息意味着缺失仍可能改变信息量，不宣称对所有缺失完全不敏感。

**抽象合并。** 对原始消息、完整正文、规范化正文、事实／关系逐层报告相同输入组、冲突行与丢失差异。保留原行与标签。精确接口区别有诊断价值，但无策略映射时不能恢复任意 DMZ 编号。只增加“同接口＋端口状态”已未降低主要冲突下界，不作主要新增特征。

不要求冲突数必须归零；去掉身份捷径可能暴露信息不足。验收要求是合并可解释、必要事实未被无依据删除、未删行改标。拟合侧同组标签分布用于歧义记录，不用于多数投票清洗或目标接口规则。

**本地放行。** 完整 WAF 4,130 行及 Windows／ASA／Duo／Falcon 实际样例，加已有软件反例。仅对明确等价的包装变换要求表示一致、概率在事先冻结容差内一致、所有冻结阈值报警一致；保存反例身份。语义变化单列，不假定改动作或删事实后标签不变。

全量新表示完成后重建候选共同联合组与职责。阶段 A 不通过，不生成平台包。

## 3. 阶段 B：固定模型，冻结决策与校准口径

固定 v3.6 B2，保留三类 argmax、既有经验报警、非目标校准来源最大经验阈值对照。新决策是风险超过一个全局门槛后再比较恶意／可疑，不按产品路由。

此组合已探索过，不能称未见验证。先冻结规则再运行匹配试验；目标评价不得选择阈值、交互项或拒答门槛。

主误报预算 0.1%，0.01%／1% 仅诊断。增加 NP 顺序统计阈值的条件检查：评分器先冻结、独立正常校准、样本单位及同分布条件、样本量与 ties。0.1%／5% 违约概率的理论最低正常校准量为 2,995，但重复行／模板数不能直接充当独立样本量。

当前独立性与新域条件未充分建立，分列“经验结果”“假设条件下的统计结果”“无法确认”。多来源联合保证须分配违约概率；不能用同一校准区试多个候选后只报最好者。NP、概率校准、共形方法不一次堆叠。现有最不利来源全局经验门槛作为对照，没有任意新来源保证。

全部保留原行误报、组集中度和来源支持矩阵。高概率也要附拟合侧语法、行为关系、类别支持；新颖／稀少本身不等于攻击。

比赛全行输出规定三类。运营可附信息不足／分型不确定说明，但不能一律变成 suspicious 或从指标中删除。同时报告复核量、覆盖率、复核样本类别与全行成绩。

## 4. 阶段 C：输入修复的配对训练

只比较旧表示未加权对照与修复后 B2：共同原行、联合组、职责、优化器及小 C 范围。表示变化影响分组时两侧重训，不用不同职责旧分数归因收益。

分别检查包装捷径、风险排序、低误报检出、ASA／Falcon／小来源细分类。总体 Macro-F1 不能抵消受支持场景严重退化。不重启降权、纯 B1 扩展或目标标签选字段。

保存逐条概率、模型身份、配置和阈值，能够完整回放。在目标评价前冻结非退化标准和选择规则；稀有支持不足不包装成显著提升。

## 5. 阶段 D：有必要才增加条件分型

若阶段 C 风险排序可用而 ASA 非冲突／未见关系错误仍突出，固定风险部分，在允许拟合的 malicious／suspicious 子集上比较无交互与有限交互分型器。正常记录继续参与风险模型及最终全行评价，原行权重不改。

交互限于事前规定的协议×端点角色、协议×目的端口类别等可解释关系；依据拟合侧支持与组合留出选参，未知组合显式记录。不构造完整高阶笛卡尔积记忆身份，不能用目标标签生成规则。

优先现有环境中的稀疏显式交互。只有匹配证据表明表达能力不足时，再隔离验证 EBM 等更灵活模型；兼容性不等于效果。无收益即停止，不扩为无限网格。

ASA 分开报告当前表示冲突／非冲突、关系已见／未见，并计入完整成绩。缺失策略不能由交互层补出。Falcon 只补提取完整可观察动作、对象、命令或结果；severity、scenario、tactic 与检测名称不替代事实。

## 6. 共用验收与停止条件

- 保留 known_dev、AD、Duo、WAF、ASA hard 五协议、全行混淆矩阵、逐类召回、风险排序、误报与小来源零检出。
- 三个整来源目标无恶意，ASA hard 无正常。产品缺失桶按可核实家族盘点；仅在有支持时补充允许开发侧组合留出，不拆稀有组凑支持。
- 原行与组级指标回答不同问题；分组防泄漏不自动证明独立性／同分布。明列正常失败、正常拒绝的真实拟合侧支持，缺失就不能声称该能力通过。
- 包装等价变换查表示、概率、类别和全部报警门槛；语义变化查变换合法性，不把所有删字段当不变性。
- 旧目标已查看，下一轮是内部回归和开发；重随机划分不抹去历史。最终未见答案／独立环境验收仍待完成。
- 解析未修好则不训练；交互无收益则停止扩展；障碍主要是类定义、策略或缺失反例时，停止同类重训并记录待确认事实。

官方数据足够推进上述工程与对照，没有凭空产生规则或可信实体关联。本阶段不找外部数据，也不让用户重跑 v3.6。阶段 A 通过后，沿用用户选择的“执行包＋命令”，尽量单文件交付；耗时与算力按真实试运行报告。
